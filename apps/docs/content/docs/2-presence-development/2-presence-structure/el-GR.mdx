## Διάταξη Φακέλων

Ένα presence βρίσκεται μέσα στο `src`, ομαδοποιημένο κατά το πρώτο γράμμα του ονόματός του:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
`-- assets/
    |-- logo.png
    |-- icon.png
    `-- thumbnail.jpg
```

## metadata.json

Το `metadata.json` περιγράφει την πλατφόρμα, τα υποστηριζόμενα URL, τον δημιουργό, την κατηγορία, τις μεταφρασμένες περιγραφές, τα assets του marketplace και προαιρετικές σημαίες όπως το `discordNative`.

## presence.ts

Το `presence.ts` περιέχει τη λογική εκτέλεσης. Εντοπίζει την κατάσταση της σελίδας και καλεί το Presence API.

## utils/

Για σύνθετα presences, χώρισε τη λογική σου σε αποκλειστικά αρχεία μέσα σε έναν φάκελο `utils/`. Το presence του YouTube, για παράδειγμα, οργανώνει βοηθητικές συναρτήσεις DOM, ανάλυση καναλιού και επίλυση Shorts σε ξεχωριστά modules:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
|-- assets/
|   |-- logo.png
|   |-- icon.png
|   `-- thumbnail.jpg
`-- utils/
    |-- categories.ts
    |-- dom.ts
    |-- channel.ts
    |-- text.ts
    |-- bridge.ts
    |-- shorts-dom.ts
    |-- shorts-resolve.ts
    `-- youtube-data.ts
```

Ο bundler επιλύει τοπικά imports από το `presence.ts`, οπότε μπορείς να κάνεις import τα αρχεία utilities κανονικά:

```ts filename="presence.ts"
import { findVideo } from "./utils/dom"
import { getChannelInfo } from "./utils/channel"
```
