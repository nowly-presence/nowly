## Susun Atur Folder

Presence berada di bawah `src`, dikumpulkan mengikut huruf pertama namanya:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
`-- assets/
    |-- logo.png
    |-- icon.png
    `-- thumbnail.jpg
```

## metadata.json

`metadata.json` menerangkan platform, URL disokong, pengarang, kategori, penerangan tempatan, aset marketplace dan bendera pilihan seperti `discordNative`.

## presence.ts

`presence.ts` mengandungi logik runtime. Ia mengesan keadaan halaman dan memanggil Presence API.

## utils/

Untuk presence yang kompleks, pisahkan logik anda ke dalam fail khusus di bawah folder `utils/`. Presence YouTube, sebagai contoh, menyusun pembantu DOM, penghuraian saluran dan penyelesaian Shorts ke dalam modul berasingan:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
|-- assets/
|   |-- logo.png
|   |-- icon.png
|   `-- thumbnail.jpg
`-- utils/
    |-- categories.ts
    |-- dom.ts
    |-- channel.ts
    |-- text.ts
    |-- bridge.ts
    |-- shorts-dom.ts
    |-- shorts-resolve.ts
    `-- youtube-data.ts
```

Bundler menyelesaikan import tempatan daripada `presence.ts`, jadi anda boleh mengimport fail utiliti seperti biasa:

```ts filename="presence.ts"
import { findVideo } from "./utils/dom"
import { getChannelInfo } from "./utils/channel"
```
