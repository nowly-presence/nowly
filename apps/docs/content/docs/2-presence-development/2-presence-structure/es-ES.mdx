## Estructura de carpetas

Una presencia se encuentra en `src`, agrupada por la primera letra de su nombre:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
`-- assets/
    |-- logo.png
    |-- icon.png
    `-- thumbnail.jpg
```

## metadata.json

`metadata.json` describe la plataforma, URL compatibles, autor, categoría, descripciones localizadas y recursos de la biblioteca.

## presence.ts

`presence.ts` contiene la lógica de ejecución. Detecta el estado de la página y llama a la API de Presence.

## utils/

Para presencias complejas, divide tu lógica en archivos dedicados bajo una carpeta `utils/`. La presencia de YouTube, por ejemplo, organiza helpers DOM, análisis de canales y resolución de Shorts en módulos separados:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
|-- assets/
|   |-- logo.png
|   |-- icon.png
|   `-- thumbnail.jpg
`-- utils/
    |-- categories.ts
    |-- dom.ts
    |-- channel.ts
    |-- text.ts
    |-- bridge.ts
    |-- shorts-dom.ts
    |-- shorts-resolve.ts
    `-- youtube-data.ts
```

El empaquetador resuelve importaciones locales desde `presence.ts`, por lo que puedes importar archivos de utilidad con normalidad:

```ts filename="presence.ts"
import { findVideo } from "./utils/dom"
import { getChannelInfo } from "./utils/channel"
```
