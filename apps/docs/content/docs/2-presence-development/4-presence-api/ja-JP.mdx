## プレゼンスの作成

`Presence` はNowlyランタイムによって注入される**グローバル**オブジェクトです。インポートする必要はありません。

すべてのプレゼンスは `Presence` インスタンスから始まります。

```ts filename="presence.ts"
const presence = new Presence()
```

## UpdateDataイベント

アクティビティを更新するには `UpdateData` を使用します。

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## detailsUrl / stateUrl

SDK 1.7.0+ のオプション文字列フィールド `detailsUrl` と `stateUrl` は、ボタンとは独立して対応する活動行にリンクを付けます。拡張機能とネイティブホストの両方の対応が必要です。旧バージョンはこれらを無視し、活動名は変わりません。

認証情報を含まない、2048 文字以内の確認済み公開 HTTPS URL を使ってください。対応するテキストのないリンクや無効な URL は省略されます。YouTube の `v` などのコンテンツ識別子は保持できますが、アクセストークン、非公開チャット、秘密リンク、プライバシー設定で隠された情報は共有しないでください。リンク先が不明な場合は省略します。

```ts
await presence.setActivity({
  details: "動画タイトル",
  detailsUrl: "https://www.youtube.com/watch?v=VIDEO_ID",
  state: "チャンネル名",
  stateUrl: "https://www.youtube.com/@channel",
})
```

## statusDisplayType

`statusDisplayType` はDiscordのコンパクトなステータスに表示するテキストを選びます。アクティビティカードの名前、詳細、状態は変更しません。

- `0`（既定）: `name`
- `1`: `state`
- `2`: `details`

例えば、カード内のアクティビティ名とチャンネル名をそのまま残し、コンパクトなステータスには動画タイトルを表示できます。

```ts filename="presence.ts"
await presence.setActivity({
  name: "動画サービス",
  details: "動画タイトル",
  state: "チャンネル名",
  statusDisplayType: 2,
})
```

このフィールドを含むSDKを使用し、Nowly拡張機能とネイティブホストの両方を更新してください。古いランタイムはこのフィールドを無視し、既定のステータス表示を維持します。

## clearActivity

表示する価値のあるものがない場合は `clearActivity` を呼び出します。

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` は `@nowly/sdk` からの名前付きエクスポートです。

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

これはDiscordのアクティビティタイプ(`Playing`、`Streaming`、`Listening`、`Watching`、`Competing`)に対応します。

## getSetting

`Presence.Settings` に基づいた、型付けされたプレゼンス個別の設定を読み取ります。値はユーザーが保存した設定、または定義のデフォルト値です。

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` も同じマップを持つ `ctx.settings` を受け取ります。ユーザーがサイドパネルで設定を変更すると、両方とも更新されます。

## ロギング

開発中のデバッグメッセージには `presence.info` と `presence.error` を使用してください。
