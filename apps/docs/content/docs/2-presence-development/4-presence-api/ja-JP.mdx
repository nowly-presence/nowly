## プレゼンスの作成

`Presence` はNowlyランタイムによって注入される**グローバル**オブジェクトです。インポートする必要はありません。

すべてのプレゼンスは `Presence` インスタンスから始まります。

```ts filename="presence.ts"
const presence = new Presence()
```

## UpdateDataイベント

アクティビティを更新するには `UpdateData` を使用します。

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## clearActivity

表示する価値のあるものがない場合は `clearActivity` を呼び出します。

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` は `@nowly/sdk` からの名前付きエクスポートです。

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

これはDiscordのアクティビティタイプ(`Playing`、`Streaming`、`Listening`、`Watching`、`Competing`)に対応します。

## getSetting

`Presence.Settings` に基づいた、型付けされたプレゼンス個別の設定を読み取ります。値はユーザーが保存した設定、または定義のデフォルト値です。

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` も同じマップを持つ `ctx.settings` を受け取ります。ユーザーがサイドパネルで設定を変更すると、両方とも更新されます。

## ロギング

開発中のデバッグメッセージには `presence.info` と `presence.error` を使用してください。
