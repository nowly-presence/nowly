## Crear una presencia

`Presence` es un **global** inyectado por el runtime de Nowly - no necesitas importarlo.

Toda presencia empieza con una instancia de `Presence`:

```ts filename="presence.ts"
const presence = new Presence()
```

## Evento UpdateData

Usa `UpdateData` para actualizar la actividad:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Viendo un video",
  })
})
```

## clearActivity

Llama a `clearActivity` cuando no haya nada que mostrar:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` es una exportación con nombre de `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Se corresponde con los tipos de actividad de Discord: `Playing`, `Streaming`, `Listening`, `Watching` y `Competing`.

## getSetting

Lee un ajuste tipado después de `Presence.Settings`. El valor es el ajuste guardado del usuario, o el valor por defecto de la definición:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` también recibe `ctx.settings` con el mismo mapa. Ambos se actualizan cuando el usuario cambia ajustes en el panel.

## Registro

Usa `presence.info` y `presence.error` para mensajes de depuración durante el desarrollo.
