## Crear una presencia

`Presence` es un **global** inyectado por el runtime de Nowly - no necesitas importarlo.

Toda presencia empieza con una instancia de `Presence`:

```ts filename="presence.ts"
const presence = new Presence()
```

## Evento UpdateData

Usa `UpdateData` para actualizar la actividad:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Viendo un video",
  })
})
```

## detailsUrl / stateUrl

El SDK 1.7.0+ añade los campos de texto opcionales `detailsUrl` y `stateUrl` para enlazar sus líneas correspondientes, independientemente de los botones. La extensión y el host nativo deben admitirlos; las versiones anteriores los ignoran. El nombre de la actividad no cambia.

Usa URL HTTPS públicas verificadas, sin credenciales y de hasta 2048 caracteres. Se omiten los enlaces sin texto correspondiente o con URL no válidas. Conserva los identificadores de contenido, como el parámetro `v` de YouTube, pero nunca compartas tokens de acceso, conversaciones privadas, enlaces secretos ni información oculta por los ajustes de privacidad. Omite los destinos desconocidos.

```ts
await presence.setActivity({
  details: "Título del vídeo",
  detailsUrl: "https://www.youtube.com/watch?v=VIDEO_ID",
  state: "Nombre del canal",
  stateUrl: "https://www.youtube.com/@channel",
})
```

## statusDisplayType

`statusDisplayType` elige el texto del estado compacto de Discord. No cambia el nombre, los detalles ni el estado de la tarjeta de actividad.

- `0` (predeterminado): `name`
- `1`: `state`
- `2`: `details`

Por ejemplo, mostrar el título del vídeo en el estado compacto y conservar el nombre de la actividad y el canal en la tarjeta:

```ts filename="presence.ts"
await presence.setActivity({
  name: "Servicio de vídeo",
  details: "Título del vídeo",
  state: "Nombre del canal",
  statusDisplayType: 2,
})
```

Usa una versión del SDK que incluya este campo y actualiza la extensión Nowly y el host nativo. Las versiones anteriores del runtime ignoran el campo y mantienen el estado predeterminado.

## clearActivity

Llama a `clearActivity` cuando no haya nada que mostrar:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` es una exportación con nombre de `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Se corresponde con los tipos de actividad de Discord: `Playing`, `Streaming`, `Listening`, `Watching` y `Competing`.

## getSetting

Lee un ajuste tipado después de `Presence.Settings`. El valor es el ajuste guardado del usuario, o el valor por defecto de la definición:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` también recibe `ctx.settings` con el mismo mapa. Ambos se actualizan cuando el usuario cambia ajustes en el panel.

## Registro

Usa `presence.info` y `presence.error` para mensajes de depuración durante el desarrollo.
