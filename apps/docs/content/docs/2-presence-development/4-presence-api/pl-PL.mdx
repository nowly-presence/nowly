## Tworzenie obecności

`Presence` jest obiektem **globalnym** wstrzykiwanym przez środowisko uruchomieniowe Nowly - nie musisz go importować.

Każda obecność zaczyna się od instancji `Presence`:

```ts filename="presence.ts"
const presence = new Presence()
```

## Zdarzenie UpdateData

Użyj `UpdateData`, aby odświeżyć aktywność:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## detailsUrl / stateUrl

SDK 1.7.0+ dodaje opcjonalne pola tekstowe `detailsUrl` i `stateUrl`, które tworzą odnośniki dla odpowiednich wierszy aktywności, niezależnie od przycisków. Rozszerzenie i host natywny muszą je obsługiwać; starsze wersje je ignorują. Nazwa aktywności się nie zmienia.

Używaj sprawdzonych publicznych adresów HTTPS bez danych logowania, o długości do 2048 znaków. Linki bez odpowiadającego tekstu lub z nieprawidłowym adresem są pomijane. Zachowuj identyfikatory treści, np. parametr YouTube `v`, ale nigdy nie udostępniaj tokenów dostępu, prywatnych rozmów, tajnych linków ani informacji ukrytych przez ustawienia prywatności. Pomijaj nieznane cele.

```ts
await presence.setActivity({
  details: "Tytuł filmu",
  detailsUrl: "https://www.youtube.com/watch?v=VIDEO_ID",
  state: "Nazwa kanału",
  stateUrl: "https://www.youtube.com/@channel",
})
```

## statusDisplayType

`statusDisplayType` wybiera tekst skróconego statusu Discord. Nie zmienia nazwy, szczegółów ani stanu na karcie aktywności.

- `0` (domyślnie): `name`
- `1`: `state`
- `2`: `details`

Na przykład można wyświetlić tytuł filmu w skróconym statusie, zachowując nazwę aktywności i kanał na karcie:

```ts filename="presence.ts"
await presence.setActivity({
  name: "Serwis wideo",
  details: "Tytuł filmu",
  state: "Nazwa kanału",
  statusDisplayType: 2,
})
```

Użyj wersji SDK zawierającej to pole i zaktualizuj rozszerzenie Nowly oraz host natywny. Starsze wersje środowiska uruchomieniowego ignorują to pole i zachowują domyślny widok statusu.

## clearActivity

Wywołaj `clearActivity`, gdy nie ma nic wartego pokazania:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` to nazwany eksport z `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Mapuje się na typy aktywności Discorda: `Playing`, `Streaming`, `Listening`, `Watching` i `Competing`.

## getSetting

Odczytaj typowane ustawienie danej obecności po `Presence.Settings`. Wartość to zapisane ustawienie użytkownika lub wartość domyślna z definicji:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` również otrzymuje `ctx.settings` z tą samą mapą. Oba są aktualizowane, gdy użytkownik zmienia ustawienia w panelu bocznym.

## Logowanie

Użyj `presence.info` i `presence.error` do komunikatów debugowania podczas developmentu.
