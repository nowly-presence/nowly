## Créer une présence

`Presence` est une **globale** injectée par le runtime Nowly - vous n'avez pas besoin de l'importer.

Chaque présence commence par une instance de `Presence`&nbsp;:

```ts filename="presence.ts"
const presence = new Presence()
```

## Événement UpdateData

Utilisez `UpdateData` pour actualiser l'activité&nbsp;:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Regarde une vidéo",
  })
})
```

## setActivity

`setActivity` envoie l'activité Discord actuelle. Les champs courants incluent&nbsp;:

<Callout type="error">
Discord refuse les activités Rich Presence lorsque `largeImageText` ou `smallImageText` contient moins de deux caractères. Nowly nettoie ces infobulles facultatives et les omet si le résultat contient moins de deux caractères&nbsp;; l'image reste disponible.
</Callout>

## statusDisplayType

`statusDisplayType` choisit le texte affiché dans le statut compact de Discord. Il ne modifie ni le nom, ni les détails, ni l'état de la carte d'activité.

- `0` (par défaut) : `name`
- `1` : `state`
- `2` : `details`

Par exemple, afficher le titre de la vidéo dans le statut compact tout en conservant le nom de l'activité et la chaîne dans la carte :

```ts filename="presence.ts"
await presence.setActivity({
  name: "Service vidéo",
  details: "Titre de la vidéo",
  state: "Nom de la chaîne",
  statusDisplayType: 2,
})
```

Utilisez une version du SDK qui inclut ce champ et mettez à jour l'extension Nowly ainsi que l'hôte natif. Les anciennes versions du runtime ignorent ce champ et conservent l'affichage du statut par défaut.

## clearActivity

Appelez `clearActivity` lorsqu'il n'y a plus rien à afficher&nbsp;:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` est un export nommé de `@nowly/sdk`&nbsp;:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Il correspond aux types d'activité Discord&nbsp;: `Playing`, `Streaming`, `Listening`, `Watching` et `Competing`.

## getSetting

Lisez un paramètre typé après `Presence.Settings`. La valeur est le réglage enregistré de l'utilisateur, ou la valeur par défaut de la définition&nbsp;:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` reçoit aussi `ctx.settings` avec la même correspondance. Les deux se mettent à jour lorsque l'utilisateur change les réglages dans le panneau.

## Journalisation

Utilisez `presence.info` et `presence.error` pour les messages de débogage pendant le développement.
