## Mencipta Presence

`Presence` ialah **global** yang disuntik oleh runtime Nowly - anda tidak perlu mengimportnya.

Setiap presence bermula dengan satu instance `Presence`:

```ts filename="presence.ts"
const presence = new Presence()
```

## Acara UpdateData

Gunakan `UpdateData` untuk menyegarkan aktiviti:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## clearActivity

Panggil `clearActivity` apabila tiada apa yang berbaloi untuk dipaparkan:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` ialah eksport bernama daripada `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Ia memetakan kepada jenis aktiviti Discord: `Playing`, `Streaming`, `Listening`, `Watching`, dan `Competing`.

## getSetting

Baca tetapan bertaip bagi setiap presence selepas `Presence.Settings`. Nilai ialah tetapan tersimpan pengguna, atau lalai definisi:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` turut menerima `ctx.settings` dengan peta yang sama. Kedua-duanya dikemas kini apabila pengguna menukar tetapan dalam panel sisi.

## Pengelogan

Gunakan `presence.info` dan `presence.error` untuk mesej penyahpepijatan semasa pembangunan.
