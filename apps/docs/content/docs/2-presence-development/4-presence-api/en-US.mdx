## Creating a Presence

`Presence` is a **global** injected by the Nowly runtime - you don't need to import it.

Every presence starts with a `Presence` instance:

```ts filename="presence.ts"
const presence = new Presence()
```

## UpdateData Event

Use `UpdateData` to refresh activity:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## setActivity

`setActivity` sends the current Discord activity. Common fields include:

    { name: "statusDisplayType", type: "0 | 1 | 2", description: "Field shown in Discord's compact status: 0 = name (default), 1 = state, 2 = details." },
    { name: "details", type: "string", description: "Primary activity line shown in Discord." },

    { name: "startTimestamp", type: "number", description: "Unix timestamp for elapsed activity progress." },
    { name: "endTimestamp", type: "number", description: "Unix timestamp for remaining activity progress." },
    { name: "largeImageKey", type: "string", description: "Main image asset key, usually Assets.Logo or Assets.Thumbnail (globals provided by the runtime)." },
    { name: "largeImageText", type: "string", description: "Tooltip for the large image." },
    { name: "smallImageKey", type: "string", description: "Optional small image asset key." },
    { name: "smallImageText", type: "string", description: "Tooltip for the small image." },
    { name: "type", type: "number", description: "Discord activity type from PresenceType." },
    { name: "buttons", type: "array", description: "Optional Discord activity buttons." }
  ]}
/>

<Callout type="error">
Discord rejects Rich Presence payloads when `largeImageText` or `smallImageText` contains fewer than two characters. Nowly trims these optional tooltips and omits them when the result is shorter than two characters; the image remains available.
</Callout>

## statusDisplayType

`statusDisplayType` chooses the text shown in Discord's compact status. It does not change the activity card's name, details, or state.

- `0` (default): `name`
- `1`: `state`
- `2`: `details`

For example, show the video title in the compact status while keeping the activity name and channel in the card:

```ts filename="presence.ts"
await presence.setActivity({
  name: "Video service",
  details: "Video title",
  state: "Channel name",
  statusDisplayType: 2,
})
```

Use an SDK version that includes this field and update both the Nowly extension and native host. Older runtime versions ignore the field and keep the default status display.

## clearActivity

Call `clearActivity` when there is nothing worth showing:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` is a named export from `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

It maps to Discord activity types: `Playing`, `Streaming`, `Listening`, `Watching`, and `Competing`.

## getSetting

Read a typed per-presence setting after `Presence.Settings`. The value is the user's saved setting, or the definition default:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` also receives `ctx.settings` with the same map. Both update when the user changes settings in the side panel.

## Logging

Use `presence.info` and `presence.error` for debug messages during development.
