## Bir Presence Oluşturma

`Presence`, Nowly runtime'ı tarafından enjekte edilen bir **global**dir - onu içe aktarmanıza gerek yoktur.

Her presence bir `Presence` örneğiyle başlar:

```ts filename="presence.ts"
const presence = new Presence()
```

## UpdateData Olayı

Etkinliği yenilemek için `UpdateData` kullanın:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## clearActivity

Gösterilmeye değer bir şey olmadığında `clearActivity`'yi çağırın:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType`, `@nowly/sdk`'den adlandırılmış bir export'tur:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Discord etkinlik türlerine eşlenir: `Playing`, `Streaming`, `Listening`, `Watching` ve `Competing`.

## getSetting

`Presence.Settings`'ten sonra tipli, presence başına bir ayarı okuyun. Değer, kullanıcının kaydedilmiş ayarı veya tanımdaki varsayılan değerdir:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData`, aynı haritayla birlikte `ctx.settings`'i de alır. Kullanıcı yan panelde ayarları değiştirdiğinde ikisi de güncellenir.

## Günlükleme

Geliştirme sırasında hata ayıklama mesajları için `presence.info` ve `presence.error` kullanın.
