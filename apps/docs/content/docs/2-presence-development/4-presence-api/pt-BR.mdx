## Criando uma Presença

`Presence` é uma **global** injetada pelo runtime do Nowly - você não precisa importá-la.

Toda presença começa com uma instância de `Presence`:

```ts filename="presence.ts"
const presence = new Presence()
```

## Evento UpdateData

Use `UpdateData` para atualizar a atividade:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

<Callout type="error">
O Discord rejeita payloads de Rich Presence quando `largeImageText` ou `smallImageText` contém menos de dois caracteres. O Nowly limpa essas dicas opcionais e as omite quando o resultado tem menos de dois caracteres; a imagem continua disponível.
</Callout>

## statusDisplayType

`statusDisplayType` escolhe o texto do status compacto do Discord. Não altera o nome, os detalhes nem o estado no cartão de atividade.

- `0` (padrão): `name`
- `1`: `state`
- `2`: `details`

Por exemplo, mostrar o título do vídeo no status compacto e manter o nome da atividade e o canal no cartão:

```ts filename="presence.ts"
await presence.setActivity({
  name: "Serviço de vídeo",
  details: "Título do vídeo",
  state: "Nome do canal",
  statusDisplayType: 2,
})
```

Use uma versão do SDK que inclua esse campo e atualize a extensão Nowly e o host nativo. Versões anteriores do runtime ignoram o campo e mantêm a exibição padrão do status.

## clearActivity

Chame `clearActivity` quando não houver nada que valha a pena exibir:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` é uma exportação nomeada de `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Ele mapeia para os tipos de atividade do Discord: `Playing`, `Streaming`, `Listening`, `Watching` e `Competing`.

## getSetting

Leia uma configuração tipada por presença após `Presence.Settings`. O valor é a configuração salva do usuário ou o padrão da definição:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` também recebe `ctx.settings` com o mesmo mapa. Ambos são atualizados quando o usuário altera as configurações no painel lateral.

## Registro (Logging)

Use `presence.info` e `presence.error` para mensagens de depuração durante o desenvolvimento.
