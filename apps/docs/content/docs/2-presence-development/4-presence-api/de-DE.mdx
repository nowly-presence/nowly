## Eine Presence erstellen

`Presence` ist ein **globales** Objekt, das von der Nowly-Laufzeitumgebung bereitgestellt wird - du musst es nicht importieren.

Jede Presence beginnt mit einer `Presence`-Instanz:

```ts filename="presence.ts"
const presence = new Presence()
```

## UpdateData-Ereignis

Verwende `UpdateData`, um die Aktivität zu aktualisieren:

```ts filename="presence.ts"
presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: "Watching a video",
  })
})
```

## clearActivity

Rufe `clearActivity` auf, wenn es nichts Sehenswertes gibt:

```ts filename="presence.ts"
presence.clearActivity()
```

## PresenceType

`PresenceType` ist ein benannter Export aus `@nowly/sdk`:

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"
```

Er bildet Discord-Aktivitätstypen ab: `Playing`, `Streaming`, `Listening`, `Watching` und `Competing`.

## getSetting

Lese eine typisierte Presence-Einstellung nach `Presence.Settings`. Der Wert ist die gespeicherte Einstellung des Nutzers oder der Standardwert aus der Definition:

```ts filename="presence.ts"
const showButtons = await presence.getSetting<boolean>("showButtons")
```

`UpdateData` erhält ebenfalls `ctx.settings` mit derselben Map. Beide aktualisieren sich, wenn der Nutzer Einstellungen im Seitenpanel ändert.

## Logging

Verwende `presence.info` und `presence.error` für Debug-Meldungen während der Entwicklung.
