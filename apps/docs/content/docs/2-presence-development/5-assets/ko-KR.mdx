## 필수 에셋

모든 프레즌스에는 다음이 포함되어야 합니다.

<TypeTable
  properties={[
    { name: "logo.png", type: "PNG, 300×300", description: "더 넓은 배치, 헤더, Open Graph 이미지에 사용되는 플랫폼 브랜드 마크.", required: true },
    { name: "icon.png", type: "PNG, 128×128", description: "작은 UI 화면과 Discord 활동 이미지에 사용되는 컴팩트한 정사각형 아이콘.", required: true },
    { name: "thumbnail.jpg", type: "JPG, 1920×1080", description: "플랫폼을 명확히 나타내는 마켓플레이스 및 상세 페이지용 비주얼.", required: true }
  ]}
/>

이 정확한 크기는 모든 프레즌스 PR에서 CI에 의해 강제됩니다 - 크기가 잘못된 에셋은 검증에 실패합니다.

## 로고

더 넓은 이미지가 적합한 경우 플랫폼 브랜드 마크로 `logo.png`를 사용하세요. 정확히 **300×300**이어야 합니다.

## 아이콘

컴팩트한 정사각형 표시, 색상 배경, Discord 활동 이미지에는 `icon.png`를 사용하세요. 정확히 **128×128**이어야 합니다.

## 썸네일

마켓플레이스 및 상세 페이지 비주얼에는 `thumbnail.jpg`를 사용하세요. 플랫폼을 명확히 나타내야 합니다. 정확히 **1920×1080**이어야 합니다.

## 런타임 에셋 상수

`Assets`는 런타임에서 제공됩니다([Presence API](/presence-development/presence-api) 참고). 3개의 기본 에셋 키를 제공합니다.

```ts filename="presence.ts"
Assets.Logo      // → "logo.png"
Assets.Icon      // → "icon.png"
Assets.Thumbnail // → "thumbnail.jpg"
```

활동 페이로드에서 사용하세요.

```ts filename="presence.ts"
await presence.setActivity({
  largeImageKey: Assets.Logo,
  largeImageText: "YouTube",
})
```

## 품질 가이드라인

`icon.png`에는 투명 PNG를 사용하세요 - 아이콘은 Nowly 라이브러리에서 색상 배경 위에 표시되므로, 채워진 배경은 충돌합니다. 투명한 `logo.png`가 선호되지만 덜 중요합니다. 썸네일은 작은 크기에서도 알아볼 수 있게 유지하고 일반적인 이미지는 피하세요.
