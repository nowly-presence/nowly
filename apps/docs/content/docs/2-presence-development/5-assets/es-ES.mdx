## Recursos requeridos

Cada presence debe incluir:

<TypeTable
  properties={[
    { name: "logo.png", type: "PNG", description: "Marca de la plataforma para colocaciones amplias, encabezados e imágenes Open Graph.", required: true },
    { name: "icon.png", type: "PNG", description: "Icono cuadrado compacto utilizado en superficies UI pequeñas e imágenes de actividad de Discord.", required: true },
    { name: "thumbnail.jpg", type: "JPG", description: "Visual del mercado y página de detalle que represente claramente la plataforma.", required: true }
  ]}
/>

## Logo

Usa `logo.png` para la marca de la plataforma cuando sea apropiada una imagen más amplia.

## Icono

Usa `icon.png` para displays cuadrados compactos, fondos de color e imágenes de actividad de Discord.

## Miniatura

Usa `thumbnail.jpg` para visuales del mercado y páginas de detalle. Debe representar la plataforma claramente.

## Constantes de recursos en runtime

`Assets` es proporcionado por el runtime (consulta [Presence API](/docs/presence-development/presence-api)). Expone las tres claves de recursos predeterminadas:

```ts filename="presence.ts"
Assets.Logo      // → "logo.png"
Assets.Icon      // → "icon.png"
Assets.Thumbnail // → "thumbnail.jpg"
```

Úsalas en los payloads de actividad:

```ts filename="presence.ts"
await presence.setActivity({
  largeImageKey: Assets.Logo,
  largeImageText: "YouTube",
})
```

## Directrices de calidad

Usa un PNG transparente para `icon.png` — el icono se muestra sobre un fondo de color en la biblioteca de Nowly, por lo que un fondo relleno causará conflicto. Se prefiere un `logo.png` transparente, aunque es menos crítico. Mantén las miniaturas legibles en tamaños pequeños y evita imágenes genéricas.
