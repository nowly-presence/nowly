## Recursos requeridos

Cada presencia debe incluir:

## Logo

Usa `logo.png` para la marca de la plataforma cuando convenga una imagen más amplia.

## Icono

Usa `icon.png` para pantallas cuadradas compactas, fondos de color e imágenes de actividad de Discord.

## Miniatura

Usa `thumbnail.jpg` para los visuales de la biblioteca y las páginas de detalle. Debe representar la plataforma con claridad.

## Constantes de recursos en runtime

`Assets` lo proporciona el runtime (consulta [Presence API](/presence-development/presence-api)). Expone las tres claves de recursos predeterminadas:

```ts filename="presence.ts"
Assets.Logo      // → "logo.png"
Assets.Icon      // → "icon.png"
Assets.Thumbnail // → "thumbnail.jpg"
```

Úsalas en los datos de actividad:

```ts filename="presence.ts"
await presence.setActivity({
  largeImageKey: Assets.Logo,
  largeImageText: "YouTube",
})
```

## Directrices de calidad

Usa un PNG transparente para `icon.png` — el icono se muestra sobre un fondo de color en la biblioteca de Nowly, así que un fondo relleno chocará. Se prefiere un `logo.png` transparente, aunque es menos crítico. Mantén las miniaturas legibles en tamaños pequeños y evita imágenes genéricas.
