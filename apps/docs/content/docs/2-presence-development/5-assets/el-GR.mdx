## Απαιτούμενα Assets

Κάθε presence πρέπει να περιλαμβάνει:

<TypeTable
  properties={[
    { name: "logo.png", type: "PNG, 300×300", description: "Σήμα μάρκας πλατφόρμας για ευρύτερες τοποθετήσεις, επικεφαλίδες και εικόνες Open Graph.", required: true },
    { name: "icon.png", type: "PNG, 128×128", description: "Συμπαγές τετράγωνο εικονίδιο που χρησιμοποιείται σε μικρές επιφάνειες UI και εικόνες δραστηριότητας Discord.", required: true },
    { name: "thumbnail.jpg", type: "JPG, 1920×1080", description: "Οπτικό στοιχείο για το marketplace και τη σελίδα λεπτομερειών που αναπαριστά ξεκάθαρα την πλατφόρμα.", required: true }
  ]}
/>

Αυτές οι ακριβείς διαστάσεις επιβάλλονται από το CI σε κάθε PR presence - ένα asset με λάθος μέγεθος αποτυγχάνει στην επικύρωση.

## Λογότυπο

Χρησιμοποίησε το `logo.png` για το σήμα μάρκας της πλατφόρμας όταν είναι κατάλληλη μια ευρύτερη εικόνα. Πρέπει να είναι ακριβώς **300×300**.

## Εικονίδιο

Χρησιμοποίησε το `icon.png` για συμπαγείς τετράγωνες προβολές, έγχρωμα φόντα και εικόνες δραστηριότητας Discord. Πρέπει να είναι ακριβώς **128×128**.

## Thumbnail

Χρησιμοποίησε το `thumbnail.jpg` για οπτικά στοιχεία στο marketplace και τη σελίδα λεπτομερειών. Θα πρέπει να αναπαριστά ξεκάθαρα την πλατφόρμα. Πρέπει να είναι ακριβώς **1920×1080**.

## Σταθερές Assets Χρόνου Εκτέλεσης

Το `Assets` παρέχεται από το runtime (δες [Presence API](/presence-development/presence-api)). Εκθέτει τα τρία προεπιλεγμένα κλειδιά assets:

```ts filename="presence.ts"
Assets.Logo      // → "logo.png"
Assets.Icon      // → "icon.png"
Assets.Thumbnail // → "thumbnail.jpg"
```

Χρησιμοποίησέ τα σε payloads δραστηριότητας:

```ts filename="presence.ts"
await presence.setActivity({
  largeImageKey: Assets.Logo,
  largeImageText: "YouTube",
})
```

## Οδηγίες Ποιότητας

Χρησιμοποίησε ένα διάφανο PNG για το `icon.png` - το εικονίδιο εμφανίζεται σε έγχρωμο φόντο στη βιβλιοθήκη του Nowly, οπότε ένα γεμάτο φόντο θα συγκρούεται οπτικά. Ένα διάφανο `logo.png` προτιμάται αλλά είναι λιγότερο κρίσιμο. Κράτα τα thumbnails ευανάγνωστα σε μικρά μεγέθη και απόφευγε γενικές εικόνες.
