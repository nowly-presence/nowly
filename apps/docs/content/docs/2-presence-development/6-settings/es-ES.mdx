## Qué son los ajustes

Los ajustes permiten a los usuarios personalizar cómo se comporta una presence sin editar código.

## Tipos de ajuste compatibles

Nowly admite ajustes booleanos, de entrada, selección y deslizantes.

## Definiendo ajustes

Usa [`Presence.Settings`](/docs/presence-development/presence-api) para definir ajustes tipados:

```ts filename="presence.ts"
const settings = Presence.Settings({
  showButtons: {
    type: "boolean",
    default: true,
    label: {
      "en-US": "Mostrar botones"
    }
  }
})
```

## Leyendo ajustes

Usa `getSetting` en tiempo de ejecución. Los valores vienen de los ajustes guardados del usuario, con fallback a los defaults de `Presence.Settings`. Los cambios desde el panel lateral llegan como `SETTINGS_UPDATED` y actualizan el mismo mapa.

También puedes leer `ctx.settings` en `UpdateData`:

```ts filename="presence.ts"
presence.on("UpdateData", async (ctx) => {
  const showButtons = await presence.getSetting<boolean>("showButtons")
  // mismo valor: ctx.settings.showButtons
})
```

## Etiquetas localizadas

Las etiquetas y descripciones de los ajustes usan las mismas claves de idioma que los metadatos.

## Valores predeterminados

Elige valores predeterminados seguros. Una presence debería funcionar inmediatamente después de la instalación sin requerir configuración.
