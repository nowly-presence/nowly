## Ayarlar Nedir

Ayarlar, kullanıcıların kod düzenlemeden bir presence'ın nasıl davrandığını özelleştirmesine olanak tanır.

## Desteklenen Ayar Türleri

Nowly, boolean, input, select ve slider ayarlarını destekler.

## Ayarları Tanımlama

Tipli ayarları tanımlamak için [`Presence.Settings`](/presence-development/presence-api) kullanın:

```ts filename="presence.ts"
const settings = Presence.Settings({
  showButtons: {
    type: "boolean",
    default: true,
    label: {
      "en-US": "Show buttons"
    }
  }
})
```

## Ayarları Okuma

Çalışma zamanında `getSetting` kullanın. Değerler, kullanıcının kaydedilmiş ayarlarından gelir ve `Presence.Settings`'teki varsayılanlara geri döner. Yan panelden gelen canlı değişiklikler `SETTINGS_UPDATED` olarak gelir ve aynı haritayı günceller.

Ayrıca `UpdateData` içindeki `ctx.settings`'ten geçerli haritayı da okuyabilirsiniz:

```ts filename="presence.ts"
presence.on("UpdateData", async (ctx) => {
  const showButtons = await presence.getSetting<boolean>("showButtons")
  // aynı değer: ctx.settings.showButtons
})
```

## Yerelleştirilmiş Etiketler

Ayar etiketleri ve açıklamaları, meta verilerde kullanılan aynı yerel ayar anahtarlarını kullanır.

## Varsayılanlar

Güvenli varsayılanlar seçin. Bir presence, yapılandırma gerektirmeden kurulumdan hemen sonra çalışmalıdır.
