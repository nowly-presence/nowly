## Apakah Tetapan

Tetapan membolehkan pengguna menyesuaikan cara presence berfungsi tanpa menyunting kod.

## Jenis Tetapan Disokong

Nowly menyokong tetapan boolean, input, select dan slider.

## Mentakrifkan Tetapan

Gunakan [`Presence.Settings`](/presence-development/presence-api) untuk mentakrifkan tetapan bertaip:

Mulai CLI 1.7.0, gunakan `settings.ts` dengan eksport lalai di sebelah `presence.ts`. Fail ini menggantikan sepenuhnya definisi inline legacy `Presence.Settings({ ... })`, tanpa penggabungan. Fail tidak sah menyebabkan binaan gagal. Tanpa fail ini, format legacy masih disokong.

```ts filename="settings.ts"
import type { PresenceSetting } from "@nowly/sdk"

export default {
  showButtons: {
    type: "boolean",
    default: true,
    label: {
      "en-US": "Show buttons"
    }
  }
} satisfies Record<string, PresenceSetting>
```

```ts filename="presence.ts"
const presence = new Presence()
```

CLI mengesan `settings.ts` secara automatik, tanpa import atau panggilan `Presence.Settings` dalam `presence.ts`. CLI masih menjana `settings.json` dan mendaftarkan nilai lalai. Nilai yang disimpan pengguna diutamakan. Gunakan definisi deklaratif serasi JSON tanpa API pelayar atau Node. Gunakan `getSetting<boolean>("showButtons")` untuk bacaan berjenis jelas.

## Membaca Tetapan

Gunakan `getSetting` semasa runtime. Nilai datang daripada tetapan tersimpan pengguna, kembali kepada lalai daripada `Presence.Settings`. Perubahan langsung daripada panel sisi tiba sebagai `SETTINGS_UPDATED` dan mengemas kini peta yang sama.

Anda juga boleh membaca peta semasa daripada `ctx.settings` dalam `UpdateData`:

```ts filename="presence.ts"
presence.on("UpdateData", async (ctx) => {
  const showButtons = await presence.getSetting<boolean>("showButtons")
  // nilai sama: ctx.settings.showButtons
})
```

## Label Tempatan

Label dan penerangan tetapan menggunakan kunci locale yang sama seperti yang digunakan dalam metadata.

## Lalai

Pilih lalai yang selamat. Presence sepatutnya berfungsi serta-merta selepas pemasangan tanpa memerlukan konfigurasi.
