## Empieza con la CLI

Usa la CLI de Nowly para generar una nueva presencia:

```bash
nowly init "Ejemplo"
```

La CLI crea los metadatos, un script de presencia y los recursos requeridos.

## Código básico de una presencia

`Presence` y `Assets` los proporciona el runtime - consulta [Presence API](/presence-development/presence-api) y [Assets](/presence-development/assets).
`document` es la API DOM estándar del navegador, disponible porque las presencias se ejecutan como scripts de contenido en la extensión.

Solo `PresenceType` (y otros helpers como `createMediaTimestamps`) deben importarse desde `@nowly/sdk`.

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    state: document.location.hostname,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

## Flujo en tiempo de ejecución

Cuando el usuario visita una URL coincidente, Nowly carga tu presencia. La presencia lee el estado de la página y llama a `setActivity`. La extensión reenvía esos datos a Nowly Host, que actualiza Discord.

## Ciclo de desarrollo

<Steps>
<Step title="Generar" description="Crea la carpeta de la presencia, los metadatos y los recursos requeridos.">

```bash
nowly init "Ejemplo"
```

</Step>
<Step title="Configurar" description="Establece el nombre, autor, URL compatibles, categoría, color, descripciones localizadas y discordNative si Discord ya admite la plataforma.">

Edita `metadata.json` - consulta [Metadata](/presence-development/metadata) para todos los campos disponibles.

</Step>
<Step title="Implementar" description="Escribe la lógica de la presencia usando el SDK de Presence.">

```typescript filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

</Step>
<Step title="Validar" description="Comprueba que la estructura de metadatos sea correcta y que los recursos estén en su sitio.">

```bash
nowly validate
```

</Step>
<Step title="Compilar" description="Compila la presencia en un paquete independiente.">

```bash
nowly build ejemplo
```

</Step>
<Step title="Cargar" description="Instala la presencia compilada en el navegador. Dos métodos: una extensión precompilada, o soltar un zip.">

Consulta [Cargar y probar en local](/presence-development/load-and-test) para la comparación completa.

**Primera vez** (Nowly aún no está en el navegador): incluye la presencia en una extensión lista para cargar.

```bash
nowly extension ejemplo
```

Carga `dist/extension-dev` como unpacked en `chrome://extensions`.

**Nowly ya cargada unpacked:** empaqueta un zip y suéltalo en Ajustes → Avanzado → Debug. Las instalaciones de la tienda rechazan zips sin firma.

```bash
nowly pack ejemplo
```

</Step>
<Step title="Probar" description="Abre el sitio web objetivo - la presencia se activa automáticamente.">

Visita el sitio
</Step>
</Steps>

Repite **Implementar** → **Compilar** → **Cargar** después de cada cambio de código.
