## Commencez avec la CLI

Utilisez la CLI Nowly pour générer une nouvelle présence&nbsp;:

```bash
nowly init "Exemple"
```

La CLI crée les métadonnées, un script de présence et les fichiers visuels requis.

## Code de base d'une présence

`Presence` et `Assets` sont fournis par le runtime - voir [Presence API](/presence-development/presence-api) et [Assets](/presence-development/assets).
`document` est l'API DOM standard du navigateur, disponible car les présences s'exécutent comme des scripts de contenu dans l'extension.

Seuls `PresenceType` (et d'autres helpers comme `createMediaTimestamps`) doivent être importés depuis `@nowly/sdk`.

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    state: document.location.hostname,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

## Flux d'exécution

Lorsque l'utilisateur visite une URL correspondante, Nowly charge votre présence. La présence lit l'état de la page et appelle `setActivity`. L'extension transmet ces données à Nowly Host, qui met à jour Discord.

## Boucle de développement

<Steps>
<Step title="Générer" description="Créez le dossier de la présence, les métadonnées et les fichiers visuels requis.">

```bash
nowly init "Exemple"
```

</Step>
<Step title="Configurer" description="Définissez le nom, l'auteur, les URL prises en charge, la catégorie, la couleur et les descriptions localisées.">

Modifiez `metadata.json` - voir [Metadata](/presence-development/metadata) pour tous les champs disponibles.

</Step>
<Step title="Implémenter" description="Écrivez la logique de la présence à l'aide du SDK Presence.">

```typescript filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

</Step>
<Step title="Valider" description="Vérifiez que la structure des métadonnées est correcte et que les fichiers visuels sont en place.">

```bash
nowly validate
```

</Step>
<Step title="Compiler" description="Compilez la présence en un paquet autonome.">

```bash
nowly build exemple
```

</Step>
<Step title="Charger" description="Installez la présence compilée dans le navigateur. Deux méthodes : une extension précompilée, ou un zip à déposer.">

Voir [Charger et tester en local](/presence-development/load-and-test) pour le comparatif complet.

**Première fois** (Nowly pas encore dans le navigateur)&nbsp;: intégrez la présence dans une extension prête à charger.

```bash
nowly extension exemple
```

Chargez `dist/extension-dev` en unpacked dans `chrome://extensions`.

**Nowly déjà chargé unpacked&nbsp;:** créez un zip et déposez-le dans Réglages → Avancé → Debug. Les installations du store refusent les zips non signés.

```bash
nowly pack exemple
```

</Step>
<Step title="Tester" description="Ouvrez le site web cible - la présence s'active automatiquement.">

Visitez le site
</Step>
</Steps>

Répétez **Implémenter** → **Compiler** → **Charger** après chaque modification de code.
