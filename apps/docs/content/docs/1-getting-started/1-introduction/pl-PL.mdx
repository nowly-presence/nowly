## Czym jest Nowly?

Nowly wyświetla aktywność z obsługiwanych stron w Discord Rich Presence. Będziesz korzystać z trzech elementów:

- rozszerzenia Nowly do Chrome, Chromium, Brave i Edge
- aplikacji desktopowej na Windows lub Linux
- instalowalnych obecności z biblioteki Nowly

## Czym jest obecność?

Obecność to niewielka integracja JavaScript dla jednej strony. Uruchamia się, gdy odwiedzasz obsługiwany adres URL, odczytuje, co robisz na stronie, i wysyła dane o aktywności do rozszerzenia.

Obecności mogą wyświetlać:

- nazwę platformy
- aktualny film, transmisję, program, repozytorium lub tytuł strony
- nazwy autora, kanału, twórcy lub projektu
- znaczniki czasu odtwarzania
- zasoby graficzne platformy
- przyciski prowadzące z powrotem do treści

## Jak działa Nowly

Rozszerzenie przeglądarki wykrywa obsługiwane strony i wczytuje zainstalowane obecności. Obecność przygotowuje dane aktywności Discorda.

Aplikacja desktopowa jest lokalnym mostem między przeglądarką a Discord Desktop. Odbiera dane aktywności z rozszerzenia i wysyła je do Discorda na Twoim komputerze.

## Zacznij tutaj

Wykonaj konfigurację w tej kolejności:

1. Zainstaluj rozszerzenie.
2. Włącz skrypty użytkownika.
3. Zainstaluj aplikację desktopową.
4. Otwórz Discord Desktop.
5. Zainstaluj obecność.
6. Przetestuj na zgodnej stronie, np. YouTube.

Jeśli czegoś brakuje, otwórz panel boczny rozszerzenia. Diagnostyka wyświetla każdą kontrolę osobno, dzięki czemu dokładnie widzisz, co naprawić.
