## Nowly란?

Nowly는 지원되는 웹사이트의 활동을 Discord Rich Presence에 표시합니다. 다음 세 가지를 사용하게 됩니다.

- Chrome, Chromium, Brave, Edge용 Nowly 브라우저 확장 프로그램
- Windows 또는 Linux용 데스크톱 앱
- Nowly 라이브러리에서 설치 가능한 프레즌스

## 프레즌스란?

프레즌스는 하나의 웹사이트를 위한 작은 JavaScript 연동 기능입니다. 지원되는 URL을 방문하면 실행되어 페이지에서 하는 작업을 읽고 활동 데이터를 확장 프로그램에 전송합니다.

프레즌스는 다음을 표시할 수 있습니다.

- 플랫폼 이름
- 현재 재생 중인 동영상, 스트림, 프로그램, 저장소 또는 페이지 제목
- 작성자, 채널, 크리에이터 또는 프로젝트 이름
- 재생 타임스탬프
- 플랫폼 에셋
- 콘텐츠로 돌아가는 버튼

## Nowly의 작동 방식

브라우저 확장 프로그램이 지원되는 웹사이트를 감지하고 설치된 프레즌스를 불러옵니다. 프레즌스는 Discord 활동 페이로드를 준비합니다.

데스크톱 앱은 브라우저와 Discord Desktop을 잇는 로컬 다리 역할을 합니다. 확장 프로그램으로부터 활동 데이터를 받아 내 컴퓨터의 Discord로 전송합니다.

## 시작하기

다음 순서로 설정을 진행하세요.

1. 확장 프로그램을 설치합니다.
2. 사용자 스크립트를 활성화합니다.
3. 데스크톱 앱을 설치합니다.
4. Discord Desktop을 엽니다.
5. 프레즌스를 설치합니다.
6. YouTube 같은 호환 사이트에서 테스트합니다.

무언가 빠져 있다면 확장 프로그램의 사이드 패널을 여세요. 진단 기능이 각 점검 항목을 개별적으로 보여주므로 무엇을 고쳐야 할지 정확히 알 수 있습니다.
