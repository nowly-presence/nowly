## Nowlyとは?

Nowlyは、対応サイトでのアクティビティをDiscord Rich Presenceに表示します。使用するのは次の3つです。

- Chrome、Chromium、Brave、Edge用のNowlyブラウザ拡張機能
- WindowsまたはLinux用のデスクトップアプリ
- Nowlyライブラリからインストールできるプレゼンス

## プレゼンスとは?

プレゼンスは、1つのサイト向けの小さなJavaScript連携機能です。対応URLにアクセスすると実行され、ページ上での操作を読み取り、アクティビティデータを拡張機能に送信します。

プレゼンスが表示できるもの:

- プラットフォーム名
- 現在の動画、配信、番組、リポジトリ、またはページタイトル
- 作者、チャンネル、クリエイター、プロジェクト名
- 再生タイムスタンプ
- プラットフォームのアセット
- コンテンツへ戻るボタン

## Nowlyの仕組み

ブラウザ拡張機能が対応サイトを検出し、インストール済みのプレゼンスを読み込みます。プレゼンスがDiscordのアクティビティ情報を準備します。

デスクトップアプリは、ブラウザとDiscord Desktopをつなぐローカルの橋渡し役です。拡張機能からアクティビティデータを受け取り、あなたのPC上のDiscordへ送信します。

## はじめの一歩

次の順番でセットアップしてください。

1. 拡張機能をインストールする。
2. ユーザースクリプトを有効にする。
3. デスクトップアプリをインストールする。
4. Discord Desktopを開く。
5. プレゼンスをインストールする。
6. YouTubeなど対応サイトでテストする。

何か不足している場合は、拡張機能のサイドパネルを開いてください。診断機能が各チェック項目を個別に表示するので、何を直せばよいか正確にわかります。
