## Nowlyとは？

Nowlyは、サイトで見ているもの、聴いているもの、閲覧しているものをDiscord Rich Presenceとして表示します。Rich Presenceとは名前の下に表示されるカードのことで、タイトル、アートワーク、プログレスバー、場合によってはボタンが表示されます。無料で、アカウントも必要ありません。

Nowlyは次の3つの要素で構成されています。

- **ブラウザ拡張機能**: Chrome、Edge、Brave、OperaなどのChromium系ブラウザと、Firefoxに対応しています。ブラウザのサイドパネルで動作します。
- **デスクトップアプリ**: Windows、macOS、Linuxに対応しています。Discordアプリへのローカルな橋渡し役で、拡張機能ではNowly Desktopと呼ばれます。
- **プレゼンス**: [ライブラリ](/library)からインストールします。YouTube、Netflix、Twitch、Spotifyなど、サイトごとに1つずつある小さなスクリプトです。

## プレゼンスとは？

プレゼンスは、1つのサイト向けに書かれたスクリプトです。そのプレゼンスに指定されたアドレスでのみ動作し、ページから必要な情報を読み取って、Discordに表示するアクティビティを準備します。公式プレゼンスはすべて公開前にレビューと署名を受けており、拡張機能は実行前にその署名を検証します。

サイトに応じて、プレゼンスは次の内容を表示できます。

- プラットフォーム名とアクティビティの種類(視聴中、再生中、プレイ中)
- 動画、エピソード、曲、配信、ページのタイトル
- チャンネル、アーティスト、エピソード番号などの2行目
- 再生中または一時停止中のバッジが付いたアートワークやサムネイル
- 経過時間、または残り時間付きのプログレスバー
- フレンドが同じページを開けるボタン(最大2つ)

多くのプレゼンスには、閲覧中のアクティビティを表示する設定や、タイトルを隠すプライバシーモードなどの設定もあります。

## 仕組み

1. 対応ページを開きます。対応するプレゼンスが、ブラウザのタブ内でそのページを読み取ります。
2. 拡張機能が設定(一時停止、スケジュール、非表示のタブ、言語)を適用します。
3. 拡張機能が、ネイティブメッセージングを通じてPC上のデスクトップアプリにアクティビティを送信します。
4. デスクトップアプリが、Discordのローカル接続を通じてDiscordアプリにアクティビティを渡します。
5. Discordがプロフィールにアクティビティを表示します。

アクティビティがNowlyのサーバーを経由することはありません。ブラウザのタブで開いたDiscordやスマートフォンのDiscordでは受け取れないため、同じPC上でDiscordデスクトップアプリを起動しておく必要があります。

## まずはここから

1. [インストール](/getting-started/installation)の手順に沿って、拡張機能、ユーザースクリプト、デスクトップアプリ、Discordを準備します。
2. [プレゼンスのインストール](/getting-started/installing-presences)の説明に従って、最初のプレゼンスをインストールします。
3. 表示されない項目がある場合は、[トラブルシューティング](/getting-started/troubleshooting)を順に確認します。

サイトを追加したいですか？[プレゼンス開発](/presence-development/prerequisites)セクションでは、独自のプレゼンスを作成、テスト、公開する方法を説明しています。
