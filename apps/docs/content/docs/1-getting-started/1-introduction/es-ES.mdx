## ¿Qué es Nowly?

Nowly muestra lo que ves, escuchas o consultas en sitios web como Rich Presence de Discord: la tarjeta bajo tu nombre con un título, una imagen, una barra de progreso y, a veces, un botón. Es gratis y no necesitas cuenta.

Nowly se compone de tres piezas:

- **La extensión del navegador**, para Chrome, Edge, Brave, Opera y otros navegadores Chromium, y para Firefox. Se abre en el panel lateral del navegador.
- **La app de escritorio**, para Windows, macOS y Linux. Es el puente local hacia la app de Discord. La extensión la llama Nowly Desktop.
- **Las presencias**, que se instalan desde la [biblioteca](/library): un pequeño script por sitio web, como YouTube, Netflix, Twitch o Spotify.

## ¿Qué es una presencia?

Una presencia es un script escrito para un sitio web concreto. Solo se ejecuta en las direcciones previstas para ella, lee de la página lo que necesita y prepara la actividad que mostrará Discord. Cada presencia oficial se revisa y se firma antes de publicarse, y la extensión comprueba esa firma antes de ejecutarla.

Según el sitio, una presencia puede mostrar:

- el nombre de la plataforma y el tipo de actividad (viendo, escuchando, jugando),
- el título del vídeo, episodio, canción, directo o página,
- una segunda línea, como el canal, el artista o el número de episodio,
- una imagen o una miniatura, con una insignia de reproducción o pausa,
- el tiempo transcurrido o una barra de progreso con el tiempo restante,
- hasta dos botones para que tus amigos abran la misma página.

La mayoría de las presencias también tienen ajustes, como mostrar la actividad mientras navegas o un modo privado que oculta los títulos.

## Cómo funciona

1. Abres una página compatible. La presencia correspondiente la lee en la pestaña de tu navegador.
2. La extensión aplica tus ajustes: pausa, horarios, pestañas ocultas, idioma.
3. Envía la actividad a la app de escritorio de tu ordenador mediante Native Messaging.
4. La app de escritorio se la pasa a la app de Discord a través de la conexión local de Discord.
5. Discord la muestra en tu perfil.

La actividad nunca pasa por los servidores de Nowly. Discord en una pestaña del navegador o en un móvil no puede recibirla: la app de escritorio de Discord tiene que estar abierta en el mismo ordenador.

1. Sigue la [Instalación](/getting-started/installation): extensión, scripts de usuario, app de escritorio, Discord.

3. Si algo se queda vacío, revisa la [Solución de problemas](/getting-started/troubleshooting).
