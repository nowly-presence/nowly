## ¿Qué es Nowly?

Nowly muestra la actividad de sitios compatibles en Discord Rich Presence. La experiencia usa tres elementos visibles:

- la extensión Nowly para Chrome, Chromium, Brave y Edge
- Nowly Host en Windows o Linux
- presencias instalables desde la biblioteca de Nowly

## ¿Qué es una presencia?

Una presencia es una pequeña integración JavaScript para un sitio web concreto. Se ejecuta cuando visitas una URL compatible, lee el estado útil de la página y envía la actividad a la extensión.

Una presencia puede mostrar:

- el nombre de la plataforma
- el vídeo, directo, programa, repositorio o título de página actual
- nombres del autor, canal, creador o proyecto
- marcas de tiempo de reproducción
- recursos de la plataforma
- botones que enlazan al contenido

## Cómo funciona Nowly

La extensión detecta sitios compatibles y carga tus presencias instaladas. La presencia prepara el payload de actividad compatible con Discord.

Nowly Host es el puente local entre el navegador y Discord Desktop. Recibe los datos de actividad de la extensión y los envía a Discord localmente.

## Primeros pasos

Sigue el flujo en este orden:

1. Instalar la extensión.
2. Activar los scripts de usuario.
3. Instalar Nowly Host.
4. Abrir Discord Desktop.
5. Instalar una presencia.
6. Probar en un sitio compatible, por ejemplo YouTube.

Si falta algo, abre el panel lateral de la extensión. El diagnóstico muestra cada enlace por separado para saber exactamente qué corregir.
