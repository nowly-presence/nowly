## What is Nowly?

Nowly shows activity from supported websites in Discord Rich Presence. You will use three parts:

- the Nowly browser extension for Chrome, Chromium, Brave, and Edge
- the desktop app on Windows or Linux
- installable presences from the Nowly library

## What is a Presence?

A presence is a small JavaScript integration for one website. It runs when you visit a supported URL, reads what you are doing on the page, and sends activity data to the extension.

Presences can display:

- the platform name
- the current video, stream, show, repository, or page title
- author, channel, creator, or project names
- playback timestamps
- platform assets
- buttons that link back to content

## How Nowly Works

The browser extension detects supported websites and loads your installed presences. A presence prepares the Discord activity payload.

The desktop app is the local bridge between the browser and Discord Desktop. It receives activity data from the extension and sends it to Discord on your machine.

## Start Here

Follow setup in this order:

1. Install the extension.
2. Enable user scripts.
3. Install the desktop app.
4. Open Discord Desktop.
5. Install a presence.
6. Test on a compatible site, such as YouTube.

If anything is missing, open the extension side panel. The diagnostic lists each check on its own, so you can see exactly what to fix.
