## O que é o Nowly?

O Nowly exibe a atividade de sites compatíveis no Discord Rich Presence. Você vai usar três partes:

- a extensão Nowly para Chrome, Chromium, Brave e Edge
- o app de desktop no Windows ou Linux
- presenças instaláveis da biblioteca Nowly

## O que é uma presença?

Uma presença é uma pequena integração em JavaScript para um site. Ela é executada quando você visita uma URL compatível, lê o que você está fazendo na página e envia os dados de atividade para a extensão.

As presenças podem exibir:

- o nome da plataforma
- o vídeo, transmissão, programa, repositório ou título de página atual
- nomes de autor, canal, criador ou projeto
- marcações de tempo de reprodução
- recursos visuais da plataforma
- botões que levam de volta ao conteúdo

## Como o Nowly funciona

A extensão do navegador detecta sites compatíveis e carrega suas presenças instaladas. Uma presença prepara os dados de atividade do Discord.

O app de desktop é a ponte local entre o navegador e o Discord Desktop. Ele recebe os dados de atividade da extensão e os envia ao Discord na sua máquina.

## Comece por aqui

Siga a configuração nesta ordem:

1. Instale a extensão.
2. Ative os scripts de usuário.
3. Instale o app de desktop.
4. Abra o Discord Desktop.
5. Instale uma presença.
6. Teste em um site compatível, como o YouTube.

Se algo estiver faltando, abra o painel lateral da extensão. O diagnóstico lista cada verificação separadamente, para que você veja exatamente o que corrigir.
