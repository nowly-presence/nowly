## Was ist Nowly?

Nowly zeigt Aktivitäten von unterstützten Websites in Discord Rich Presence an. Du brauchst dafür drei Teile:

- die Nowly-Browser-Erweiterung für Chrome, Chromium, Brave und Edge
- die Desktop-App für Windows oder Linux
- installierbare Presences aus der Nowly-Bibliothek

## Was ist eine Presence?

Eine Presence ist eine kleine JavaScript-Integration für eine Website. Sie wird ausgeführt, wenn du eine unterstützte URL besuchst, liest, was du auf der Seite tust, und sendet die Aktivitätsdaten an die Erweiterung.

Presences können Folgendes anzeigen:

- den Plattformnamen
- das aktuelle Video, den Stream, die Sendung, das Repository oder den Seitentitel
- Namen von Autor, Kanal, Ersteller oder Projekt
- Wiedergabe-Zeitstempel
- Plattform-Assets
- Buttons, die zum Inhalt zurückführen

## Wie Nowly funktioniert

Die Browser-Erweiterung erkennt unterstützte Websites und lädt deine installierten Presences. Eine Presence bereitet die Discord-Activity-Payload vor.

Die Desktop-App ist die lokale Brücke zwischen dem Browser und Discord Desktop. Sie empfängt Aktivitätsdaten von der Erweiterung und sendet sie auf deinem Rechner an Discord.

## Hier starten

Folge der Einrichtung in dieser Reihenfolge:

1. Erweiterung installieren.
2. Benutzerskripte aktivieren.
3. Desktop-App installieren.
4. Discord Desktop öffnen.
5. Eine Presence installieren.
6. Auf einer kompatiblen Seite testen, z. B. YouTube.

Falls etwas fehlt, öffne das Seitenpanel der Erweiterung. Die Diagnose listet jede Prüfung einzeln auf, sodass du genau siehst, was zu beheben ist.
