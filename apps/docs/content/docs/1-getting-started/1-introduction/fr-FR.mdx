## Qu'est-ce que Nowly ?

Nowly affiche ce que vous regardez, écoutez ou consultez sur des sites web sous forme de Rich Presence Discord : la carte sous votre pseudo avec un titre, une image, une barre de progression et parfois un bouton. C'est gratuit, et aucun compte n'est nécessaire.

Nowly se compose de trois éléments :

- **L'extension de navigateur**, pour Chrome, Edge, Brave, Opera et les autres navigateurs Chromium, et pour Firefox. Elle s'ouvre dans le panneau latéral du navigateur.
- **L'application de bureau**, pour Windows, macOS et Linux. C'est le pont local vers l'application Discord. L'extension l'appelle Nowly Desktop.
- **Les présences**, installées depuis la [bibliothèque](/library) : un petit script par site, comme YouTube, Netflix, Twitch ou Spotify.

## Qu'est-ce qu'une présence ?

Une présence est un script écrit pour un site. Elle ne s'exécute que sur les adresses prévues pour elle, lit ce dont elle a besoin dans la page et prépare l'activité que Discord affichera. Chaque présence officielle est relue et signée avant sa publication, et l'extension vérifie cette signature avant de l'exécuter.

Selon le site, une présence peut afficher :

- le nom de la plateforme et le type d'activité (regarde, écoute, joue),
- le titre de la vidéo, de l'épisode, du morceau, du live ou de la page,
- une deuxième ligne comme la chaîne, l'artiste ou le numéro d'épisode,
- une image ou une miniature, avec un badge lecture ou pause,
- le temps écoulé, ou une barre de progression avec le temps restant,
- jusqu'à deux boutons qui permettent à vos amis d'ouvrir la même page.

La plupart des présences ont aussi des réglages, comme afficher l'activité pendant la navigation ou un mode privé qui masque les titres.

## Comment ça marche

1. Vous ouvrez une page prise en charge. La présence correspondante la lit dans votre onglet.
2. L'extension applique vos réglages : pause, horaires, onglets masqués, langue.
3. Elle envoie l'activité à l'application de bureau de votre ordinateur par le native messaging.
4. L'application de bureau la transmet à l'application Discord par la connexion locale de Discord.
5. Discord l'affiche sur votre profil.

L'activité ne passe jamais par les serveurs de Nowly. Discord dans un onglet ou sur un téléphone ne peut pas la recevoir : l'application Discord doit tourner sur le même ordinateur.

## Par où commencer

1. Suivez l'[Installation](/getting-started/installation) : extension, scripts utilisateur, application de bureau, Discord.
2. Installez une première présence, comme décrit dans [Installation des présences](/getting-started/installing-presences).
3. Si rien ne s'affiche, suivez le [Dépannage](/getting-started/troubleshooting).

Vous voulez ajouter un site ? La section [Développement de présences](/presence-development/prerequisites) explique comment écrire, tester et publier votre propre présence.
