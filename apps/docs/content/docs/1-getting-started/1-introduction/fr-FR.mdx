## Qu'est-ce que Nowly ?

Nowly affiche l'activité des sites compatibles dans Discord Rich Presence. L'expérience repose sur trois éléments visibles :

- l'extension Nowly pour Chrome, Chromium, Brave et Edge
- Nowly Host sur Windows ou Linux
- des présences installables depuis la bibliothèque Nowly

## Qu'est-ce qu'une présence ?

Une présence est une petite intégration JavaScript pour un site web précis. Elle s'exécute lorsque vous visitez une URL compatible, lit l'état utile de la page et envoie l'activité à l'extension.

Une présence peut afficher :

- le nom de la plateforme
- la vidéo, le stream, l'émission, le repository ou le titre de page en cours
- les noms de l'auteur, de la chaîne, du créateur ou du projet
- les timestamps de lecture
- les assets de la plateforme
- des boutons qui renvoient vers le contenu

## Comment fonctionne Nowly

L'extension détecte les sites compatibles et charge vos présences installées. La présence prépare le payload d'activité compatible avec Discord.

Nowly Host est le pont local entre le navigateur et Discord Desktop. Il reçoit les données d'activité de l'extension et les envoie à Discord localement.

## Commencer

Suivez le flow dans cet ordre :

1. Installer l'extension.
2. Activer les scripts utilisateur.
3. Installer Nowly Host.
4. Ouvrir Discord Desktop.
5. Installer une présence.
6. Tester sur un site compatible, par exemple YouTube.

Si un élément manque, ouvrez le panneau latéral de l'extension. Le diagnostic affiche chaque maillon séparément pour savoir exactement quoi corriger.
