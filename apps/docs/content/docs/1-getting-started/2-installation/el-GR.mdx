## Απαιτήσεις

Πριν ξεκινήσεις, χρειάζεσαι:

- Chrome, Chromium, Brave ή Edge
- Discord Desktop
- Windows ή Linux για την εφαρμογή υπολογιστή

## 1. Εγκατέστησε την Επέκταση

Εγκατέστησε την επέκταση Nowly από το Chrome Web Store. Μετά την εγκατάσταση, ανανέωσε τυχόν ανοιχτές σελίδες Nowly ώστε ο ιστότοπος να εντοπίσει την επέκταση.

## 2. Ενεργοποίησε τα Scripts Χρήστη

Άνοιξε τη σελίδα λεπτομερειών της επέκτασης στον browser σου και ενεργοποίησε τα scripts χρήστη για το Nowly. Αυτή η άδεια επιτρέπει στο Nowly να εκτελεί τα εγκατεστημένα presences σε συμβατούς ιστότοπους.

Στο πλαϊνό πλαίσιο της επέκτασης, η γραμμή διάγνωσης **Τα scripts χρήστη είναι ενεργά** θα πρέπει να γίνει πράσινη.

## 3. Εγκατέστησε την εφαρμογή υπολογιστή

Κατέβασε την εφαρμογή υπολογιστή από τη [σελίδα εφαρμογής υπολογιστή](https://nowly.me/desktop).

- Windows: χρησιμοποίησε πρώτα το πρόγραμμα εγκατάστασης. Το φορητό zip είναι για προχωρημένες ή χειροκίνητες ρυθμίσεις.
- Linux: σε Debian, Ubuntu ή Mint, εγκατέστησε το πακέτο `.deb` (`sudo dpkg -i nowly-host.deb`). Σε άλλες διανομές, κατέβασε το αρχείο `.tar.gz` και ακολούθησε το συμπεριλαμβανόμενο script εγκατάστασης.

Εγκατέστησε την εφαρμογή υπολογιστή στον ίδιο υπολογιστή με το Discord Desktop.

## 4. Άνοιξε το Discord Desktop

Ξεκίνα το Discord Desktop πριν δοκιμάσεις. Το Discord στον browser δεν αρκεί: το Rich Presence στέλνεται στον τοπικό client του Discord Desktop.

Η επέκταση χειρίζεται αυτές τις δύο περιπτώσεις ξεχωριστά:

- **Η εφαρμογή υπολογιστή δεν εντοπίστηκε.** Εγκατέστησε την εφαρμογή υπολογιστή και μετά κάνε κλικ στο **Έλεγχος σύνδεσης**.
- **Η εφαρμογή υπολογιστή είναι εγκατεστημένη αλλά το Discord Desktop δεν είναι ανοιχτό.** Άνοιξε το Discord Desktop και μετά κάνε κλικ στο **Έλεγχος σύνδεσης**.

## 5. Εγκατέστησε ένα Presence

Άνοιξε το [presence του YouTube](/library/youtube) και κάνε κλικ στο **Εγκατάσταση**. Το YouTube είναι η καλύτερη πρώτη δοκιμή επειδή επαληθεύεται γρήγορα.

## 6. Δοκίμασε στο YouTube

Άνοιξε το [YouTube](https://youtube.com) και μετά το πλαϊνό πλαίσιο της επέκτασης. Η γραμμή **Εντοπίστηκε δραστηριότητα** θα πρέπει να γίνει πράσινη και το Discord θα πρέπει να εμφανίσει τη δραστηριότητά σου.

## Έλεγξε ότι Όλα Λειτουργούν

Χρησιμοποίησε αυτή τη λίστα ελέγχου στη διάγνωση της επέκτασης:

- Η επέκταση εγκαταστάθηκε
- Τα scripts χρήστη είναι ενεργά
- Εντοπίστηκε η εφαρμογή υπολογιστή
- Το Discord συνδέθηκε
- Το presence εγκαταστάθηκε
- Εντοπίστηκε δραστηριότητα

Όταν και οι έξι γραμμές είναι πράσινες, το Nowly είναι έτοιμο για καθημερινή χρήση.
