## Requisitos

Antes de começar, você precisa de:

- Chrome, Chromium, Brave ou Edge
- Discord Desktop
- Windows ou Linux para o app de desktop

## 1. Instale a extensão

Instale a extensão Nowly na Chrome Web Store. Após a instalação, recarregue qualquer página do Nowly aberta para que o site consiga detectar a extensão.

## 2. Ative os scripts de usuário

Abra a página de detalhes da extensão no seu navegador e ative os scripts de usuário para o Nowly. Essa permissão permite que o Nowly execute as presenças instaladas em sites compatíveis.

No painel lateral da extensão, a linha de diagnóstico **Scripts de usuário ativos** deve ficar verde.

## 3. Instale o app de desktop

Baixe o app de desktop na [página do app de desktop](https://nowly.me/desktop).

- Windows: use primeiro o instalador. O zip portátil é para configurações avançadas ou manuais.
- Linux: no Debian, Ubuntu ou Mint, instale o pacote `.deb` (`sudo dpkg -i nowly-host.deb`). Em outras distros, baixe o arquivo `.tar.gz` e siga o script de instalação incluído.

Instale o app de desktop na mesma máquina em que está o Discord Desktop.

## 4. Abra o Discord Desktop

Inicie o Discord Desktop antes de testar. O Discord no navegador não é suficiente: o Rich Presence é enviado ao cliente local do Discord Desktop.

A extensão trata esses dois casos separadamente:

- **O app de desktop não foi detectado.** Instale o app de desktop e clique em **Verificar conexão**.
- **O app de desktop está instalado, mas o Discord Desktop não está aberto.** Abra o Discord Desktop e clique em **Verificar conexão**.

## 5. Instale uma presença

Abra a [presença do YouTube](/library/youtube) e clique em **Instalar**. O YouTube é o melhor primeiro teste porque é rápido de verificar.

## 6. Teste no YouTube

Abra o [YouTube](https://youtube.com) e, em seguida, o painel lateral da extensão. A linha **Atividade detectada** deve ficar verde, e o Discord deve exibir sua atividade.

## Verifique se tudo está funcionando

Use esta lista de verificação no diagnóstico da extensão:

- Extensão instalada
- Scripts de usuário ativos
- App de desktop detectado
- Discord conectado
- Presença instalada
- Atividade detectada

Quando as seis linhas estiverem verdes, o Nowly está pronto para o uso diário.
