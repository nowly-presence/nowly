title: Instalação

## Requisitos

- **Sistema**: Windows 10 ou 11, macOS 11 Big Sur ou mais recente, ou Linux 64 bits (glibc 2.17 ou mais recente).
- **Navegador**: Chrome, Edge, Brave, Opera ou outro navegador Chromium, ou Firefox.
- **Discord**: o app de desktop do Discord, instalado e com login feito, no mesmo computador.

## 1. Instale a extensão

Instale o Nowly pela Chrome Web Store (Chrome, Edge, Brave, Opera) ou pelo Firefox Add-ons. A [página da extensão](https://nowly.me/extension) leva à loja certa para o seu navegador.

Abra o painel lateral pelo ícone da barra de ferramentas ou com **Ctrl+Shift+Y** (**Cmd+Shift+Y** no macOS). Na primeira execução, uma breve introdução mostra os mesmos passos desta página.

## 2. Permita os scripts de usuário

As presenças rodam como scripts de usuário, então o navegador pede sua permissão uma vez.

- **Navegadores Chromium**: abra a página de extensões (`chrome://extensions`, `edge://extensions`, `brave://extensions` ou `opera://extensions`), clique em **Detalhes** no Nowly e ative **Permitir scripts de usuário**. Em versões antigas do Chrome, ative em vez disso o **Modo do desenvolvedor**, no canto superior direito da página.
- **Firefox**: aceite o pedido de permissão exibido durante a introdução. Se você o dispensou, permita os scripts de usuário em `about:addons`, Nowly, **Permissões**.

No diagnóstico do painel lateral, **Scripts de usuário permitidos** fica verde.

## 3. Instale o app de desktop

Baixe-o na [página do app de desktop](https://nowly.me/desktop), que detecta seu sistema.

- **Windows**: execute o instalador. O build ainda não é assinado com um certificado comercial, então o SmartScreen pode exibir um aviso: escolha **Mais informações** e depois **Executar assim mesmo**, somente para um arquivo baixado de nowly.me. Existe um zip portátil para configurações manuais.
- **macOS**: abra a imagem de disco. O app é notarizado pela Apple.
- **Linux**: no Debian, Ubuntu ou Mint, instale o pacote `.deb` (`sudo dpkg -i nowly-host.deb` em um terminal se o clique duplo não fizer nada). Em outras distribuições, extraia o arquivo `.tar.gz` e execute o script de instalação que ele contém.

O app de desktop não tem janela. O navegador o inicia quando o Nowly precisa dele. Reinicie o navegador depois de instalá-lo.

## 4. Abra o Discord

Inicie o app de desktop do Discord. Nas **Configurações de usuário** do Discord, em **Activity Privacy**, verifique se o compartilhamento da sua atividade atual está ativado. Com o status **Invisível**, ninguém vê sua atividade.

A extensão diferencia dois casos:

- **O Nowly Desktop não foi encontrado**: instale o app de desktop e clique em **Verificar conexão**.
- **O Nowly Desktop foi encontrado, mas o Discord não está conectado**: abra o app do Discord e clique em **Verificar conexão**.

## 5. Instale uma presença

Abra a [presença do YouTube](/library/youtube) e clique em **Instalar**, ou instale-a pela aba **Biblioteca** do painel lateral. O YouTube é o primeiro teste mais rápido.

## 6. Teste

Abra um vídeo no YouTube e dê play. Seu perfil do Discord deve mostrar **Assistindo YouTube** com o título do vídeo, o canal e uma barra de progresso.

## Verifique se tudo funciona

O diagnóstico do painel lateral lista seis verificações. Quando todas estiverem verdes, o Nowly está pronto:

- Extensão instalada
- Scripts de usuário permitidos
- Nowly Desktop encontrado
- Discord conectado
- Uma presença está instalada
- Atividade detectada

A primeira linha que não estiver verde é a próxima coisa a corrigir. Veja [Solução de problemas](/getting-started/troubleshooting).
