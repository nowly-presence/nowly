## Keperluan

Sebelum anda mula, anda memerlukan:

- Chrome, Chromium, Brave atau Edge
- Discord Desktop
- Windows atau Linux untuk aplikasi desktop

## 1. Pasang Sambungan

Pasang sambungan Nowly daripada Chrome Web Store. Selepas pemasangan, muat semula mana-mana halaman Nowly yang terbuka supaya laman web dapat mengesan sambungan tersebut.

## 2. Dayakan Skrip Pengguna

Buka halaman butiran sambungan dalam pelayar anda dan dayakan skrip pengguna untuk Nowly. Kebenaran ini membolehkan Nowly menjalankan presence yang dipasang pada laman web yang serasi.

Dalam panel sisi sambungan, baris diagnostik **Skrip pengguna aktif** sepatutnya bertukar hijau.

## 3. Pasang aplikasi desktop

Muat turun aplikasi desktop daripada [halaman aplikasi desktop](https://nowly.me/desktop).

- Windows: gunakan pemasang dahulu. Zip mudah alih adalah untuk persediaan lanjutan atau manual.
- Linux: pada Debian, Ubuntu atau Mint, pasang pakej `.deb` (`sudo dpkg -i nowly-host.deb`). Pada distro lain, muat turun arkib `.tar.gz` dan ikut skrip pemasangan yang disertakan.

Pasang aplikasi desktop pada komputer yang sama dengan Discord Desktop.

## 4. Buka Discord Desktop

Mulakan Discord Desktop sebelum anda menguji. Discord dalam pelayar tidak mencukupi: Rich Presence dihantar kepada klien Discord Desktop tempatan.

Sambungan mengendalikan kedua-dua kes ini secara berasingan:

- **Aplikasi desktop tidak dikesan.** Pasang aplikasi desktop, kemudian klik **Semak sambungan**.
- **Aplikasi desktop dipasang tetapi Discord Desktop tidak dibuka.** Buka Discord Desktop, kemudian klik **Semak sambungan**.

## 5. Pasang Presence

Buka [presence YouTube](/library/youtube) dan klik **Pasang**. YouTube adalah ujian pertama terbaik kerana ia cepat untuk disahkan.

## 6. Uji pada YouTube

Buka [YouTube](https://youtube.com), kemudian buka panel sisi sambungan. Baris **Aktiviti dikesan** sepatutnya bertukar hijau, dan Discord sepatutnya memaparkan aktiviti anda.

## Semak Semuanya Berfungsi

Gunakan senarai semak ini dalam diagnostik sambungan:

- Sambungan dipasang
- Skrip pengguna aktif
- Aplikasi desktop dikesan
- Discord disambungkan
- Presence dipasang
- Aktiviti dikesan

Apabila keenam-enam baris hijau, Nowly sedia untuk kegunaan harian.
