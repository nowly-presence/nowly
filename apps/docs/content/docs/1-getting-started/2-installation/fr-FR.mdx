## Prérequis

- **Système** : Windows 10 ou 11, macOS 11 Big Sur ou plus récent, ou Linux 64 bits (glibc 2.17 ou plus récente).
- **Navigateur** : Chrome, Edge, Brave, Opera ou un autre navigateur Chromium, ou Firefox.
- **Discord** : l'application Discord pour ordinateur, installée et connectée, sur le même ordinateur.

## 1. Installer l'extension

Installez Nowly depuis le Chrome Web Store (Chrome, Edge, Brave, Opera) ou depuis les modules complémentaires Firefox. La [page de l'extension](https://nowly.me/fr/extension) mène à la bonne boutique pour votre navigateur.

Ouvrez le panneau latéral avec l'icône de la barre d'outils ou **Ctrl+Maj+Y** (**Cmd+Maj+Y** sur macOS). Au premier lancement, une courte présentation reprend les mêmes étapes que cette page.

## 2. Autoriser les scripts utilisateur

Les présences s'exécutent comme des scripts utilisateur : le navigateur demande donc votre accord une fois.

- **Navigateurs Chromium** : ouvrez la page des extensions (`chrome://extensions`, `edge://extensions`, `brave://extensions` ou `opera://extensions`), cliquez sur **Détails** pour Nowly et activez **Autoriser les scripts utilisateur**. Sur les anciennes versions de Chrome, activez plutôt le **Mode développeur** en haut à droite de la page.
- **Firefox** : acceptez la demande d'autorisation affichée pendant la présentation. Si vous l'avez refusée, autorisez les scripts utilisateur depuis `about:addons`, Nowly, **Permissions**.

Dans le diagnostic du panneau latéral, **Scripts utilisateur autorisés** passe au vert.

## 3. Installer l'application de bureau

Téléchargez-la depuis la [page de l'application de bureau](https://nowly.me/fr/desktop), qui détecte votre système.

- **Windows** : lancez l'installateur. L'application n'est pas encore signée avec un certificat commercial, SmartScreen peut donc afficher un avertissement : choisissez **Informations complémentaires**, puis **Exécuter quand même**, uniquement pour un fichier téléchargé sur nowly.me. Une archive zip portable existe pour les installations manuelles.
- **macOS** : ouvrez l'image disque. L'application est notarisée par Apple.
- **Linux** : sur Debian, Ubuntu ou Mint, installez le paquet `.deb` (`sudo dpkg -i nowly-host.deb` dans un terminal si le double-clic ne fait rien). Sur les autres distributions, décompressez l'archive `.tar.gz` et lancez le script d'installation qu'elle contient.

L'application de bureau n'a pas de fenêtre. Le navigateur la lance quand Nowly en a besoin. Redémarrez le navigateur après l'avoir installée.

## 4. Ouvrir Discord

Lancez l'application Discord. Dans les **Paramètres utilisateur** de Discord, **Confidentialité des activités**, vérifiez que le partage de votre activité actuelle est activé. En statut **Invisible**, personne ne voit votre activité.

L'extension distingue deux cas :

- **Nowly Desktop n'est pas détecté** : installez l'application de bureau, puis cliquez sur **Vérifier la connexion**.
- **Nowly Desktop est détecté mais Discord n'est pas connecté** : ouvrez l'application Discord, puis cliquez sur **Vérifier la connexion**.

## 5. Installer une présence

Ouvrez la [présence YouTube](/library/youtube) et cliquez sur **Installer**, ou installez-la depuis l'onglet **Bibliothèque** du panneau latéral. YouTube est le test le plus rapide.

## 6. Tester

Ouvrez une vidéo sur YouTube et lancez la lecture. Votre profil Discord doit afficher **Regarde YouTube** avec le titre de la vidéo, la chaîne et une barre de progression.

## Vérifier que tout fonctionne

Le diagnostic du panneau latéral affiche six vérifications. Quand elles sont toutes vertes, Nowly est prêt :

- Extension installée
- Scripts utilisateur autorisés
- Nowly Desktop détecté
- Discord connecté
- Une présence est installée
- Activité détectée

La première ligne qui n'est pas verte est la prochaine chose à corriger. Voir le [Dépannage](/getting-started/troubleshooting).
