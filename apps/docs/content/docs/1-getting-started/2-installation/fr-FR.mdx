## Prérequis

Avant de commencer, assurez-vous d'avoir :

- Chrome, Chromium, Brave ou Edge
- Discord Desktop installé
- Windows ou Linux pour Nowly Host

## 1. Installer l'extension

Installez l'extension Nowly depuis le Chrome Web Store. Après l'installation, rechargez les pages Nowly ouvertes afin que le site puisse détecter l'extension.

## 2. Activer les scripts utilisateur

Ouvrez la page de détails de l'extension dans votre navigateur et activez les scripts utilisateur pour Nowly. Cette autorisation permet à Nowly d'exécuter les présences installées sur les sites compatibles.

Dans le panneau latéral de l'extension, la ligne **Scripts utilisateur actifs** doit passer au vert.

## 3. Installer Nowly Host

Téléchargez Nowly Host depuis la [page Nowly Host](/host).

- Windows : utilisez d'abord l'installateur. Le zip portable est disponible pour les installations avancées ou manuelles.
- Linux : téléchargez l'archive `.tar.gz` et suivez le script d'installation inclus.

Nowly Host doit être installé sur le même ordinateur que Discord Desktop.

## 4. Ouvrir Discord Desktop

Lancez Discord Desktop avant de tester. Discord dans le navigateur ne suffit pas : Rich Presence est envoyé au client Discord Desktop local.

L'extension distingue ces deux cas :

- **Nowly Host n'est pas détecté.** Installez Nowly Host, puis cliquez sur **Vérifier la connexion**.
- **Nowly Host est installé mais Discord Desktop n'est pas ouvert.** Ouvrez Discord Desktop, puis cliquez sur **Vérifier la connexion**.

## 5. Installer une présence

Ouvrez la [présence YouTube](/library/youtube) et cliquez sur **Installer**. YouTube est le premier test recommandé, car il se vérifie rapidement.

## 6. Tester sur YouTube

Ouvrez [YouTube](https://youtube.com), puis ouvrez le panneau latéral de l'extension. La ligne **Activité détectée** doit passer au vert, et Discord doit afficher votre activité.

## Vérifier que tout fonctionne

Utilisez cette checklist dans le diagnostic de l'extension :

- Extension installée
- Scripts utilisateur actifs
- Nowly Host détecté
- Discord connecté
- Présence installée
- Activité détectée

Lorsque les six lignes sont vertes, Nowly est prêt pour un usage quotidien.
