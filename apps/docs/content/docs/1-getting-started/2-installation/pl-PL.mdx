## Wymagania

Zanim zaczniesz, potrzebujesz:

- Chrome, Chromium, Brave lub Edge
- Discord Desktop
- Windows lub Linux dla aplikacji desktopowej

## 1. Zainstaluj rozszerzenie

Zainstaluj rozszerzenie Nowly ze sklepu Chrome Web Store. Po instalacji odśwież wszystkie otwarte strony Nowly, aby witryna mogła wykryć rozszerzenie.

## 2. Włącz skrypty użytkownika

Otwórz stronę szczegółów rozszerzenia w przeglądarce i włącz skrypty użytkownika dla Nowly. To uprawnienie pozwala Nowly uruchamiać zainstalowane obecności na zgodnych stronach.

W panelu bocznym rozszerzenia wiersz diagnostyczny **Skrypty użytkownika aktywne** powinien zmienić kolor na zielony.

## 3. Zainstaluj aplikację desktopową

Pobierz aplikację desktopową ze [strony aplikacji desktopowej](https://nowly.me/desktop).

- Windows: najpierw użyj instalatora. Przenośny plik zip jest przeznaczony do zaawansowanych lub ręcznych konfiguracji.
- Linux: w systemach Debian, Ubuntu lub Mint zainstaluj pakiet `.deb` (`sudo dpkg -i nowly-host.deb`). W innych dystrybucjach pobierz archiwum `.tar.gz` i postępuj zgodnie z dołączonym skryptem instalacyjnym.

Zainstaluj aplikację desktopową na tym samym komputerze co Discord Desktop.

## 4. Otwórz Discord Desktop

Uruchom Discord Desktop przed testowaniem. Discord w przeglądarce nie wystarczy: Rich Presence jest wysyłane do lokalnego klienta Discord Desktop.

Rozszerzenie obsługuje te dwa przypadki osobno:

- **Aplikacja desktopowa nie została wykryta.** Zainstaluj aplikację desktopową, a następnie kliknij **Sprawdź połączenie**.
- **Aplikacja desktopowa jest zainstalowana, ale Discord Desktop nie jest otwarty.** Otwórz Discord Desktop, a następnie kliknij **Sprawdź połączenie**.

## 5. Zainstaluj obecność

Otwórz [obecność YouTube](/library/youtube) i kliknij **Zainstaluj**. YouTube to najlepszy pierwszy test, ponieważ szybko można go zweryfikować.

## 6. Przetestuj na YouTube

Otwórz [YouTube](https://youtube.com), a następnie panel boczny rozszerzenia. Wiersz **Wykryto aktywność** powinien zmienić kolor na zielony, a Discord powinien wyświetlić Twoją aktywność.

## Sprawdź, czy wszystko działa

Skorzystaj z tej listy kontrolnej w diagnostyce rozszerzenia:

- Rozszerzenie zainstalowane
- Skrypty użytkownika aktywne
- Wykryto aplikację desktopową
- Discord połączony
- Obecność zainstalowana
- Wykryto aktywność

Gdy wszystkie sześć wierszy będzie zielonych, Nowly jest gotowe do codziennego użytku.
