## Voraussetzungen

- **System**: Windows 10 oder 11, macOS 11 Big Sur oder neuer oder 64-Bit-Linux (glibc 2.17 oder neuer).
- **Browser**: Chrome, Edge, Brave, Opera oder ein anderer Chromium-Browser oder Firefox.
- **Discord**: die Discord-Desktop-App, installiert und angemeldet, auf demselben Computer.

## 1. Erweiterung installieren

Installiere Nowly aus dem Chrome Web Store (Chrome, Edge, Brave, Opera) oder bei Firefox Add-ons. Die [Erweiterungsseite](https://nowly.me/extension) verlinkt den passenden Store für deinen Browser.

Öffne das Seitenpanel über das Symbol in der Symbolleiste oder mit **Ctrl+Shift+Y** (**Cmd+Shift+Y** unter macOS). Beim ersten Start zeigt Nowly ein kurzes Onboarding mit denselben Schritten wie auf dieser Seite.

## 2. Benutzerskripte erlauben

Presences laufen als Benutzerskripte, deshalb fragt der Browser einmalig nach deiner Erlaubnis.

- **Chromium-Browser**: Öffne die Erweiterungsseite (`chrome://extensions`, `edge://extensions`, `brave://extensions` oder `opera://extensions`), klicke bei Nowly auf **Details** und aktiviere **Benutzerskripte zulassen**. In älteren Chrome-Versionen aktivierst du stattdessen den **Entwicklermodus** oben rechts auf der Seite.
- **Firefox**: Akzeptiere die Berechtigungsanfrage, die während des Onboardings erscheint. Falls du sie geschlossen hast, erlaube die Berechtigung für Benutzerskripte über `about:addons`, Nowly, **Berechtigungen**.

In der Diagnose im Seitenpanel wird **Benutzerskripte erlaubt** grün.

## 3. Desktop-App installieren

Lade sie von der [Desktop-App-Seite](https://nowly.me/desktop) herunter, die dein System erkennt.

- **Windows**: Führe das Installationsprogramm aus. Der Build ist noch nicht mit einem kommerziellen Zertifikat signiert, daher kann SmartScreen eine Warnung anzeigen: Wähle **Weitere Informationen** und dann **Trotzdem ausführen**, aber nur bei einer Datei, die du von nowly.me heruntergeladen hast. Für manuelle Einrichtungen gibt es ein portables ZIP-Archiv.
- **macOS**: Öffne das Disk-Image. Die App ist von Apple notarisiert.
- **Linux**: Installiere unter Debian, Ubuntu oder Mint das `.deb`-Paket (`sudo dpkg -i nowly-host.deb` in einem Terminal, falls ein Doppelklick nichts bewirkt). Entpacke bei anderen Distributionen das `.tar.gz`-Archiv und führe das darin enthaltene Installationsskript aus.

Die Desktop-App hat kein Fenster. Der Browser startet sie, wenn Nowly sie braucht. Starte den Browser nach der Installation neu.

## 4. Discord öffnen

Starte die Discord-Desktop-App. Stelle in den **Benutzereinstellungen** von Discord unter **Activity Privacy** sicher, dass das Teilen deiner aktuellen Aktivität aktiviert ist. Im Status **Unsichtbar** sieht niemand deine Aktivität.

Die Erweiterung unterscheidet zwei Fälle:

- **Nowly Desktop wird nicht gefunden**: Installiere die Desktop-App und klicke dann auf **Verbindung prüfen**.
- **Nowly Desktop wird gefunden, aber Discord ist nicht verbunden**: Öffne die Discord-App und klicke dann auf **Verbindung prüfen**.

## 5. Eine Presence installieren

Öffne die [YouTube-Presence](/library/youtube) und klicke auf **Installieren**, oder installiere sie im Tab **Bibliothek** des Seitenpanels. YouTube ist der schnellste erste Test.

## 6. Testen

Öffne ein Video auf YouTube und starte die Wiedergabe. Dein Discord-Profil sollte **Schaut YouTube** mit dem Videotitel, dem Kanal und einem Fortschrittsbalken anzeigen.

## Prüfen, ob alles funktioniert

Die Diagnose im Seitenpanel listet sechs Prüfungen auf. Wenn alle grün sind, ist Nowly bereit:

- Erweiterung installiert
- Benutzerskripte erlaubt
- Nowly Desktop gefunden
- Discord verbunden
- Eine Präsenz ist installiert
- Aktivität erkannt

Die erste Zeile, die nicht grün ist, ist das Nächste, was du beheben musst. Siehe [Fehlerbehebung](/getting-started/troubleshooting).
