## Voraussetzungen

Bevor du beginnst, benötigst du:

- Chrome, Chromium, Brave oder Edge
- Discord Desktop
- Windows oder Linux für die Desktop-App

## 1. Erweiterung installieren

Installiere die Nowly-Erweiterung aus dem Chrome Web Store. Lade nach der Installation alle geöffneten Nowly-Seiten neu, damit die Website die Erweiterung erkennen kann.

## 2. Benutzerskripte aktivieren

Öffne die Details-Seite der Erweiterung in deinem Browser und aktiviere Benutzerskripte für Nowly. Diese Berechtigung ermöglicht es Nowly, installierte Presences auf kompatiblen Websites auszuführen.

Im Seitenpanel der Erweiterung sollte die Diagnosezeile **Benutzerskripte aktiv** grün werden.

## 3. Desktop-App installieren

Lade die Desktop-App von der [Desktop-App-Seite](https://nowly.me/desktop) herunter.

- Windows: Verwende zuerst das Installationsprogramm. Das portable ZIP-Archiv ist für fortgeschrittene oder manuelle Einrichtungen gedacht.
- Linux: Installiere unter Debian, Ubuntu oder Mint das `.deb`-Paket (`sudo dpkg -i nowly-host.deb`). Lade bei anderen Distributionen das `.tar.gz`-Archiv herunter und folge dem enthaltenen Installationsskript.

Installiere die Desktop-App auf demselben Rechner wie Discord Desktop.

## 4. Discord Desktop öffnen

Starte Discord Desktop, bevor du testest. Discord im Browser reicht nicht aus: Rich Presence wird an den lokalen Discord-Desktop-Client gesendet.

Die Erweiterung behandelt diese beiden Fälle getrennt:

- **Die Desktop-App wird nicht erkannt.** Installiere die Desktop-App und klicke dann auf **Verbindung prüfen**.
- **Die Desktop-App ist installiert, aber Discord Desktop ist nicht geöffnet.** Öffne Discord Desktop und klicke dann auf **Verbindung prüfen**.

## 5. Eine Presence installieren

Öffne die [YouTube-Presence](/library/youtube) und klicke auf **Installieren**. YouTube eignet sich am besten für den ersten Test, weil es schnell zu überprüfen ist.

## 6. Auf YouTube testen

Öffne [YouTube](https://youtube.com) und dann das Seitenpanel der Erweiterung. Die Zeile **Aktivität erkannt** sollte grün werden, und Discord sollte deine Aktivität anzeigen.

## Prüfen, ob alles funktioniert

Verwende diese Checkliste in der Erweiterungsdiagnose:

- Erweiterung installiert
- Benutzerskripte aktiv
- Desktop-App erkannt
- Discord verbunden
- Presence installiert
- Aktivität erkannt

Wenn alle sechs Zeilen grün sind, ist Nowly bereit für den täglichen Gebrauch.
