## 必要なもの

- **OS**: Windows 10または11、macOS 11 Big Sur以降、または64ビットLinux(glibc 2.17以降)。
- **ブラウザ**: Chrome、Edge、Brave、OperaなどのChromium系ブラウザ、またはFirefox。
- **Discord**: 同じPCにインストールされ、ログイン済みのDiscordデスクトップアプリ。

## 1. 拡張機能をインストールする

Chrome ウェブストア(Chrome、Edge、Brave、Opera)またはFirefox Add-onsからNowlyをインストールします。[拡張機能ページ](https://nowly.me/extension)から、お使いのブラウザに合ったストアに移動できます。

ツールバーのアイコン、または**Ctrl+Shift+Y**(macOSでは**Cmd+Shift+Y**)でサイドパネルを開きます。初回起動時には、このページと同じ手順を案内する短いオンボーディングが表示されます。

## 2. ユーザースクリプトを許可する

プレゼンスはユーザースクリプトとして動作するため、ブラウザから一度だけ許可を求められます。

- **Chromium系ブラウザ**: 拡張機能ページ(`chrome://extensions`、`edge://extensions`、`brave://extensions`、`opera://extensions`)を開き、Nowlyの**詳細**をクリックして、**ユーザー スクリプトを許可する**をオンにします。古いバージョンのChromeでは、代わりにページ右上の**デベロッパー モード**をオンにします。
- **Firefox**: オンボーディング中に表示される許可のプロンプトを承認します。閉じてしまった場合は、`about:addons`、Nowly、**Permissions**の順に開き、ユーザースクリプトの権限を許可します。

サイドパネルの診断で、**ユーザースクリプトが許可済み**が緑色になります。

## 3. デスクトップアプリをインストールする

お使いのシステムを自動で判別する[デスクトップアプリページ](https://nowly.me/desktop)からダウンロードします。

- **Windows**: インストーラーを実行します。現時点では商用証明書で署名されていないため、SmartScreenの警告が表示されることがあります。nowly.meからダウンロードしたファイルに限り、**詳細情報**、**実行**の順に選択してください。手動セットアップ用にポータブル版のzipも用意されています。
- **macOS**: ディスクイメージを開きます。アプリはAppleの公証を受けています。
- **Linux**: Debian、Ubuntu、Mintでは`.deb`パッケージをインストールします(ダブルクリックしても何も起きない場合は、ターミナルで`sudo dpkg -i nowly-host.deb`を実行します)。その他のディストリビューションでは、`.tar.gz`アーカイブを展開し、同梱のインストールスクリプトを実行します。

デスクトップアプリにはウィンドウがありません。Nowlyが必要とするときにブラウザが起動します。インストール後はブラウザを再起動してください。

## 4. Discordを開く

Discordデスクトップアプリを起動します。Discordの**ユーザー設定**にある**アクティビティのプライバシー**で、現在のアクティビティを共有する設定がオンになっていることを確認します。ステータスが**オフライン表示**の場合、アクティビティは誰にも表示されません。

拡張機能は次の2つのケースを区別します。

- **Nowly Desktopが検出されない**: デスクトップアプリをインストールし、**接続を確認**をクリックします。
- **Nowly Desktopは検出されたが、Discordに接続されていない**: Discordアプリを開き、**接続を確認**をクリックします。

## 5. プレゼンスをインストールする

[YouTubeプレゼンス](/library/youtube)を開いて**インストール**をクリックするか、サイドパネルの**ライブラリ**タブからインストールします。最初のテストにはYouTubeが最も手軽です。

## 6. テストする

YouTubeで動画を開いて再生します。Discordのプロフィールに、動画のタイトル、チャンネル、プログレスバーとともに**YouTubeを視聴中**と表示されるはずです。

## すべて正常に動作しているか確認する

サイドパネルの診断には6つのチェック項目があります。すべて緑色になれば、Nowlyの準備は完了です。

- 拡張機能がインストール済み
- ユーザースクリプトが許可済み
- Nowly Desktop を検出
- Discord に接続済み
- プレゼンスがインストール済み
- アクティビティを検出

緑色になっていない最初の項目が、次に直すべき箇所です。[トラブルシューティング](/getting-started/troubleshooting)を参照してください。
