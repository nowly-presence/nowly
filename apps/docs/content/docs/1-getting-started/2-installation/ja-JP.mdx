---

## 必要なもの

始める前に、以下が必要です。

- Chrome、Chromium、Brave、またはEdge
- Discord Desktop
- デスクトップアプリ用のWindowsまたはLinux

## 1. 拡張機能をインストールする

Chromeウェブストアから Nowly 拡張機能をインストールします。インストール後、開いているNowlyのページを再読み込みして、サイトが拡張機能を検出できるようにしてください。

## 2. ユーザースクリプトを有効にする

ブラウザで拡張機能の詳細ページを開き、Nowlyのユーザースクリプトを有効にします。この権限により、Nowlyは対応サイト上でインストール済みのプレゼンスを実行できるようになります。

拡張機能のサイドパネルで、診断項目の**ユーザースクリプトが有効**が緑色になるはずです。

## 3. デスクトップアプリをインストールする

[デスクトップアプリページ](https://nowly.me/desktop)からデスクトップアプリをダウンロードします。

- Windows: まずインストーラーを使用してください。ポータブルZIPは上級者向けや手動セットアップ用です。
- Linux: Debian、Ubuntu、Mintでは `.deb` パッケージをインストールしてください(`sudo dpkg -i nowly-host.deb`)。他のディストリビューションでは `.tar.gz` アーカイブをダウンロードし、同梱のインストールスクリプトに従ってください。

デスクトップアプリはDiscord Desktopと同じマシンにインストールしてください。

## 4. Discord Desktopを開く

テストする前にDiscord Desktopを起動してください。ブラウザ版のDiscordだけでは不十分です。Rich Presenceはローカルの Discord Desktop クライアントに送信されます。

拡張機能はこの2つのケースを別々に扱います。

- **デスクトップアプリが検出されない場合。** デスクトップアプリをインストールし、**接続を確認**をクリックしてください。
- **デスクトップアプリはインストール済みだがDiscord Desktopが開いていない場合。** Discord Desktopを開き、**接続を確認**をクリックしてください。

## 5. プレゼンスをインストールする

[YouTubeプレゼンス](/library/youtube)を開き、**インストール**をクリックします。YouTubeはすぐに確認できるため、最初のテストに最適です。

## 6. YouTubeでテストする

[YouTube](https://youtube.com)を開き、次に拡張機能のサイドパネルを開きます。**アクティビティを検出**の行が緑色になり、Discordにあなたのアクティビティが表示されるはずです。

## すべて正常に動作しているか確認する

拡張機能の診断で、次のチェックリストを確認してください。

- 拡張機能がインストール済み
- ユーザースクリプトが有効
- デスクトップアプリを検出
- Discordに接続済み
- プレゼンスがインストール済み
- アクティビティを検出

6つすべての項目が緑色になれば、Nowlyは日常的に使用できる状態です。
