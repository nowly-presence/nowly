## Requirements

Before starting, make sure you have:

- Chrome, Chromium, Brave, or Edge
- Discord Desktop installed
- Windows or Linux for Nowly Host

## 1. Install the Extension

Install the Nowly extension from the Chrome Web Store. After installation, reload any open Nowly pages so the website can detect the extension.

## 2. Enable User Scripts

Open the extension details page in your browser and enable user scripts for Nowly. This permission lets Nowly run installed presences on compatible websites.

In the extension side panel, the diagnostic row **User scripts active** should turn green.

## 3. Install Nowly Host

Download Nowly Host from the [Nowly Host page](/host).

- Windows: use the installer first. The portable zip is available for advanced/manual setups.
- Linux: download the `.tar.gz` archive and follow the included install script.

Nowly Host must be installed on the same machine as Discord Desktop.

## 4. Open Discord Desktop

Start Discord Desktop before testing. Browser Discord is not enough because Rich Presence is sent to the local Discord Desktop client.

The extension distinguishes these two cases:

- **Nowly Host is not detected.** Install Nowly Host, then click **Check connection**.
- **Nowly Host is installed but Discord Desktop is not open.** Open Discord Desktop, then click **Check connection**.

## 5. Install a Presence

Open the [YouTube presence](/library/youtube) and click **Install**. YouTube is the recommended first test because it is quick to verify.

## 6. Test on YouTube

Open [YouTube](https://youtube.com), then open the extension side panel. The row **Activity detected** should turn green, and Discord should show your activity.

## Check That Everything Works

Use this checklist in the extension diagnostic:

- Extension installed
- User scripts active
- Nowly Host detected
- Discord connected
- Presence installed
- Activity detected

When all six rows are green, Nowly is ready for everyday use.
