## Gereksinimler

Başlamadan önce şunlara ihtiyacınız var:

- Chrome, Chromium, Brave veya Edge
- Discord Desktop
- Masaüstü uygulaması için Windows veya Linux

## 1. Uzantıyı Kurun

Nowly uzantısını Chrome Web Mağazası'ndan kurun. Kurulumdan sonra, sitenin uzantıyı algılayabilmesi için açık olan Nowly sayfalarını yeniden yükleyin.

## 2. Kullanıcı Komut Dosyalarını Etkinleştirin

Tarayıcınızda uzantı ayrıntıları sayfasını açın ve Nowly için kullanıcı komut dosyalarını etkinleştirin. Bu izin, Nowly'nin uyumlu web sitelerinde kurulu presence'ları çalıştırmasını sağlar.

Uzantının yan panelinde **Kullanıcı komut dosyaları etkin** tanılama satırı yeşile dönmelidir.

## 3. Masaüstü Uygulamasını Kurun

Masaüstü uygulamasını [masaüstü uygulaması sayfasından](https://nowly.me/desktop) indirin.

- Windows: Önce yükleyiciyi kullanın. Taşınabilir zip, gelişmiş veya manuel kurulumlar içindir.
- Linux: Debian, Ubuntu veya Mint'te `.deb` paketini kurun (`sudo dpkg -i nowly-host.deb`). Diğer dağıtımlarda `.tar.gz` arşivini indirin ve birlikte gelen kurulum betiğini izleyin.

Masaüstü uygulamasını Discord Desktop ile aynı makineye kurun.

## 4. Discord Desktop'ı Açın

Test etmeden önce Discord Desktop'ı başlatın. Tarayıcıdaki Discord yeterli değildir: Rich Presence, yerel Discord Desktop istemcisine gönderilir.

Uzantı bu iki durumu ayrı ayrı ele alır:

- **Masaüstü uygulaması algılanmadı.** Masaüstü uygulamasını kurun, ardından **Bağlantıyı kontrol et**'e tıklayın.
- **Masaüstü uygulaması kurulu ama Discord Desktop açık değil.** Discord Desktop'ı açın, ardından **Bağlantıyı kontrol et**'e tıklayın.

## 5. Bir Presence Kurun

[YouTube presence'ını](/library/youtube) açın ve **Kur**'a tıklayın. YouTube, hızlıca doğrulanabildiği için en iyi ilk testtir.

## 6. YouTube'da Test Edin

[YouTube'u](https://youtube.com) açın, ardından uzantının yan panelini açın. **Etkinlik algılandı** satırı yeşile dönmeli ve Discord etkinliğinizi göstermelidir.

## Her Şeyin Çalıştığını Kontrol Edin

Uzantı tanılamasında şu kontrol listesini kullanın:

- Uzantı kuruldu
- Kullanıcı komut dosyaları etkin
- Masaüstü uygulaması algılandı
- Discord bağlandı
- Presence kuruldu
- Etkinlik algılandı

Altı satırın tamamı yeşil olduğunda Nowly günlük kullanıma hazırdır.
