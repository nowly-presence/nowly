## Requisitos

Antes de empezar, necesitas:

- Chrome, Chromium, Brave o Edge
- Discord Desktop
- Windows o Linux para la app de escritorio

## 1. Instalar la extensión

Instala la extensión Nowly desde Chrome Web Store. Después de instalarla, recarga las páginas de Nowly abiertas para que el sitio pueda detectar la extensión.

## 2. Activar los scripts de usuario

Abre la página de detalles de la extensión en tu navegador y activa los scripts de usuario para Nowly. Este permiso permite que Nowly ejecute presencias instaladas en sitios compatibles.

En el panel lateral de la extensión, la línea **Scripts de usuario activos** debería ponerse en verde.

## 3. Instalar la app de escritorio

Descarga la app de escritorio desde la [página de la app de escritorio](https://nowly.me/desktop).

- Windows: usa primero el instalador. El zip portable es para instalaciones avanzadas o manuales.
- Linux: en Debian, Ubuntu o Mint, instala el paquete `.deb` (`sudo dpkg -i nowly-host.deb`). En otras distribuciones, descarga el archivo `.tar.gz` y sigue el script de instalación incluido.

Instala la app de escritorio en el mismo equipo que Discord Desktop.

## 4. Abrir Discord Desktop

Abre Discord Desktop antes de probar. Discord en el navegador no es suficiente: Rich Presence se envía al cliente local de Discord Desktop.

La extensión distingue estos dos casos:

- **la app de escritorio no está detectada.** Instala la app de escritorio y haz clic en **Comprobar conexión**.
- **la app de escritorio está instalada pero Discord Desktop no está abierto.** Abre Discord Desktop y haz clic en **Comprobar conexión**.

## 5. Instalar una presencia

Abre la [presencia de YouTube](/library/youtube) y haz clic en **Instalar**. YouTube es la mejor primera prueba porque se verifica rápido.

## 6. Probar en YouTube

Abre [YouTube](https://youtube.com) y luego abre el panel lateral de la extensión. La línea **Actividad detectada** debería ponerse en verde, y Discord debería mostrar tu actividad.

## Verificar que todo funciona

Usa esta lista en el diagnóstico de la extensión:

- Extensión instalada
- Scripts de usuario activos
- la app de escritorio detectado
- Discord conectado
- Presencia instalada
- Actividad detectada

Cuando las seis líneas están en verde, Nowly está listo para el uso diario.
