## 요구 사항

시작하기 전에 다음이 필요합니다.

- Chrome, Chromium, Brave 또는 Edge
- Discord Desktop
- 데스크톱 앱용 Windows 또는 Linux

## 1. 확장 프로그램 설치

Chrome 웹 스토어에서 Nowly 확장 프로그램을 설치합니다. 설치 후 열려 있는 Nowly 페이지를 새로고침하여 사이트가 확장 프로그램을 감지할 수 있도록 하세요.

## 2. 사용자 스크립트 활성화

브라우저에서 확장 프로그램 세부정보 페이지를 열고 Nowly의 사용자 스크립트를 활성화합니다. 이 권한을 통해 Nowly가 호환 웹사이트에서 설치된 프레즌스를 실행할 수 있습니다.

확장 프로그램의 사이드 패널에서 **사용자 스크립트 활성** 진단 항목이 녹색으로 표시되어야 합니다.

## 3. 데스크톱 앱 설치

[데스크톱 앱 페이지](https://nowly.me/desktop)에서 데스크톱 앱을 다운로드합니다.

- Windows: 먼저 설치 프로그램을 사용하세요. 휴대용 zip 파일은 고급 또는 수동 설정용입니다.
- Linux: Debian, Ubuntu, Mint에서는 `.deb` 패키지를 설치하세요(`sudo dpkg -i nowly-host.deb`). 다른 배포판에서는 `.tar.gz` 압축 파일을 다운로드하고 포함된 설치 스크립트를 따르세요.

데스크톱 앱은 Discord Desktop과 같은 컴퓨터에 설치하세요.

## 4. Discord Desktop 열기

테스트하기 전에 Discord Desktop을 실행하세요. 브라우저의 Discord만으로는 충분하지 않습니다. Rich Presence는 로컬 Discord Desktop 클라이언트로 전송됩니다.

확장 프로그램은 다음 두 가지 경우를 별도로 처리합니다.

- **데스크톱 앱이 감지되지 않는 경우.** 데스크톱 앱을 설치한 다음 **연결 확인**을 클릭하세요.
- **데스크톱 앱은 설치되어 있지만 Discord Desktop이 열려 있지 않은 경우.** Discord Desktop을 연 다음 **연결 확인**을 클릭하세요.

## 5. 프레즌스 설치

[YouTube 프레즌스](/library/youtube)를 열고 **설치**를 클릭하세요. YouTube는 빠르게 확인할 수 있어 첫 테스트로 가장 적합합니다.

## 6. YouTube에서 테스트

[YouTube](https://youtube.com)를 연 다음 확장 프로그램의 사이드 패널을 여세요. **활동 감지됨** 행이 녹색으로 표시되고 Discord에 활동이 표시되어야 합니다.

## 모든 것이 작동하는지 확인

확장 프로그램 진단에서 다음 체크리스트를 사용하세요.

- 확장 프로그램 설치됨
- 사용자 스크립트 활성
- 데스크톱 앱 감지됨
- Discord 연결됨
- 프레즌스 설치됨
- 활동 감지됨

여섯 항목이 모두 녹색이면 Nowly를 일상적으로 사용할 준비가 된 것입니다.
