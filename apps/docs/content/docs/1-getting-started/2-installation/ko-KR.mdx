## 요구 사항

- **시스템**: Windows 10 또는 11, macOS 11 Big Sur 이상, 또는 64비트 Linux(glibc 2.17 이상).
- **브라우저**: Chrome, Edge, Brave, Opera 또는 기타 Chromium 기반 브라우저, 또는 Firefox.
- **Discord**: 같은 컴퓨터에 설치되어 로그인된 Discord 데스크톱 앱.

## 1. 확장 프로그램 설치

Chrome 웹 스토어(Chrome, Edge, Brave, Opera) 또는 Firefox 부가 기능에서 Nowly를 설치하세요. [확장 프로그램 페이지](https://nowly.me/extension)에서 사용 중인 브라우저에 맞는 스토어로 이동할 수 있습니다.

툴바 아이콘이나 **Ctrl+Shift+Y**(macOS에서는 **Cmd+Shift+Y**)로 사이드 패널을 여세요. 처음 실행하면 이 페이지와 같은 단계를 안내하는 짧은 온보딩이 표시됩니다.

## 2. 사용자 스크립트 허용

프레즌스는 사용자 스크립트로 실행되므로 브라우저가 한 번 권한을 요청합니다.

- **Chromium 기반 브라우저**: 확장 프로그램 페이지(`chrome://extensions`, `edge://extensions`, `brave://extensions` 또는 `opera://extensions`)를 열고 Nowly의 **세부정보**를 클릭한 다음 **사용자 스크립트 허용**을 켜세요. 이전 버전의 Chrome에서는 대신 페이지 오른쪽 상단의 **개발자 모드**를 켜세요.
- **Firefox**: 온보딩 중에 표시되는 권한 요청을 수락하세요. 요청을 닫았다면 `about:addons`, Nowly, **권한**에서 사용자 스크립트 권한을 허용하세요.

사이드 패널 진단에서 **사용자 스크립트 허용됨**이 녹색으로 바뀝니다.

## 3. 데스크톱 앱 설치

시스템을 자동으로 감지하는 [데스크톱 앱 페이지](https://nowly.me/desktop)에서 다운로드하세요.

- **Windows**: 설치 프로그램을 실행하세요. 아직 상용 인증서로 서명되지 않아 SmartScreen 경고가 표시될 수 있습니다. nowly.me에서 다운로드한 파일인 경우에만 **추가 정보**를 선택한 다음 **실행**을 선택하세요. 수동 설정용 휴대용 zip 파일도 있습니다.
- **macOS**: 디스크 이미지를 여세요. 앱은 Apple의 공증을 받았습니다.
- **Linux**: Debian, Ubuntu, Mint에서는 `.deb` 패키지를 설치하세요(더블클릭해도 아무 일도 일어나지 않으면 터미널에서 `sudo dpkg -i nowly-host.deb`를 실행하세요). 다른 배포판에서는 `.tar.gz` 압축 파일을 풀고 안에 있는 설치 스크립트를 실행하세요.

데스크톱 앱에는 창이 없습니다. Nowly가 필요할 때 브라우저가 앱을 실행합니다. 설치한 후에는 브라우저를 다시 시작하세요.

## 4. Discord 열기

Discord 데스크톱 앱을 실행하세요. Discord의 **사용자 설정**에 있는 **활동 개인정보 보호**에서 현재 활동 공유가 켜져 있는지 확인하세요. 상태가 **오프라인 표시**이면 아무도 활동을 볼 수 없습니다.

확장 프로그램은 다음 두 가지 경우를 구분합니다.

- **Nowly Desktop이 감지되지 않음**: 데스크톱 앱을 설치한 다음 **연결 확인**을 클릭하세요.
- **Nowly Desktop은 감지되었지만 Discord가 연결되지 않음**: Discord 앱을 연 다음 **연결 확인**을 클릭하세요.

## 5. 프레즌스 설치

[YouTube 프레즌스](/library/youtube)를 열고 **설치**를 클릭하거나, 사이드 패널의 **라이브러리** 탭에서 설치하세요. YouTube가 가장 빠르게 첫 테스트를 할 수 있는 방법입니다.

## 6. 테스트

YouTube에서 동영상을 열고 재생하세요. Discord 프로필에 동영상 제목, 채널, 진행률 표시줄과 함께 **YouTube 시청 중**이 표시되어야 합니다.

## 모든 것이 작동하는지 확인

사이드 패널 진단에는 여섯 가지 점검 항목이 있습니다. 모두 녹색이면 Nowly를 사용할 준비가 된 것입니다.

- 확장 프로그램 설치됨
- 사용자 스크립트 허용됨
- Nowly Desktop 감지됨
- Discord 연결됨
- 프레즌스 설치됨
- 활동 감지됨

녹색이 아닌 첫 번째 항목이 다음에 해결해야 할 부분입니다. [문제 해결](/getting-started/troubleshooting)을 참고하세요.
