## Start With the Diagnostic

Open the extension side panel and read each row on its own:

- Extension installed
- User scripts active
- Desktop app detected
- Discord connected
- Presence installed
- Activity detected

Do not rely on a single global status. The missing row is the next thing to fix.

## Desktop app is not detected

Message shown: **The desktop app is not detected.**

Install the desktop app from the [desktop app page](https://nowly.me/desktop), then click **Check connection** in the extension. If you just installed it, close and reopen the extension side panel.

## Discord Desktop Is Closed

Message shown: **The desktop app is installed but Discord Desktop is not open.**

Open Discord Desktop, wait a few seconds, then click **Check connection**. Discord in the browser cannot receive local Rich Presence updates.

## No Presence Is Installed

Install a presence from the library. For the fastest test, install the [YouTube presence](/library/youtube), then open YouTube.

## No Activity Is Detected

Make sure:

- the matching presence is installed and enabled
- the current URL is supported by that presence
- user scripts are active
- the page was reloaded after you installed the presence

## URL Is Not Supported

Open the presence detail page and compare your current URL with the **Supported URLs** list. If the site changed its address or layout, report the presence from the support page.

## Permissions Are Missing

Open your browser extension settings and check:

- Nowly is enabled
- user scripts are allowed
- site access is allowed for the current site

After you change permissions, reload the website tab and reopen the extension side panel.

## Discord IPC: "Access is denied"

Runtime logs may show:

```text
reason=open \\.\pipe\discord-ipc-0: Access is denied.
```

For integrations, use the stable native response code `DISCORD_IPC_ACCESS_DENIED` instead of matching this localized log text.

This means the desktop app can reach the host, but Windows is refusing access to Discord's local IPC pipe. The most common cause is Discord being started with **Run as administrator** while the browser and Nowly Host run normally.

Fix it in this order:

1. Quit Discord completely, including its notification-area icon.
2. In Task Manager, close any remaining `Discord.exe` processes.
3. Open Discord's properties and disable **Run this program as an administrator** under **Compatibility**.
4. Start Discord normally.
5. Restart the browser or click **Reconnect** in Nowly.

Do not run the browser or Nowly as administrator as a workaround. Native messaging is launched by the browser, and forcing an elevated host would require an unsafe privileged relay. Nowly Host can show a native notification when it detects this permission mismatch: a Windows tray notification, macOS Notification Center notification, or Linux desktop notification when `notify-send` is available.

If the diagnostics page looks healthy but the log contains this error, clear the runtime logs and reproduce the problem. The diagnostics can reflect the native host connection while Discord's IPC connection is still denied.

## Linux: "Update Available" After Installing the .deb

Message shown: **update available**, even though the `.deb` package was just installed.

Two common causes, check them in order:

1. **The `.deb` was never actually installed.** On some desktop environments (XFCE with Thunar, for example), double-clicking a `.deb` does nothing if no graphical package manager is associated with it (like GDebi). Install it from a terminal instead:

   ```bash
   sudo dpkg -i ~/Downloads/nowly-host.deb
   ```

   Then confirm it is registered: `dpkg -L nowly-host` should list `/usr/lib/nowly-client/nowly-host`.

2. **An old per-user manifest is overriding the one from the .deb.** If you previously installed the desktop app from the `.tar.gz` archive (the `install-linux.sh` script) before switching to the `.deb`, a leftover manifest in your home directory can still point to the old binary. Remove it:

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   Then fully restart the browser (not just the extension) so it relaunches the native process with the updated binary.

The extension diagnostic includes a **Copy support** button. It copies the state of the desktop app, Discord, presences, and activity without exposing technical logs.
