## まず診断から始める

拡張機能のサイドパネルを開き、各項目を個別に確認してください。

- 拡張機能がインストール済み
- ユーザースクリプトが有効
- デスクトップアプリを検出
- Discordに接続済み
- プレゼンスがインストール済み
- アクティビティを検出

単一の全体ステータスに頼らないでください。欠けている項目こそ、次に直すべきものです。

## デスクトップアプリが検出されない

表示されるメッセージ: **デスクトップアプリが検出されません。**

[デスクトップアプリページ](https://nowly.me/desktop)からデスクトップアプリをインストールし、拡張機能で**接続を確認**をクリックしてください。インストールしたばかりの場合は、拡張機能のサイドパネルを閉じて再度開いてください。

## Discord Desktopが閉じている

表示されるメッセージ: **デスクトップアプリはインストール済みですが、Discord Desktopが開いていません。**

Discord Desktopを開き、数秒待ってから**接続を確認**をクリックしてください。ブラウザ版のDiscordではローカルのRich Presence更新を受信できません。

## プレゼンスがインストールされていない

ライブラリからプレゼンスをインストールしてください。最も早くテストするには、[YouTubeプレゼンス](/library/youtube)をインストールし、YouTubeを開いてください。

## アクティビティが検出されない

次を確認してください。

- 対応するプレゼンスがインストールされ、有効になっている
- 現在のURLがそのプレゼンスに対応している
- ユーザースクリプトが有効になっている
- プレゼンスをインストールした後にページが再読み込みされている

## URLが対応していない

プレゼンスの詳細ページを開き、現在のURLを**対応URL**の一覧と比較してください。サイトのアドレスやレイアウトが変更された場合は、サポートページからそのプレゼンスを報告してください。

## 権限が不足している

ブラウザの拡張機能設定を開き、次を確認してください。

- Nowlyが有効になっている
- ユーザースクリプトが許可されている
- 現在のサイトへのアクセスが許可されている

権限を変更した後は、サイトのタブを再読み込みし、拡張機能のサイドパネルを開き直してください。

## Linux: .debインストール後に「アップデートあり」と表示される

表示されるメッセージ: `.deb` パッケージをインストールしたばかりなのに**アップデートあり**と表示される。

よくある原因は2つあります。順番に確認してください。

1. **`.deb` が実際にはインストールされていない。** 一部のデスクトップ環境(例: Thunarを使用するXFCE)では、GDebiのようなグラフィカルなパッケージマネージャーが関連付けられていない場合、`.deb` をダブルクリックしても何も起こりません。代わりにターミナルからインストールしてください。

   ```bash
   sudo dpkg -i ~/Downloads/nowly-host.deb
   ```

   その後、登録されていることを確認します。`dpkg -L nowly-host` を実行すると `/usr/lib/nowly-client/nowly-host` が表示されるはずです。

2. **古いユーザー単位のマニフェストが .deb のものを上書きしている。** `.deb` に切り替える前に `.tar.gz` アーカイブ(`install-linux.sh` スクリプト)からデスクトップアプリをインストールしたことがある場合、ホームディレクトリに残ったマニフェストが古いバイナリを指したままになっている可能性があります。以下を削除してください。

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   その後、ブラウザを(拡張機能だけでなく)完全に再起動し、更新されたバイナリでネイティブプロセスを再起動させてください。

## サポート用診断情報をコピーする

拡張機能の診断には**サポート情報をコピー**ボタンがあります。技術的なログを公開することなく、デスクトップアプリ、Discord、プレゼンス、アクティビティの状態をコピーします。
