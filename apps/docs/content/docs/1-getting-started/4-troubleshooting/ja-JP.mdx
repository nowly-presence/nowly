## まず診断を確認する

共有したいタブでサイドパネルを開き、各項目を1つずつ確認します。

- 拡張機能がインストール済み
- ユーザースクリプトが許可済み
- Nowly Desktop を検出
- Discord に接続済み
- プレゼンスがインストール済み
- アクティビティを検出

緑色になっていない最初の項目が、次に直すべき箇所です。

## Nowly Desktopが検出されない

[デスクトップアプリページ](https://nowly.me/desktop)からデスクトップアプリをインストールし、**接続を確認**をクリックします。インストールした直後の場合は、ブラウザがアプリを見つけられるようにブラウザを再起動してください。アプリはブラウザと同じPCにインストールする必要があります。

Linuxでは、FlatpakやSnapでインストールしたブラウザがネイティブメッセージングを完全にブロックすることがあります。ディストリビューションのリポジトリ、またはブラウザ提供元の公式パッケージからインストールしたブラウザを使用してください。

## Discordに接続されていない

Discordデスクトップアプリを開き、読み込みが終わるまで待ってから、**接続を確認**をクリックします。ブラウザのタブで開いたDiscordは、ローカルのRich Presenceを受け取れません。

Discord StableとDiscord PTBまたはCanaryを同時に使っている場合は、どれか1つだけを開いておいてください。Windowsでは、デスクトップアプリは最初に見つかったDiscordのパイプに接続します。

## Discord IPC:「Access is denied」(Windows)

実行ログに次のように表示されることがあります。

```text
reason=open \\.\pipe\discord-ipc-0: Access is denied.
```

連携機能では、このローカライズされたテキストではなく、安定したネイティブ応答コード`DISCORD_IPC_ACCESS_DENIED`を判定に使用してください。

Discordが管理者として実行されているのに、ブラウザとデスクトップアプリはそうではないため、WindowsがDiscordのローカルパイプへのアクセスを拒否しています。次の順番で解決してください。

1. 通知領域のアイコンも含めて、Discordを完全に終了します。
2. タスク マネージャーで、残っている`Discord.exe`プロセスをすべて終了します。
3. Discordのショートカットのプロパティで、**管理者としてこのプログラムを実行する**(互換性タブ)と**管理者として実行**(ショートカットタブの詳細設定)のチェックを外します。
4. Discordを通常どおり起動します。
5. Nowlyで**再接続**をクリックするか、ブラウザを再起動します。

代わりにブラウザやデスクトップアプリを管理者として実行することはしないでください。ネイティブメッセージングはブラウザによって起動されるため、管理者権限で動作するブラウザはセキュリティ上のリスクになります。デスクトップアプリはこの不一致を検出すると、システム通知を表示できます。Windowsでは通知領域の通知、macOSでは通知センターの通知、Linuxでは`notify-send`が利用できる場合に通知が表示されます。

## ユーザースクリプトが許可されていない

Nowlyの詳細ページで**ユーザー スクリプトを許可する**をオンにします(Chromium系ブラウザ)。古いバージョンのChromeでは**デベロッパー モード**をオンにします。Firefoxでは、`about:addons`からユーザースクリプトの権限を許可します。その後、タブを再読み込みし、サイドパネルを開き直してください。

## アクティビティが検出されない

次の点を確認してください。

- このサイトのプレゼンスがインストールされ、有効になっている
- 共有が一時停止されておらず(**Ctrl+Shift+U**で切り替え)、プレゼンスも一時停止中やスケジュール外になっていない
- タブがアクティビティタブで非表示になっていない
- 実際に何かが再生されている。ほとんどのプレゼンスは、**閲覧アクティビティを表示**がオンでない限り、閲覧中は何も表示しません
- アドレスが、ライブラリのページに記載されているプレゼンスの対応サイトと一致している
- プレゼンスのインストール後にタブを再読み込みしている

サイトの変更により、プレゼンスの表示内容が誤っている、または何も表示されない場合は、ライブラリのページで**問題を報告**を使用してください。

## 別のRich Presenceツールが干渉している

PreMiDや独自のRich Presenceを持つ音楽プレーヤーなど、Discordのアクティビティを設定する他のツールは、Nowlyが送信した内容を置き換えたり消去したりすることがあります。テスト中はそれらをオフにしてください。

## Linux: .debのインストール直後に「アップデートあり」と表示される

1. **`.deb`がインストールされていない。** 一部のデスクトップ環境(Thunarを使用するXFCEなど)では、`.deb`をダブルクリックしても何も起こりません。ターミナルからインストールしてください。

   ```bash
   sudo dpkg -i ~/Downloads/nowly-host.deb
   ```

   その後、`dpkg -L nowly-host`を実行すると`/usr/lib/nowly-client/nowly-host`が表示されるはずです。

2. **古いユーザー単位のインストールが優先されている。** 以前に`.tar.gz`アーカイブを使用していた場合は、その残りを削除してください。

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   その後、ブラウザを完全に終了してから、もう一度開いてください。

## Linux: FlatpakまたはSnapのDiscord

サンドボックス化されたDiscordは、独自のフォルダーにソケットを作成します。デスクトップアプリは、`$XDG_RUNTIME_DIR`、`$TMPDIR`、`/tmp`で`discord-ipc-0`から`discord-ipc-9`を探します。実際のソケットを想定される場所にリンクしてください。Flathubの場合の例は次のとおりです。

```bash
ln -sf "$XDG_RUNTIME_DIR/app/com.discordapp.Discord/discord-ipc-0" "$XDG_RUNTIME_DIR/discord-ipc-0"
```

再起動後も維持されるリンクの作り方やSnapのパスを含む詳しい手順は、[LinuxでのNowly](https://nowly.me/guides/nowly-on-linux)を参照してください。

## ログ

- 拡張機能は実行ログを保持しており、サイドパネルの**ログをコピー**でコピーできます。ログにはアクセスした対応ページのアドレスが含まれることがあるため、共有する前に内容を確認してください。
- デスクトップアプリは`nowly-host.log`を`%LOCALAPPDATA%\NowlyClient\`(Windows)、`~/Library/Caches/NowlyClient/`(macOS)、`~/.cache/NowlyClient/`(Linux)に書き込みます。

それでも解決しない場合は、NowlyのDiscordサーバーでチケットを作成し、失敗している診断項目とお使いのシステムを伝えてください。
