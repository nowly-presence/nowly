## 진단부터 시작하세요

확장 프로그램의 사이드 패널을 열고 각 항목을 개별적으로 확인하세요.

- 확장 프로그램 설치됨
- 사용자 스크립트 활성
- 데스크톱 앱 감지됨
- Discord 연결됨
- 프레즌스 설치됨
- 활동 감지됨

하나의 전체 상태에만 의존하지 마세요. 표시되지 않은 항목이 다음으로 고쳐야 할 부분입니다.

## 데스크톱 앱이 감지되지 않음

표시되는 메시지: **데스크톱 앱이 감지되지 않습니다.**

[데스크톱 앱 페이지](https://nowly.me/desktop)에서 데스크톱 앱을 설치한 다음 확장 프로그램에서 **연결 확인**을 클릭하세요. 방금 설치했다면 확장 프로그램의 사이드 패널을 닫았다가 다시 여세요.

## Discord Desktop이 닫혀 있음

표시되는 메시지: **데스크톱 앱은 설치되어 있지만 Discord Desktop이 열려 있지 않습니다.**

Discord Desktop을 열고 몇 초 기다린 다음 **연결 확인**을 클릭하세요. 브라우저의 Discord는 로컬 Rich Presence 업데이트를 받을 수 없습니다.

## 설치된 프레즌스가 없음

라이브러리에서 프레즌스를 설치하세요. 가장 빠른 테스트를 위해 [YouTube 프레즌스](/library/youtube)를 설치한 다음 YouTube를 여세요.

## 활동이 감지되지 않음

다음을 확인하세요.

- 해당 프레즌스가 설치되어 있고 활성화되어 있는지
- 현재 URL이 해당 프레즌스에서 지원되는지
- 사용자 스크립트가 활성화되어 있는지
- 프레즌스를 설치한 후 페이지를 새로고침했는지

## URL이 지원되지 않음

프레즌스 상세 페이지를 열고 현재 URL을 **지원되는 URL** 목록과 비교하세요. 사이트가 주소나 레이아웃을 변경한 경우, 지원 페이지에서 해당 프레즌스를 신고하세요.

## 권한이 없음

브라우저의 확장 프로그램 설정을 열고 다음을 확인하세요.

- Nowly가 활성화되어 있는지
- 사용자 스크립트가 허용되어 있는지
- 현재 사이트에 대한 사이트 접근이 허용되어 있는지

권한을 변경한 후에는 웹사이트 탭을 새로고침하고 확장 프로그램의 사이드 패널을 다시 여세요.

## Discord IPC: "Access is denied"

런타임 로그에 다음과 같이 표시될 수 있습니다.

```text
reason=open \\.\pipe\discord-ipc-0: Access is denied.
```

연동 기능에서는 번역될 수 있는 이 로그 문구 대신 안정적인 네이티브 응답 코드 `DISCORD_IPC_ACCESS_DENIED`를 사용하세요.

데스크톱 앱이 호스트에는 연결되지만 Windows가 Discord의 로컬 IPC 파이프에 대한 접근을 거부하고 있다는 뜻입니다. 가장 흔한 원인은 브라우저와 Nowly Host는 일반 권한으로 실행되는데 Discord만 **관리자 권한으로 실행**으로 시작된 경우입니다.

다음 순서로 해결하세요.

1. 알림 영역의 아이콘까지 포함해 Discord를 완전히 종료하세요.
2. 작업 관리자에서 남아 있는 `Discord.exe` 프로세스를 종료하세요.
3. Discord 속성을 열고 **호환성** 탭에서 **관리자 권한으로 이 프로그램 실행**을 해제하세요.
4. Discord를 평소처럼 실행하세요.
5. 브라우저를 다시 시작하거나 Nowly에서 **다시 연결**을 클릭하세요.

문제를 우회하려고 브라우저나 Nowly를 관리자 권한으로 실행하지 마세요. Native Messaging은 브라우저가 실행하므로, 권한이 상승된 호스트를 강제하려면 안전하지 않은 권한 중계가 필요합니다. Nowly Host는 이 권한 불일치를 감지하면 시스템 알림을 표시할 수 있습니다. Windows에서는 알림 영역, macOS에서는 알림 센터, Linux에서는 `notify-send`를 사용할 수 있을 때 데스크톱 알림으로 표시됩니다.

진단 페이지는 정상으로 보이는데 로그에 이 오류가 있다면 런타임 로그를 지운 뒤 문제를 다시 재현하세요. 진단은 네이티브 호스트 연결을 반영하지만 Discord IPC 연결은 여전히 거부된 상태일 수 있습니다.

## Linux: .deb 설치 후 "업데이트 가능" 표시

표시되는 메시지: `.deb` 패키지를 방금 설치했는데도 **업데이트 가능**이 표시됨.

흔한 원인은 두 가지입니다. 순서대로 확인하세요.

1. **`.deb`가 실제로 설치되지 않았습니다.** 일부 데스크톱 환경(예: Thunar를 사용하는 XFCE)에서는 GDebi 같은 그래픽 패키지 관리자가 연결되어 있지 않으면 `.deb`를 더블클릭해도 아무 일도 일어나지 않습니다. 대신 터미널에서 설치하세요.

   ```bash
   sudo dpkg -i ~/Downloads/nowly-host.deb
   ```

   그런 다음 등록되었는지 확인하세요. `dpkg -L nowly-host`를 실행하면 `/usr/lib/nowly-client/nowly-host`가 표시되어야 합니다.

2. **오래된 사용자별 매니페스트가 .deb의 것을 덮어쓰고 있습니다.** `.deb`로 전환하기 전에 `.tar.gz` 압축 파일(`install-linux.sh` 스크립트)로 데스크톱 앱을 설치한 적이 있다면, 홈 디렉터리에 남아 있는 매니페스트가 여전히 이전 바이너리를 가리킬 수 있습니다. 제거하세요.

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   그런 다음 브라우저를(확장 프로그램만이 아니라) 완전히 재시작하여 업데이트된 바이너리로 네이티브 프로세스를 다시 시작하도록 하세요.

## 지원 진단 정보 복사하기

확장 프로그램 진단에는 **지원 정보 복사** 버튼이 있습니다. 기술적인 로그를 노출하지 않고 데스크톱 앱, Discord, 프레즌스, 활동 상태를 복사합니다.
