## 진단부터 시작하세요

공유하려는 탭에서 사이드 패널을 열고 각 항목을 하나씩 확인하세요.

- 확장 프로그램 설치됨
- 사용자 스크립트 허용됨
- Nowly Desktop 감지됨
- Discord 연결됨
- 프레즌스 설치됨
- 활동 감지됨

녹색이 아닌 첫 번째 항목이 다음에 해결해야 할 부분입니다.

## Nowly Desktop이 감지되지 않음

[데스크톱 앱 페이지](https://nowly.me/desktop)에서 데스크톱 앱을 설치한 다음 **연결 확인**을 클릭하세요. 방금 설치했다면 브라우저가 앱을 찾을 수 있도록 브라우저를 다시 시작하세요. 앱은 브라우저와 같은 컴퓨터에 설치되어 있어야 합니다.

Linux에서는 Flatpak이나 Snap으로 설치한 브라우저가 네이티브 메시징을 완전히 차단할 수 있습니다. 배포판 저장소나 브라우저 제작사의 자체 패키지로 설치한 브라우저를 사용하세요.

## Discord가 연결되지 않음

Discord 데스크톱 앱을 열고 로딩이 끝날 때까지 기다린 다음 **연결 확인**을 클릭하세요. 브라우저 탭의 Discord는 로컬 Rich Presence를 받을 수 없습니다.

Discord Stable과 Discord PTB 또는 Canary를 함께 실행한다면 하나만 열어 두세요. Windows에서는 데스크톱 앱이 첫 번째 Discord 파이프에 연결됩니다.

## Discord IPC: "Access is denied" (Windows)

실행 로그에 다음과 같이 표시될 수 있습니다.

```text
reason=open \\.\pipe\discord-ipc-0: Access is denied.
```

연동 기능은 이 현지화된 텍스트 대신 안정적인 네이티브 응답 코드 `DISCORD_IPC_ACCESS_DENIED`를 기준으로 삼아야 합니다.

Discord는 관리자 권한으로 실행되는데 브라우저와 데스크톱 앱은 그렇지 않아서 Windows가 Discord의 로컬 파이프에 대한 접근을 거부하는 것입니다. 다음 순서로 해결하세요.

1. 알림 영역의 아이콘까지 포함해 Discord를 완전히 종료하세요.
2. 작업 관리자에서 남아 있는 `Discord.exe` 프로세스를 모두 종료하세요.
3. Discord 바로 가기의 속성에서 **관리자 권한으로 이 프로그램 실행**(호환성 탭)과 **관리자 권한으로 실행**(바로 가기 탭, 고급)을 해제하세요.
4. Discord를 평소처럼 실행하세요.
5. Nowly에서 **다시 연결**을 클릭하거나 브라우저를 다시 시작하세요.

대신 브라우저나 데스크톱 앱을 관리자 권한으로 실행하지 마세요. 네이티브 메시징은 브라우저가 실행하며, 권한이 상승된 브라우저는 보안상 위험합니다. 데스크톱 앱은 이 불일치를 감지하면 시스템 알림을 표시할 수 있습니다. Windows에서는 알림 영역 알림, macOS에서는 알림 센터 알림, Linux에서는 `notify-send`를 사용할 수 있을 때 알림으로 표시됩니다.

## 사용자 스크립트가 허용되지 않음

Nowly 세부정보 페이지에서 **사용자 스크립트 허용**을 켜세요(Chromium 기반 브라우저). 이전 버전의 Chrome에서는 **개발자 모드**를 켜세요. Firefox에서는 `about:addons`에서 사용자 스크립트 권한을 허용하세요. 그런 다음 탭을 새로고침하고 사이드 패널을 다시 여세요.

## 활동이 감지되지 않음

다음을 확인하세요.

- 이 웹사이트의 프레즌스가 설치되어 있고 켜져 있는지
- 공유가 일시정지되지 않았고(**Ctrl+Shift+U**로 전환), 프레즌스가 일시정지되었거나 일정 외 시간이 아닌지
- 탭이 활동 탭에서 숨겨지지 않았는지
- 실제로 무언가가 재생 중인지: 대부분의 프레즌스는 **탐색 활동 표시**가 켜져 있지 않으면 둘러보는 동안 아무것도 표시하지 않습니다
- 주소가 라이브러리 페이지에 표시된 프레즌스의 지원 사이트와 일치하는지
- 프레즌스를 설치한 후 탭을 새로고침했는지

웹사이트가 바뀌어 프레즌스가 잘못된 정보를 표시하거나 아무것도 표시하지 않는다면 라이브러리 페이지에서 **문제 신고**를 사용하세요.

## 다른 Rich Presence 도구가 간섭함

PreMiD나 자체 Rich Presence 기능이 있는 음악 플레이어처럼 Discord 활동을 설정하는 다른 도구는 Nowly가 보낸 내용을 대체하거나 지울 수 있습니다. 테스트하는 동안에는 해당 도구를 끄세요.

## Linux: .deb 설치 직후 "업데이트 가능" 표시

1. **`.deb`가 설치되지 않았습니다.** 일부 데스크톱 환경(예: Thunar를 사용하는 XFCE)에서는 `.deb`를 더블클릭해도 아무 일도 일어나지 않습니다. 터미널에서 설치하세요.

   ```bash
   sudo dpkg -i ~/Downloads/nowly-host.deb
   ```

   그러면 `dpkg -L nowly-host`를 실행했을 때 `/usr/lib/nowly-client/nowly-host`가 표시되어야 합니다.

2. **이전의 사용자별 설치가 우선 적용되고 있습니다.** 이전에 `.tar.gz` 압축 파일을 사용했다면 남은 파일을 제거하세요.

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   그런 다음 브라우저를 완전히 종료하고 다시 여세요.

## Linux: Flatpak 또는 Snap의 Discord

샌드박스에서 실행되는 Discord는 자체 폴더에 소켓을 만듭니다. 데스크톱 앱은 `$XDG_RUNTIME_DIR`, `$TMPDIR`, `/tmp`에서 `discord-ipc-0`부터 `discord-ipc-9`까지 찾습니다. 실제 소켓을 예상 위치에 링크하세요. 예를 들어 Flathub의 경우는 다음과 같습니다.

```bash
ln -sf "$XDG_RUNTIME_DIR/app/com.discordapp.Discord/discord-ipc-0" "$XDG_RUNTIME_DIR/discord-ipc-0"
```

재부팅 후에도 유지되는 링크와 Snap 경로를 포함한 단계별 가이드는 [Linux에서 Nowly 사용하기](https://nowly.me/guides/nowly-on-linux)를 참고하세요.

## 로그

- 확장 프로그램은 실행 로그를 보관하며, 사이드 패널의 **로그 복사**로 복사할 수 있습니다. 방문한 지원 페이지의 주소가 포함될 수 있으므로 공유하기 전에 내용을 확인하세요.
- 데스크톱 앱은 `nowly-host.log`를 `%LOCALAPPDATA%\NowlyClient\`(Windows), `~/Library/Caches/NowlyClient/`(macOS) 또는 `~/.cache/NowlyClient/`(Linux)에 기록합니다.

그래도 해결되지 않나요? Nowly Discord 서버에서 티켓을 열고, 실패한 진단 항목과 사용 중인 시스템을 알려 주세요.
