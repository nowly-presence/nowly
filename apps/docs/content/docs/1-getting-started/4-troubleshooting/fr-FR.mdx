title: Dépannage
description: Corrigez les problèmes Nowly Host absent, Discord Desktop fermé, présence absente, activité absente, URL non supportée et permissions manquantes.
---

## Commencer par le diagnostic

Ouvrez le panneau latéral de l'extension et lisez chaque ligne séparément :

- Extension installée
- Scripts utilisateur actifs
- Nowly Host détecté
- Discord connecté
- Présence installée
- Activité détectée

Ne vous fiez pas à un statut global. La ligne manquante indique la prochaine action.

## Nowly Host n'est pas détecté

Message affiché : **Nowly Host n'est pas détecté.**

Installez Nowly Host depuis la [page Nowly Host](/host), puis cliquez sur **Vérifier la connexion** dans l'extension. Si vous venez de l'installer, fermez et rouvrez le panneau latéral.

## Discord Desktop est fermé

Message affiché : **Nowly Host est installé mais Discord Desktop n'est pas ouvert.**

Ouvrez Discord Desktop, attendez quelques secondes, puis cliquez sur **Vérifier la connexion**. Discord dans le navigateur ne peut pas recevoir les mises à jour Rich Presence locales.

## Aucune présence n'est installée

Installez une présence depuis la bibliothèque. Pour le test le plus rapide, installez la [présence YouTube](/library/youtube), puis ouvrez YouTube.

## Aucune activité n'est détectée

Vérifiez que :

- la présence correspondante est installée et activée
- l'URL actuelle est compatible avec cette présence
- les scripts utilisateur sont actifs
- la page a été rechargée après l'installation de la présence

## URL non supportée

Ouvrez la page de détail de la présence et comparez votre URL actuelle avec la liste **URL compatibles**. Si le site a changé d'adresse ou de structure, signalez la présence depuis la page support.

## Permissions manquantes

Ouvrez les paramètres d'extension de votre navigateur et vérifiez que :

- Nowly est activée
- les scripts utilisateur sont autorisés
- l'accès au site est autorisé pour le site actuel

Après une modification de permission, rechargez l'onglet du site et rouvrez le panneau latéral de l'extension.

## Copier un diagnostic support

Le diagnostic de l'extension contient un bouton **Copier support**. Il copie l'état Nowly Host, Discord, présence et activité sans exposer de logs techniques.
