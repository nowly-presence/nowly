title: Dépannage
description: Corrigez l'application bureau manquante, Discord Desktop fermé, présence absente, activité absente, URL non compatible et permissions manquantes.
---

## Commencer par le diagnostic

Ouvrez le panneau latéral de l'extension et lisez chaque ligne séparément :

- Extension installée
- Scripts utilisateur actifs
- Application bureau détectée
- Discord connecté
- Présence installée
- Activité détectée

Ne vous fiez pas à un statut global. La ligne manquante indique la prochaine action.

## L'application bureau n'est pas détectée

Message affiché : **l'application bureau n'est pas détectée.**

Installez l’application bureau depuis la [page Application bureau](https://nowly.me/desktop), puis cliquez sur **Vérifier la connexion** dans l'extension. Si vous venez de l'installer, fermez et rouvrez le panneau latéral.

## Discord Desktop est fermé

Message affiché : **l'application bureau est installée mais Discord Desktop n'est pas ouvert.**

Ouvrez Discord Desktop, attendez quelques secondes, puis cliquez sur **Vérifier la connexion**. Discord dans le navigateur ne peut pas recevoir les mises à jour Rich Presence locales.

## Aucune présence n'est installée

Installez une présence depuis la bibliothèque. Pour le test le plus rapide, installez la [présence YouTube](/library/youtube), puis ouvrez YouTube.

## Aucune activité n'est détectée

Vérifiez que :

- la présence correspondante est installée et activée
- l'URL actuelle est compatible avec cette présence
- les scripts utilisateur sont actifs
- la page a été rechargée après l'installation de la présence

## URL non compatible

Ouvrez la page de détail de la présence et comparez votre URL actuelle avec la liste **URL compatibles**. Si le site a changé d'adresse ou de structure, signalez la présence depuis la page support.

## Permissions manquantes

Ouvrez les paramètres d'extension de votre navigateur et vérifiez que :

- Nowly est activée
- les scripts utilisateur sont autorisés
- l'accès au site est autorisé pour le site actuel

Après une modification de permission, rechargez l'onglet du site et rouvrez le panneau latéral de l'extension.

## Linux : « Mise à jour disponible » après avoir installé le .deb

Message affiché : **mise à jour disponible**, alors que le paquet `.deb` vient d'être installé.

Deux causes fréquentes, à vérifier dans l'ordre :

1. **Le `.deb` n'a jamais été installé.** Sur certains environnements de bureau (XFCE avec Thunar, par exemple), double-cliquer sur un `.deb` ne fait rien si aucun gestionnaire de paquets graphique n'est associé (comme GDebi). Installez-le depuis un terminal pour être sûr :

   ```bash
   sudo dpkg -i ~/Téléchargements/nowly-host.deb
   ```

   Vérifiez ensuite que le paquet est bien enregistré : `dpkg -L nowly-host` doit lister `/usr/lib/nowly-client/nowly-host`.

2. **Un ancien manifest par utilisateur prend le pas sur celui du `.deb`.** Si vous aviez déjà installé l'application bureau via l'archive `.tar.gz` (script `install-linux.sh`) avant de passer au `.deb`, un manifest resté dans votre dossier personnel peut continuer à pointer vers l'ancien binaire. Supprimez-le :

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   Puis redémarrez complètement le navigateur (pas seulement l'extension) pour qu'il relance le processus natif à jour.

## Copier un diagnostic support

Le diagnostic de l'extension contient un bouton **Copier support**. Il copie l'état de l'application bureau, Discord, des présences et de l'activité, sans exposer de journaux techniques.
