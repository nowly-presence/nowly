## Commencer par le diagnostic

Ouvrez le panneau latéral sur l'onglet à partager et lisez chaque ligne séparément :

- Extension installée
- Scripts utilisateur autorisés
- Nowly Desktop détecté
- Discord connecté
- Une présence est installée
- Activité détectée

La première ligne qui n'est pas verte est la prochaine chose à corriger.

## Nowly Desktop n'est pas détecté

Installez l'application de bureau depuis la [page de l'application de bureau](https://nowly.me/fr/desktop), puis cliquez sur **Vérifier la connexion**. Si vous venez de l'installer, redémarrez le navigateur pour qu'il la trouve. L'application doit être installée sur le même ordinateur que le navigateur.

Sous Linux, un navigateur installé via Flatpak ou Snap peut bloquer complètement le native messaging. Utilisez un navigateur installé depuis les dépôts de votre distribution ou depuis le paquet de l'éditeur.

## Discord n'est pas connecté

Ouvrez l'application Discord, attendez qu'elle soit chargée, puis cliquez sur **Vérifier la connexion**. Discord dans un onglet ne peut pas recevoir de Rich Presence locale.

Si vous lancez Discord classique à côté de Discord PTB ou Canary, n'en gardez qu'un seul ouvert : sous Windows, l'application de bureau se connecte au premier canal de Discord.

## IPC Discord : « Accès refusé » (Windows)

Les journaux peuvent afficher :

```text
reason=open \\.\pipe\discord-ipc-0: Access is denied.
```

Les intégrations doivent s'appuyer sur le code de réponse natif stable `DISCORD_IPC_ACCESS_DENIED` plutôt que sur ce texte traduit.

Windows refuse l'accès au canal local de Discord parce que Discord tourne en administrateur alors que le navigateur et l'application de bureau non. Corrigez dans cet ordre :

1. Quittez complètement Discord, y compris son icône dans la zone de notification.
2. Dans le Gestionnaire des tâches, terminez tout processus `Discord.exe` restant.
3. Dans les propriétés du raccourci Discord, décochez **Exécuter ce programme en tant qu'administrateur** (onglet Compatibilité) et **Exécuter en tant qu'administrateur** (onglet Raccourci, Avancé).
4. Relancez Discord normalement.
5. Cliquez sur **Reconnecter** dans Nowly, ou redémarrez le navigateur.

Ne lancez pas le navigateur ou l'application de bureau en administrateur à la place : le native messaging est lancé par le navigateur, et un navigateur élevé est un risque de sécurité. L'application de bureau peut afficher une notification système quand elle détecte ce problème : une notification de la zone de notification sous Windows, du Centre de notifications sous macOS, ou une notification Linux quand `notify-send` est disponible.

## Les scripts utilisateur ne sont pas autorisés

Activez **Autoriser les scripts utilisateur** dans la page de détails de Nowly (navigateurs Chromium), ou le **Mode développeur** sur les anciennes versions de Chrome. Dans Firefox, autorisez les scripts utilisateur depuis `about:addons`. Rechargez ensuite l'onglet et rouvrez le panneau latéral.

## Aucune activité n'est détectée

Vérifiez que :

- la présence de ce site est installée et activée,
- le partage n'est pas en pause (**Ctrl+Maj+U** l'active ou le coupe) et que la présence n'est ni en veille ni hors de ses horaires,
- l'onglet n'est pas masqué depuis l'onglet Activité,
- quelque chose joue vraiment : la plupart des présences n'affichent rien pendant la navigation, sauf si **Afficher l'activité de navigation** est activé,
- l'adresse correspond aux sites compatibles de la présence, affichés sur sa page de la bibliothèque,
- l'onglet a été rechargé après l'installation de la présence.

Si le site a changé et que la présence affiche des informations fausses ou rien du tout, utilisez **Signaler un problème** sur sa page de la bibliothèque.

## Un autre outil de Rich Presence interfère

D'autres outils qui modifient votre activité Discord, comme PreMiD ou un lecteur de musique avec sa propre Rich Presence, peuvent remplacer ou effacer ce que Nowly envoie. Coupez-les pendant vos tests.

## Linux : « mise à jour disponible » juste après l'installation du .deb

1. **Le `.deb` n'a jamais été installé.** Un double-clic sur un `.deb` ne fait rien sur certains bureaux (XFCE avec Thunar, par exemple). Installez-le depuis un terminal :

   ```bash
   sudo dpkg -i ~/Téléchargements/nowly-host.deb
   ```

   `dpkg -L nowly-host` doit ensuite lister `/usr/lib/nowly-client/nowly-host`.

2. **Une ancienne installation par utilisateur passe en priorité.** Si vous avez utilisé l'archive `.tar.gz` auparavant, supprimez ses restes :

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   Quittez ensuite complètement le navigateur et rouvrez-le.

## Linux : Discord via Flatpak ou Snap

Un Discord isolé crée son socket dans son propre dossier. L'application de bureau cherche `discord-ipc-0` à `discord-ipc-9` dans `$XDG_RUNTIME_DIR`, `$TMPDIR` et `/tmp`. Liez le vrai socket à l'emplacement attendu, par exemple pour Flathub :

```bash
ln -sf "$XDG_RUNTIME_DIR/app/com.discordapp.Discord/discord-ipc-0" "$XDG_RUNTIME_DIR/discord-ipc-0"
```

Le guide pas à pas, avec un lien qui survit aux redémarrages et le chemin pour Snap, est [Nowly sous Linux](https://nowly.me/fr/guides/nowly-on-linux).

## Journaux

- L'extension conserve des journaux que vous pouvez copier depuis le panneau latéral avec **Copier les journaux**. Ils peuvent contenir les adresses des pages compatibles visitées : relisez-les avant de les partager.
- L'application de bureau écrit `nowly-host.log` dans `%LOCALAPPDATA%\NowlyClient\` (Windows), `~/Library/Caches/NowlyClient/` (macOS) ou `~/.cache/NowlyClient/` (Linux).

Toujours bloqué ? Ouvrez un ticket sur le serveur Discord de Nowly en indiquant la ligne du diagnostic en échec et votre système.
