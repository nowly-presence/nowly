title: Fehlerbehebung
description: Behebe eine fehlende Desktop-App, eine unter Windows verweigerte Verbindung zu Discord, fehlende Berechtigungen, eine Presence, die nichts erkennt, und Installationsprobleme unter Linux.
---

## Mit der Diagnose beginnen

Öffne das Seitenpanel in dem Tab, den du teilen möchtest, und lies jede Zeile einzeln:

- Erweiterung installiert
- Benutzerskripte erlaubt
- Nowly Desktop gefunden
- Discord verbunden
- Eine Präsenz ist installiert
- Aktivität erkannt

Die erste Zeile, die nicht grün ist, ist das Nächste, was du beheben musst.

## Nowly Desktop wird nicht gefunden

Installiere die Desktop-App von der [Desktop-App-Seite](https://nowly.me/desktop) und klicke dann auf **Verbindung prüfen**. Wenn du sie gerade installiert hast, starte den Browser neu, damit er die App findet. Die App muss auf demselben Computer wie der Browser installiert sein.

Unter Linux kann ein über Flatpak oder Snap installierter Browser Native Messaging komplett blockieren. Verwende einen Browser aus den Paketquellen deiner Distribution oder aus dem eigenen Paket des Herstellers.

## Discord ist nicht verbunden

Öffne die Discord-Desktop-App, warte, bis sie geladen ist, und klicke dann auf **Verbindung prüfen**. Discord in einem Browser-Tab kann keine lokale Rich Presence empfangen.

Wenn du Discord Stable neben Discord PTB oder Canary nutzt, lass nur eine Version geöffnet: Unter Windows verbindet sich die Desktop-App mit der ersten Discord-Pipe.

## Discord IPC: „Access is denied“ (Windows)

Die Laufzeitprotokolle können Folgendes zeigen:

```text
reason=open \\.\pipe\discord-ipc-0: Access is denied.
```

Integrationen sollten sich auf den stabilen nativen Antwortcode `DISCORD_IPC_ACCESS_DENIED` stützen statt auf diesen lokalisierten Text.

Windows verweigert den Zugriff auf die lokale Pipe von Discord, weil Discord als Administrator läuft, der Browser und die Desktop-App aber nicht. Behebe es in dieser Reihenfolge:

1. Beende Discord vollständig, auch über sein Symbol im Infobereich.
2. Beende im Task-Manager alle verbleibenden `Discord.exe`-Prozesse.
3. Deaktiviere in den Eigenschaften der Discord-Verknüpfung **Programm als Administrator ausführen** (Registerkarte Kompatibilität) und **Als Administrator ausführen** (Registerkarte Verknüpfung, Erweitert).
4. Starte Discord normal.
5. Klicke in Nowly auf **Neu verbinden** oder starte den Browser neu.

Starte stattdessen nicht den Browser oder die Desktop-App als Administrator: Native Messaging wird vom Browser gestartet, und ein Browser mit erhöhten Rechten ist ein Sicherheitsrisiko. Die Desktop-App kann eine Systembenachrichtigung anzeigen, wenn sie diesen Konflikt erkennt: eine Benachrichtigung im Infobereich unter Windows, eine Mitteilung in der Mitteilungszentrale unter macOS oder eine Linux-Benachrichtigung, wenn `notify-send` verfügbar ist.

## Benutzerskripte sind nicht erlaubt

Aktiviere **Benutzerskripte zulassen** auf der Detailseite von Nowly (Chromium-Browser) oder den **Entwicklermodus** in älteren Chrome-Versionen. Erlaube in Firefox die Berechtigung für Benutzerskripte über `about:addons`. Lade dann den Tab neu und öffne das Seitenpanel erneut.

## Keine Aktivität erkannt

Prüfe, ob:

- die Presence für diese Website installiert und aktiviert ist,
- das Teilen nicht pausiert ist (**Ctrl+Shift+U** schaltet es ein und aus) und die Presence weder vorübergehend pausiert noch außerhalb ihres Zeitplans ist,
- der Tab nicht über den Tab Aktivität ausgeblendet wurde,
- wirklich etwas läuft: Die meisten Presences zeigen beim Surfen nichts an, außer **Browsing-Aktivität anzeigen** ist aktiviert,
- die Adresse zu den unterstützten Seiten der Presence passt, die auf ihrer Seite in der Bibliothek aufgeführt sind,
- der Tab nach der Installation der Presence neu geladen wurde.

Wenn sich die Website geändert hat und die Presence falsche oder gar keine Informationen anzeigt, nutze **Problem melden** auf ihrer Seite in der Bibliothek.

## Ein anderes Rich-Presence-Tool stört

Andere Tools, die deine Discord-Aktivität setzen, etwa PreMiD oder ein Musikplayer mit eigener Rich Presence, können ersetzen oder löschen, was Nowly sendet. Schalte sie während des Tests aus.

## Linux: „Update verfügbar“ direkt nach der Installation der .deb

1. **Die `.deb` wurde nie installiert.** In manchen Desktop-Umgebungen (zum Beispiel XFCE mit Thunar) bewirkt ein Doppelklick auf eine `.deb` nichts. Installiere sie über ein Terminal:

   ```bash
   sudo dpkg -i ~/Downloads/nowly-host.deb
   ```

   `dpkg -L nowly-host` sollte danach `/usr/lib/nowly-client/nowly-host` auflisten.

2. **Eine alte benutzerspezifische Installation hat Vorrang.** Wenn du früher das `.tar.gz`-Archiv verwendet hast, entferne ihre Überreste:

   ```bash
   rm -f ~/.mozilla/native-messaging-hosts/nowly.client.json
   rm -f ~/.config/*/NativeMessagingHosts/nowly.client.json
   rm -f ~/.local/share/NowlyClient/nowly-host
   ```

   Beende den Browser danach vollständig und öffne ihn erneut.

## Linux: Discord aus Flatpak oder Snap

Ein Discord in einer Sandbox legt seinen Socket in einem eigenen Ordner an. Die Desktop-App sucht `discord-ipc-0` bis `discord-ipc-9` in `$XDG_RUNTIME_DIR`, `$TMPDIR` und `/tmp`. Verlinke den echten Socket an den erwarteten Ort, zum Beispiel für Flathub:

```bash
ln -sf "$XDG_RUNTIME_DIR/app/com.discordapp.Discord/discord-ipc-0" "$XDG_RUNTIME_DIR/discord-ipc-0"
```

Die Schritt-für-Schritt-Anleitung, mit einem Link, der Neustarts übersteht, und dem Pfad für Snap, findest du unter [Nowly unter Linux](https://nowly.me/guides/nowly-on-linux).

## Protokolle

- Die Erweiterung speichert Laufzeitprotokolle, die du im Seitenpanel mit **Protokolle kopieren** kopieren kannst. Sie können die Adressen besuchter unterstützter Seiten enthalten: Lies sie durch, bevor du sie teilst.
- Die Desktop-App schreibt `nowly-host.log` in `%LOCALAPPDATA%\NowlyClient\` (Windows), `~/Library/Caches/NowlyClient/` (macOS) oder `~/.cache/NowlyClient/` (Linux).

Kommst du immer noch nicht weiter? Eröffne auf dem Nowly-Discord-Server ein Ticket mit der fehlschlagenden Diagnosezeile und deinem System.
