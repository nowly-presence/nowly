## 프레즌스가 하는 일

프레즌스는 하나의 웹사이트를 읽는 방법을 Nowly에 알려 줍니다. 프레즌스에 지정된 주소에서만, 그리고 설치한 후에만 실행됩니다. 확장 프로그램이 프레즌스를 실행하고, 데스크톱 앱이 그 결과를 Discord 앱으로 보냅니다.

## 프레즌스 설치하기

웹사이트에서:

1. [라이브러리](/library)에서 프레즌스 페이지를 엽니다.
2. 페이지가 확장 프로그램을 감지할 때까지 기다립니다.
3. **설치**를 클릭합니다.

확장 프로그램에서: 사이드 패널의 **라이브러리** 탭을 열고 플랫폼을 검색해 설치합니다.

두 방법 모두 같은 서명된 패키지를 다운로드합니다. 확장 프로그램은 패키지를 등록하기 전에 서명과 해시를 확인하며, 수정된 패키지는 거부합니다.

설치한 후에는 해당 웹사이트의 탭을 한 번 새로고침하세요. 설치 전에 열린 탭에서는 아직 프레즌스가 실행되지 않습니다.

## 첫 테스트: YouTube

[YouTube 프레즌스](/library/youtube)를 설치하고 youtube.com에서 동영상을 열어 재생하세요. 사이드 패널에 **활동 감지됨**이 표시되고, 몇 초 안에 Discord 프로필이 업데이트됩니다.

## 프레즌스 설정

사이드 패널에서 프레즌스를 열면 설정을 볼 수 있습니다. 설정은 웹사이트마다 다릅니다. 가장 흔한 설정은 다음과 같습니다.

- **탐색 활동 표시**: 대부분의 프레즌스에서 기본적으로 꺼져 있으며, 이 경우 실제로 보거나 듣고 있는 것만 공유합니다.
- **개인정보 보호 모드**: 제목, 아티스트, 이름을 숨겨 Discord에 플랫폼만 표시합니다.
- **버튼 표시**: 친구가 같은 페이지를 열 수 있는 버튼을 없앱니다.
- **언어**: 프레즌스가 여러 언어를 제공하는 경우 Discord에 표시되는 텍스트의 언어입니다.

프레즌스를 일시정지하거나(1시간, 4시간, 내일까지) 프레즌스별로 개별 공유 일정을 지정할 수도 있습니다.

## 프레즌스 업데이트 또는 제거

업데이트는 사이드 패널과 프레즌스 페이지에 표시됩니다. 프레즌스는 사이드 패널이나 라이브러리의 프레즌스 페이지에서 제거할 수 있습니다. 제거하면 Nowly는 해당 웹사이트에서 아무것도 실행하지 않습니다.

## 작성 중인 프레즌스 테스트

개발 중인 프레즌스는 라이브러리를 거치지 않고 로컬에서 로드합니다. [로컬에서 로드 및 테스트](/presence-development/load-and-test)를 참고하세요.
