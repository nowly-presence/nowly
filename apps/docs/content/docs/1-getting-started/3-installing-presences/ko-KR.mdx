## 프레즌스가 하는 일

프레즌스는 지원되는 웹사이트에서 활동을 감지하는 방법을 Nowly에 알려줍니다. 확장 프로그램이 프레즌스를 실행하고, 데스크톱 앱이 해당 활동을 Discord Desktop으로 전송합니다.

## 프레즌스 설치하기

1. [라이브러리](/library)에서 프레즌스 페이지를 엽니다.
2. 페이지에 Nowly 확장 프로그램이 감지되었다고 표시되는지 확인합니다.
3. **설치**를 클릭합니다.
4. 해당 프레즌스에 대해 지원되는 URL을 엽니다.
5. 확장 프로그램의 진단과 Discord를 확인합니다.

확장 프로그램이 감지되지 않으면 설치하거나 활성화한 다음 페이지를 새로고침하세요.

## 권장 첫 테스트: YouTube

첫 테스트에는 [YouTube](/library/youtube)를 사용하세요.

YouTube 프레즌스를 설치한 후 [youtube.com](https://youtube.com)을 엽니다. 확장 프로그램에 **활동 감지됨**이 표시되고 Discord가 업데이트되어야 합니다.

## 프레즌스 업데이트 또는 제거

새 버전이 있으면 프레즌스 페이지에 업데이트 작업이 표시됩니다. 프레즌스는 상세 페이지나 확장 프로그램의 사이드 패널에서도 제거할 수 있습니다.

프레즌스를 제거하면 Nowly가 해당 웹사이트에서 더 이상 실행하지 않습니다.
