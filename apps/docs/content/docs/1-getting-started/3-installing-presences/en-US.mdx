## What Presences Do

Presences tell Nowly how to detect activity on a supported website. The extension runs the presence, and Nowly Host sends the resulting activity to Discord Desktop.

## Install a Presence

1. Open a presence page in the [library](/library).
2. Make sure the page says the Nowly extension is detected.
3. Click **Install**.
4. Open a supported URL for that presence.
5. Check the extension diagnostic and Discord.

If the extension is not detected, install or enable it and reload the page.

## Recommended First Test: YouTube

Use [YouTube](/library/youtube) for the first test.

After installing the YouTube presence, open [youtube.com](https://youtube.com). The extension should show **Activity detected**, then Discord should update.

## Update or Remove a Presence

When a new version is available, the presence page shows an update action. You can also remove a presence from its detail page or from the extension side panel.

Removing a presence stops Nowly from running it on matching websites.
