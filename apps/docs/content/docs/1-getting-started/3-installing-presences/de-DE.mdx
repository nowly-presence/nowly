## Was Presences tun

Presences teilen Nowly mit, wie Aktivität auf einer unterstützten Website erkannt wird. Die Erweiterung führt die Presence aus, und die Desktop-App sendet diese Aktivität an Discord Desktop.

## Eine Presence installieren

1. Öffne eine Presence-Seite in der [Bibliothek](/library).
2. Stelle sicher, dass die Seite anzeigt, dass die Nowly-Erweiterung erkannt wurde.
3. Klicke auf **Installieren**.
4. Öffne eine unterstützte URL für diese Presence.
5. Prüfe die Diagnose der Erweiterung und Discord.

Wenn die Erweiterung nicht erkannt wird, installiere oder aktiviere sie und lade die Seite neu.

## Empfohlener erster Test: YouTube

Verwende [YouTube](/library/youtube) für den ersten Test.

Nachdem du die YouTube-Presence installiert hast, öffne [youtube.com](https://youtube.com). Die Erweiterung sollte **Aktivität erkannt** anzeigen, und Discord sollte sich aktualisieren.

## Eine Presence aktualisieren oder entfernen

Wenn eine neue Version verfügbar ist, zeigt die Presence-Seite eine Update-Aktion an. Du kannst eine Presence auch von ihrer Detailseite oder im Seitenpanel der Erweiterung entfernen.

Das Entfernen einer Presence stoppt Nowly daran, sie auf passenden Websites auszuführen.
