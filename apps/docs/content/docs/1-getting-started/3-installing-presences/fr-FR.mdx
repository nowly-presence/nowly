## À quoi servent les présences

Les présences indiquent à Nowly comment détecter l'activité sur un site compatible. L'extension exécute la présence, puis Nowly Host envoie l'activité obtenue à Discord Desktop.

## Installer une présence

1. Ouvrez une page de présence dans la [bibliothèque](/library).
2. Vérifiez que la page indique que l'extension Nowly est détectée.
3. Cliquez sur **Installer**.
4. Ouvrez une URL compatible avec cette présence.
5. Vérifiez le diagnostic de l'extension et Discord.

Si l'extension n'est pas détectée, installez-la ou activez-la, puis rechargez la page.

## Premier test recommandé : YouTube

Utilisez [YouTube](/library/youtube) pour le premier test.

Après l'installation de la présence YouTube, ouvrez [youtube.com](https://youtube.com). L'extension doit afficher **Activité détectée**, puis Discord doit se mettre à jour.

## Mettre à jour ou supprimer une présence

Lorsqu'une nouvelle version est disponible, la page de présence affiche une action de mise à jour. Vous pouvez aussi supprimer une présence depuis sa page de détail ou depuis le panneau latéral de l'extension.

Supprimer une présence empêche Nowly de l'exécuter sur les sites correspondants.
