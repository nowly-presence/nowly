## O que as presenças fazem

As presenças dizem ao Nowly como detectar atividade em um site compatível. A extensão executa a presença, e o app de desktop envia essa atividade para o Discord Desktop.

## Instale uma presença

1. Abra uma página de presença na [biblioteca](/library).
2. Verifique se a página indica que a extensão Nowly foi detectada.
3. Clique em **Instalar**.
4. Abra uma URL compatível para essa presença.
5. Verifique o diagnóstico da extensão e o Discord.

Se a extensão não for detectada, instale-a ou ative-a e recarregue a página.

## Primeiro teste recomendado: YouTube

Use o [YouTube](/library/youtube) para o primeiro teste.

Depois de instalar a presença do YouTube, abra [youtube.com](https://youtube.com). A extensão deve mostrar **Atividade detectada**, e o Discord deve ser atualizado.

## Atualize ou remova uma presença

Quando uma nova versão estiver disponível, a página da presença mostra uma ação de atualização. Você também pode remover uma presença na página de detalhes dela ou no painel lateral da extensão.

Remover uma presença faz o Nowly parar de executá-la nos sites correspondentes.
