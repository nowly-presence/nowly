## プレゼンスの役割

プレゼンスは、対応サイトでのアクティビティをどのように検出するかをNowlyに伝えます。拡張機能がプレゼンスを実行し、デスクトップアプリがそのアクティビティをDiscord Desktopへ送信します。

## プレゼンスをインストールする

1. [ライブラリ](/library)でプレゼンスのページを開きます。
2. ページにNowly拡張機能が検出されていると表示されていることを確認します。
3. **インストール**をクリックします。
4. そのプレゼンスに対応するURLを開きます。
5. 拡張機能の診断とDiscordを確認します。

拡張機能が検出されない場合は、インストールまたは有効化してからページを再読み込みしてください。

## おすすめの最初のテスト: YouTube

最初のテストには[YouTube](/library/youtube)を使用してください。

YouTubeプレゼンスをインストールしたら、[youtube.com](https://youtube.com)を開きます。拡張機能に**アクティビティを検出**と表示され、Discordが更新されるはずです。

## プレゼンスの更新・削除

新しいバージョンが利用可能になると、プレゼンスのページに更新操作が表示されます。プレゼンスは、その詳細ページまたは拡張機能のサイドパネルから削除することもできます。

プレゼンスを削除すると、対応するサイトでNowlyがそれを実行しなくなります。
