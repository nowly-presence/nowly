Nowly ships as a browser extension, a desktop app, and a public library. Newest first.

## [2.0.0](/changelog/2-0-0)

A rebuilt nowly.me, public library, privacy and data controls, desktop and Canary downloads, legal pages, Chrome and Firefox.

## [1.4.0](/changelog/1-4-0)

Side panel rework, in-panel library, pause and shortcuts, local pack zip, changelog after an update.

## [1.3.0](/changelog/1-3-0)

Typed Discord activity language packs, plus SDK and CLI 1.0.0.

## [1.2.1](/changelog/1-2-1)

Hotfix for a leaked development environment in the production build, and API config cleanup.

## [1.2.0](/changelog/1-2-0)

Extension UI overhaul, redesigned player, snooze and planning, settings reorganization.

## [1.1.0](/changelog/1-1-0)

Update flows, uninstall cleanup, and the first per-version changelog pages.

## [1.0.0](/changelog/1-0-0)

First stable public launch.
