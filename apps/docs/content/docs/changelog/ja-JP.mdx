Nowly はブラウザー拡張機能、デスクトップアプリ、公開ライブラリとして提供されます。新しいものから掲載しています。

## [2.0.0](/changelog/2-0-0)

再構築された nowly.me、公開ライブラリ、プライバシーとデータの管理、デスクトップ版と Canary のダウンロード、法的ページ、Chrome と Firefox。

## [1.4.0](/changelog/1-4-0)

サイドパネルの刷新、パネル内ライブラリ、一時停止とショートカット、ローカルパック ZIP、更新後の変更履歴。

## [1.3.0](/changelog/1-3-0)

型付き Discord アクティビティ言語パックと SDK および CLI 1.0.0。

## [1.2.1](/changelog/1-2-1)

本番ビルドに漏れていた開発環境を修正し、API 設定を整理したホットフィックス。

## [1.2.0](/changelog/1-2-0)

拡張機能 UI の刷新、プレイヤーの再設計、スヌーズとスケジュール、設定の再編成。

## [1.1.0](/changelog/1-1-0)

更新フロー、アンインストール時のクリーンアップ、バージョン別変更履歴ページの初回追加。

## [1.0.0](/changelog/1-0-0)

初の安定版公開リリース。
