`1.3.0` introduit un système de localisation dédié aux textes d'activité Discord. Les développeurs peuvent fournir des dictionnaires JSON optionnels et typés, tandis que les utilisateurs choisissent une langue globale ou différente pour chaque présence localisée.

## Compatibilité et correctifs

- Les présences sans dossier `locales` restent compatibles et conservent leurs textes inline.
- Les anciennes releases signées sans métadonnées de langues restent installables.
- Les locales manquantes, JSON invalides, fichiers inconnus, valeurs non textuelles et clés divergentes sont rejetés.
- Les choix globaux et individuels persistent dans le stockage de l'extension, y compris après le redémarrage du service worker.
