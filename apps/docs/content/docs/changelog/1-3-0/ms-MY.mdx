---

`1.3.0` memperkenalkan sistem penyetempatan untuk teks aktiviti Discord. Pengarang boleh menghantar kamus JSON bertip dan pengguna memilih bahasa secara global atau bagi setiap presence.

## Sambungan 1.3.0
Menambah mod Inggeris, Perancis dan Sepanyol global serta mod setiap presence. YouTube boleh menggunakan Perancis sementara Netflix menggunakan Sepanyol.
## Masa jalan
Memuatkan kamus bertandatangan, kembali kepada en-US, mengemas kini halaman aktif serta mengekalkan keserasian presence lama.
## SDK 1.0.0
`presence.getStrings<T>()` mengembalikan kamus bertip tanpa argumen; VS Code melengkapkan kunci dan melaporkan kunci tidak dikenali.
## CLI 1.0.0
Pek bahasa pilihan ditemui, disahkan, disalin dan dimasukkan ke metadata; terjemahan tidak sah gagal awal dengan ralat tepat.
## Saluran keluaran
Pek diterbitkan ke laluan CDN semasa dan berversi dengan cache tidak berubah.
## Pustaka presence
Semua presence semasa menyediakan pek en-US, fr-FR dan es-ES.
## Dokumentasi dan keserasian
Pek bahasa didokumentasikan. Presence tanpa `locales` dan keluaran bertandatangan lama kekal boleh dipasang; pilihan bertahan selepas mula semula.
