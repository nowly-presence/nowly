`1.3.0` は Discord アクティビティテキストのローカライズ機能を導入します。作成者は型付き JSON 辞書を提供でき、ユーザーは全体または presence ごとに言語を選べます。

## 拡張機能 1.3.0
英語・フランス語・スペイン語の全体設定と presence 別設定を追加しました。YouTube をフランス語、Netflix をスペイン語にできます。
## ランタイム
署名済み辞書を読み込み、en-US にフォールバックし、アクティブページを即時更新します。旧 presence もそのまま動作します。
## SDK 1.0.0
`presence.getStrings<T>()` は引数なしで型付き辞書を返し、VS Code がキーを補完して未知のキーを報告します。
## CLI 1.0.0
任意の言語パックを検出、検証、コピーしてメタデータに含めます。不正な翻訳は正確なエラーで早期に失敗します。
## リリースパイプライン
パックを現行およびバージョン付き CDN パスへ公開し、不変キャッシュを適用します。
## Presence ライブラリ
現在のすべての presence が en-US、fr-FR、es-ES パックを提供します。
## ドキュメントと互換性
言語パックを文書化しました。`locales` のない presence と古い署名済みリリースもインストールでき、選択は再起動後も保持されます。
