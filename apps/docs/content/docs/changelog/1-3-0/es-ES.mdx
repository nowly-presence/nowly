`1.3.0` introduce un sistema de localización dedicado a los textos de actividad de Discord. Los desarrolladores pueden incluir diccionarios JSON opcionales y tipados, mientras los usuarios eligen un idioma global o diferente para cada presencia localizada.

## Compatibilidad y correcciones

- Las presencias sin carpeta `locales` siguen funcionando con sus textos inline.
- Las releases firmadas antiguas sin metadatos de idioma siguen siendo compatibles.
- Se rechazan locales ausentes, JSON inválido, archivos desconocidos, valores no textuales y claves diferentes.
- Las selecciones globales e individuales persisten tras reiniciar el service worker.
