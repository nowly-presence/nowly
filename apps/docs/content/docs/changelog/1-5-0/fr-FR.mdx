1.5.0 suit 1.4.0. Il n'y a pas de 1.4.1 sur les stores. Le panneau de 1.4.0 reste. Cette version, c'est le site public, la bibliothèque, et les chemins d'install autour.

## Un nouveau nowly.me

Le site est reconstruit : hero, plateformes, fonctionnalités, installation, confidentialité, FAQ, section code source disponible, CTA. Les textes sont en anglais, français et espagnol. Clair et sombre suivent le système. Les cartes animées du hero tournent seulement sur grand écran.

Le sélecteur de thème du footer cycle clair, sombre et système sans clignoter. Le lockup reste lisible sur fond clair. La navigation utilise de vrais liens. Les libellés disent Application bureau, jamais Host.

## Bibliothèque sur le site

`/library` est un vrai catalogue : recherche, filtres, pagination, fiches de présence, pages auteur. Un résultat vide propose encore de demander ou de créer une présence. Avec l'extension, on peut lancer l'install depuis une fiche.

## Application bureau, Chrome et Firefox

`/desktop` sert Windows, macOS et Linux. Les installs stables pointent vers le Chrome Web Store et Firefox Add-ons. Firefox n'est plus un lien oublié.

## Canary

`/canary` propose des zips d'essai Chrome et Firefox, avec détection du navigateur. Le bouton store est mis en avant pour ne pas confondre test et version stable. Les builds Canary de l'extension ont un lockup et une couleur distincts.

## Support, notes de version, légal

`/support` liste Discord, GitHub, Ko-fi et GitHub Sponsors. Nowly reste gratuit.

`/changelog` liste les versions. Une mise à jour store ouvre toujours `nowly.me/changelog/{version}` puis envoie vers les notes ici.

Confidentialité, conditions, cookies et mentions légales sont sur nowly.me. Ils nomment l'éditeur, un VPS Contabo dans l'UE, Cloudflare, les deux stores, et la BUSL-1.1 (code source disponible, pas open source OSI avant la Change Date). Un bandeau couvre le cookie de langue. La publicité est décrite comme inactive tant qu'on ne l'active pas.

URL canoniques, sitemap, robots, Open Graph et JSON-LD couvrent les pages publiques. Les hôtes de staging comme `dev.nowly.me` ne sont jamais canoniques.

## Documentation

Les docs sont sur [docs.nowly.me](https://docs.nowly.me), chemins du type `/changelog`. Les anciennes URLs `/docs/...` redirigent.

## Aussi dans cette version

- Menus de langue custom dans l'extension, avec drapeaux dans la liste ouverte
- `getSetting` dans les scripts, ticks plus rapides (visibilité, historique, hash, média)
- Parcours de reconnexion si l'application bureau manque ou est trop ancienne
- Snooze jusqu'à minuit ; planning off par défaut sur les nouvelles installs
- Assets bundlés chargeables en local ; présences archivées ignorées à la mise à jour
- `nowly build --watch` et `nowly pack --watch`
