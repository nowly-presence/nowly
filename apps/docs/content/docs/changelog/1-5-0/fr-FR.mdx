## Site web

Routes publiques : `/`, `/library`, `/library/[slug]`, `/author/[github]`, `/desktop`, `/canary`, `/support`, `/changelog`, `/changelog/[version]`, `/privacy`, `/tos`, `/cookies`, `/legal-notice`. Les dons passent par Ko-fi et GitHub Sponsors. Le site et l'API tournent sur un VPS Contabo ; les fichiers statiques restent sur Cloudflare.

## Documentation

L'app docs est `@nowly/docs` sur [docs.nowly.me](https://docs.nowly.me). Les pages n'utilisent que le slug (`/changelog`, `/getting-started/installation`). `https://docs.nowly.me/docs/...` et `https://nowly.me/docs/...` redirigent vers la même page, sans segment `/docs` en trop.

## Sélecteurs de langue

Les contrôles précédents superposaient un drapeau sur le champ fermé et s'appuyaient sur un select HTML natif. Les navigateurs retirent le markup custom des `<option>`, donc la liste ouverte était du texte seul.

Le menu de l'extension est un listbox custom (portal, pour ne pas être coupé par les cartes de réglages). Le Select du footer affiche un drapeau à côté de chaque locale.

## Après une mise à jour

Les builds store Chrome et Firefox ouvrent toujours `https://nowly.me/changelog/{version du manifeste}` sur `onInstalled` avec `reason === "update"`. Pour cette release, l'URL est `/changelog/1.5.0`, qui envoie vers les notes sur docs.nowly.me. Un reload unpacked n'ouvre pas d'onglet.
