## Sitio web

Rutas públicas: `/`, `/library`, `/library/[slug]`, `/author/[github]`, `/desktop`, `/canary`, `/support`, `/changelog`, `/changelog/[version]`, `/privacy`, `/tos`, `/cookies`, `/legal-notice`. Las donaciones van por Ko-fi y GitHub Sponsors. El sitio y la API corren en un VPS Contabo; los estáticos siguen en Cloudflare.

## Documentación

La app de docs es `@nowly/docs` en [docs.nowly.me](https://docs.nowly.me). Las páginas usan solo el slug (`/changelog`, `/getting-started/installation`). `https://docs.nowly.me/docs/...` y `https://nowly.me/docs/...` redirigen a la misma página, sin el segmento `/docs` extra.

## Selectores de idioma

Los controles anteriores superponían una bandera en el campo cerrado y usaban un select HTML nativo. Los navegadores quitan el markup custom de `<option>`, así que la lista abierta era solo texto.

El menú de la extensión es un listbox custom (portal, para no recortarse en las tarjetas de ajustes). El Select del footer muestra una bandera junto a cada locale.

## Tras una actualización

Las builds de Chrome y Firefox Store siguen abriendo `https://nowly.me/changelog/{versión del manifiesto}` en `onInstalled` con `reason === "update"`. En esta release esa URL es `/changelog/1.5.0`, que lleva a las notas en docs.nowly.me. Un reload unpacked no abre pestaña.
