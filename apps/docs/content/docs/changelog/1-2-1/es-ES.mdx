---
title: 1.2.1
date: 2026-06-25
description: Corrección — eliminación de fugas de variables de entorno de desarrollo en el build de producción y simplificación de la configuración de la API.
---

`1.2.1` es una release de mantenimiento que corrige un problema de build donde las variables de entorno de desarrollo se filtraban en el artefacto de Chrome Web Store, simplifica la superficie de configuración de la API, y limpia las páginas legales de referencias obsoletas a comentarios y OAuth de Discord.
