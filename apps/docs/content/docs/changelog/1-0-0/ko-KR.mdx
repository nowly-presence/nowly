`1.0.0`은 Nowly가 분리된 여러 요소의 모음이 아니라 완성된 제품이 된 시점입니다. 첫 안정 출시이며 이후 모든 기능의 기반입니다.

## 브라우저 확장 프로그램

지원 웹사이트를 감지하고 서명된 presence를 불러와 활동을 데스크톱 앱으로 전달합니다. 모든 presence 활동의 사용자 진입점입니다.

## 데스크톱 앱

브라우저 활동을 Discord Rich Presence로 연결합니다. Discord 업데이트는 로컬에서 이루어지므로 브라우저가 통합 계층이 되지 않습니다.

## 공개 라이브러리

presence, 상세 페이지, 댓글, 평점, 릴리스 기록을 보여 줍니다. 사용자는 설치 전에 presence를 확인할 수 있습니다.

## Presence 수명 주기

설치, 업데이트, 비활성화, 제거 흐름을 지원합니다. presence 관리는 일반적인 사용자 흐름으로 제공됩니다.

## 문서

설정, 문제 해결, presence 개발, 게시를 다룹니다. 기여자와 사용자가 제품 동작을 한곳에서 확인할 수 있습니다.

## CLI

presence 번들을 빌드하고 검증하며 게시합니다. 개발 과정을 수작업 일회성이 아닌 반복 가능한 과정으로 만듭니다.
