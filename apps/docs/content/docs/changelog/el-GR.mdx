description: Τι κυκλοφόρησε σε κάθε έκδοση του Nowly, γραμμένο ως αρχείο αλλαγών προϊόντος και όχι ως υπολογιστικό φύλλο.
---

Το Nowly διατίθεται ως επέκταση προγράμματος περιήγησης, εφαρμογή υπολογιστή και δημόσια βιβλιοθήκη. Πρώτα εμφανίζονται τα νεότερα.

## [2.0.0](/changelog/2-0-0)

Ανακατασκευασμένο nowly.me, δημόσια βιβλιοθήκη, έλεγχοι απορρήτου και δεδομένων, λήψεις desktop και Canary, νομικές σελίδες, Chrome και Firefox.

## [1.4.0](/changelog/1-4-0)

Νέα σχεδίαση πλευρικού πίνακα, βιβλιοθήκη μέσα στον πίνακα, παύση και συντομεύσεις, τοπικό ZIP πακέτου και αρχείο αλλαγών μετά από ενημέρωση.

## [1.3.0](/changelog/1-3-0)

Τυποποιημένα πακέτα γλωσσών δραστηριότητας Discord, καθώς και SDK και CLI 1.0.0.

## [1.2.1](/changelog/1-2-1)

Hotfix για περιβάλλον ανάπτυξης που διέρρευσε στο production build και εκκαθάριση ρυθμίσεων API.

## [1.2.0](/changelog/1-2-0)

Ανανεωμένο UI επέκτασης, επανασχεδιασμένο πρόγραμμα αναπαραγωγής, αναβολή και προγραμματισμός, αναδιοργάνωση ρυθμίσεων.

## [1.1.0](/changelog/1-1-0)

Ροές ενημέρωσης, καθαρισμός κατά την απεγκατάσταση και οι πρώτες σελίδες αρχείου αλλαγών ανά έκδοση.

## [1.0.0](/changelog/1-0-0)

Πρώτη σταθερή δημόσια κυκλοφορία.
