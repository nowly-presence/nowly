## Sélecteurs de langue

Les contrôles précédents superposaient un drapeau sur le champ fermé et s'appuyaient sur un select HTML natif. Les navigateurs retirent le markup custom des `<option>`, donc la liste ouverte était du texte seul.

Le menu de l'extension est maintenant un listbox custom (portal, pour ne pas être coupé par les cartes de réglages arrondies). Le footer du site garde le Select partagé, avec un drapeau à côté de chaque locale.

## Après une mise à jour

Les builds store Chrome et Firefox ouvrent toujours `https://nowly.me/changelog/{version du manifeste}` sur `onInstalled` avec `reason === "update"`. Pour cette release, l'URL est `/changelog/1.4.1`. Un reload unpacked n'ouvre pas d'onglet.
