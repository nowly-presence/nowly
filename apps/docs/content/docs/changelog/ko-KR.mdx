Nowly는 브라우저 확장 프로그램, 데스크톱 앱, 공개 라이브러리로 제공됩니다. 최신 버전부터 표시합니다.

## [2.0.0](/changelog/2-0-0)

새롭게 구축한 nowly.me, 공개 라이브러리, 개인정보 및 데이터 제어, 데스크톱과 Canary 다운로드, 법률 페이지, Chrome 및 Firefox.

## [1.4.0](/changelog/1-4-0)

사이드 패널 개편, 패널 내 라이브러리, 일시 정지와 단축키, 로컬 팩 ZIP, 업데이트 후 변경 기록.

## [1.3.0](/changelog/1-3-0)

타입이 지정된 Discord 활동 언어 팩과 SDK 및 CLI 1.0.0.

## [1.2.1](/changelog/1-2-1)

프로덕션 빌드에 유출된 개발 환경을 수정하고 API 설정을 정리한 핫픽스.

## [1.2.0](/changelog/1-2-0)

확장 프로그램 UI 개편, 플레이어 재설계, 일시 정지와 일정 관리, 설정 재구성.

## [1.1.0](/changelog/1-1-0)

업데이트 흐름, 제거 시 정리, 버전별 변경 기록 페이지의 첫 도입.

## [1.0.0](/changelog/1-0-0)

첫 안정적인 공개 출시.
