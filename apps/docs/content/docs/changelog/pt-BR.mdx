description: O que foi lançado em cada versão do Nowly, escrito como um changelog de produto, não como uma planilha.

O Nowly é distribuído como extensão de navegador, aplicativo para desktop e biblioteca pública. Mais recente primeiro.

## [2.0.0](/changelog/2-0-0)

nowly.me reconstruído, biblioteca pública, controles de privacidade e dados, downloads para desktop e Canary, páginas legais, Chrome e Firefox.

## [1.4.0](/changelog/1-4-0)

Painel lateral reformulado, biblioteca no painel, pausa e atalhos, ZIP de pacote local e changelog após uma atualização.

## [1.3.0](/changelog/1-3-0)

Pacotes de idioma tipados para atividades do Discord, além do SDK e da CLI 1.0.0.

## [1.2.1](/changelog/1-2-1)

Hotfix para um ambiente de desenvolvimento exposto no build de produção e limpeza da configuração da API.

## [1.2.0](/changelog/1-2-0)

Interface da extensão renovada, player redesenhado, soneca e planejamento, além da reorganização das configurações.

## [1.1.0](/changelog/1-1-0)

Fluxos de atualização, limpeza na desinstalação e as primeiras páginas de changelog por versão.

## [1.0.0](/changelog/1-0-0)

Primeiro lançamento público estável.
