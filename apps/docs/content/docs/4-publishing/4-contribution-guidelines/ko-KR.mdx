## 기여하기 전에

해당 플랫폼이 Discord Rich Presence에 적합하고 표시할 가치가 있는 활동인지 확인하세요.

## 프레즌스 품질

좋은 프레즌스는 다음을 충족해야 합니다:

- 주요 지원 URL에서 작동
- 개인 또는 민감한 데이터 회피
- 로딩 및 누락된 요소 처리
- 명확한 메타데이터와 에셋 사용
- 유용한 다국어 설명 포함
- 사용자가 계정을 연결할 때 Discord가 이미 해당 플랫폼을 표시한다면 `discordNative`를 `true`로 설정

## 코드 스타일

프레즌스 코드를 작고 읽기 쉽게 유지하세요. 페이지 상태를 파싱할 때는 이름이 있는 헬퍼 함수를 선호하고 관련 없는 추상화는 피하세요.

## 에셋

깔끔한 플랫폼 에셋을 사용하세요. 아이콘은 어두운 배경에서도 읽을 수 있어야 합니다. 썸네일은 서비스를 분명하게 나타내야 합니다.

## 테스트

제출하기 전에 프레즌스를 테스트하세요:

- 로컬에 설치
- 지원 URL 방문
- Discord 활동 확인
- 일시 중지 및 지원되지 않는 상태 확인
- 메타데이터 검증 실행
