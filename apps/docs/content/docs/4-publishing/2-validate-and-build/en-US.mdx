---
title: Validate and Build
description: Validate presence metadata and build presence bundles before publishing.
---

## Validate Metadata

Run:

```bash
nowly validate
```

Validation checks `metadata.json` against the Nowly schema. Fix validation errors before building.

## Build All Presences

Run:

```bash
nowly build
```

## Build One Presence

Run:

```bash
nowly build youtube
```

Use the slug or folder-derived name for the target presence.

## Load in the browser

After a successful build, load the presence with `nowly extension <slug>` or drop a zip from `nowly pack <slug>`. See [Load and Test Locally](/presence-development/load-and-test).
