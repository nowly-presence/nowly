---
title: Valider et compiler
description: Validez les métadonnées de la présence et compilez les paquets de présence avant la publication.
---

## Valider les métadonnées

Exécutez&nbsp;:

```bash
nowly validate
```

La validation vérifie `metadata.json` par rapport au schéma Nowly, y compris que `discordNative` est un booléen s'il est présent. Corrigez les erreurs de validation avant de compiler.

## Compiler toutes les présences

Exécutez&nbsp;:

```bash
nowly build
```

## Compiler une présence

Exécutez&nbsp;:

```bash
nowly build youtube
```

Utilisez le slug ou le nom dérivé du dossier pour la présence cible.

## Charger dans le navigateur

Après une compilation réussie, chargez la présence avec `nowly extension <slug>` ou déposez un zip issu de `nowly pack <slug>`. Voir [Charger et tester en local](/presence-development/load-and-test).
