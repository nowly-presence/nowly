---
title: Valider et compiler
description: Validez les métadonnées de la presence et compilez les paquets de presence avant la publication.
---

## Valider les métadonnées

Exécutez&nbsp;:

```bash
nowly validate
```

La validation vérifie `metadata.json` par rapport au schéma Nowly. Corrigez les erreurs de validation avant de compiler.

## Compiler toutes les presences

Exécutez&nbsp;:

```bash
nowly build
```

## Compiler une presence

Exécutez&nbsp;:

```bash
nowly build youtube
```

Utilisez le slug ou le nom dérivé du dossier pour la presence cible.

## Charger dans le navigateur

Après une compilation réussie, chargez la presence avec `nowly extension <slug>` ou déposez un zip issu de `nowly pack <slug>`. Voir [Charger et tester en local](/docs/presence-development/load-and-test).
