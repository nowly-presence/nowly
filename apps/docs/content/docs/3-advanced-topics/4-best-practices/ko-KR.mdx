## 안정적인 감지를 우선하세요

안정적인 선택자와 미디어 요소를 사용하세요. 가능하면 프레임워크가 생성한 취약한 선택자는 피하세요.

## 활동 정보를 유용하게 유지하세요

사용자가 무엇을 보고 있는지, 페이지 맥락, 재생 진행률, 플랫폼 브랜딩 등 의미 있는 정보를 표시하세요.

## 개인정보를 존중하세요

개인 데이터, 비공개 메시지, 계정 정보 또는 민감한 페이지 내용을 수집하지 마세요. 프레즌스에는 공개된 활동과 관련된 정보만 표시해야 합니다.

## 누락된 상태를 처리하세요

웹사이트는 변경됩니다. 요소가 없거나 로딩 중이거나 지원되지 않는 페이지인 경우에도 항상 우아하게 처리하세요.

## 과도한 작업을 피하세요

프레즌스 업데이트는 가벼워야 합니다. 업데이트마다 비용이 큰 DOM 스캔을 수행하지 마세요.

## 여러 페이지를 테스트하세요

게시하기 전에 재생 페이지, 로그아웃 상태, 지원되지 않는 URL, 일시 정지된 미디어, 로딩 상태를 테스트하세요.
