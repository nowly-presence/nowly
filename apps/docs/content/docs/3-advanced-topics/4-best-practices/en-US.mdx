---
title: Best Practices
description: Build reliable, privacy-friendly, and maintainable Nowly presences.
---

## Prefer Stable Detection

Use stable selectors and media elements. Avoid brittle selectors generated by frameworks when possible.

## Keep Activity Useful

Show meaningful information: what the user is watching, page context, playback progress, and platform branding.

## Respect Privacy

Do not collect personal data, private messages, account details, or sensitive page content. A presence should only display public activity-like information.

## Handle Missing State

Websites change. Always handle missing elements, loading states, and unsupported pages gracefully.

## Avoid Excessive Work

Presence updates should be lightweight. Avoid expensive DOM scans on every update.

## Test Multiple Pages

Test playback pages, logged-out states, unsupported URLs, paused media, and loading states before publishing.
