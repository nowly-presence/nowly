iFrameプレゼンススクリプトはオプトイン機能として利用できます。`metadata.json`で`iframe`を`true`に設定し、`iFrameRegExp`を指定してください。
</CalloutInfo>

## iFrameプレゼンスの設定

ネストされたフレームのURLパターンを`metadata.json`に追加します。

```json
{
  "iframe": true,
  "iFrameRegExp": "player\\.example\\.com/embed/"
}
```

`presence.ts`の隣に`iframe.ts`を作成します。該当するネストされたフレーム内で実行されます。

```ts filename="iframe.ts"
const iframe = new iFrame()

iframe.on("UpdateData", () => {
  const video = document.querySelector("video")
  if (!video) return

  iframe.send({
    video: {
      paused: video.paused,
      currentTime: video.currentTime,
      duration: video.duration,
      title: document.querySelector(".video-title")?.textContent,
    },
  })
})
```

`presence.ts`でデータを受け取ります。

```ts
presence.on("iFrameData", (data) => {
  iFrameData = data
})
```

`iFrameData`はメッセージごとに1回発行されます。複数のフレームがある場合は、メインのプレゼンスでデータを識別または統合してください。`iFrameRegExp`はネストされたフレームのURLに対して評価されます。

## 推奨されるアプローチ

iframe処理は、メインページが必要な状態にアクセスできない場合にのみ使用してください。

iframeのロジックを追加する前に、安定したDOMセレクタ、メディア要素、公開されているページの状態を優先してください。

## 安全性

フレームから個人情報や機密データを収集することは避けてください。プレゼンスは、Discord Rich Presenceにとって有用なアクティビティ情報のみを送信する必要があります。
