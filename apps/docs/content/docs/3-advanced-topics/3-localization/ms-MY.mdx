## Penyetempatan Tetapan

Label dan penerangan tetapan menggunakan format locale yang sama.

## Rentetan Runtime

Teks aktiviti Discord menggunakan [pepakej bahasa presence](/advanced-topics/presence-language-packs) pilihan, yang berasingan daripada penyetempatan metadata dan tetapan.

## Kekalkan Teks Pendek

Medan aktiviti Discord adalah padat. Kekalkan rentetan tempatan ringkas dan elakkan perenggan panjang dalam aktiviti runtime.
