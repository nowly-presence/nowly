## Por qué importan las marcas de tiempo

Las marcas de tiempo hacen que la actividad de Discord se sienta en vivo. Muestran cuánto tiempo ha estado viendo el usuario o cuánto tiempo queda.

## Usando createMediaTimestamps

`document` es la API DOM del navegador (disponible porque las presences se ejecutan como scripts de contenido). `Assets` es proporcionado por el runtime (consulta [Assets](/docs/presence-development/assets)).

```ts filename="presence.ts"
import { createMediaTimestamps } from "@nowly/sdk"

const video = document.querySelector("video")

if (video) {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    ...createMediaTimestamps(video),
  })
}
```

## Multimedia en pausa

Cuando el multimedia está en pausa, `createMediaTimestamps` no devuelve marcas de tiempo. Esto evita mostrar un progreso de reproducción incorrecto.

## Transmisiones en vivo

Las transmisiones en vivo a menudo no tienen una duración fija. Usa solo una marca de tiempo de inicio u omite las marcas de tiempo según el comportamiento de la plataforma.
