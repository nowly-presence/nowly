友だちのDiscordプロフィールに、画像やタイマー、**参加**ボタンとともにゲームを**プレイ中**と表示されているのを見たことがあれば、それがRich Presenceです。プログラム名だけでなく、何をしているかを詳しく伝えられる機能です。このガイドでは表示内容、Discordへの送信方法、ウェブサイトの情報を表示するのにNowlyのようなツールが必要な理由を説明します。

## ゲーム名から詳しいアクティビティへ

Discordは当初、実行中のゲームを検出して、その名前をユーザー名の下に表示していました。ゲーム開発者向けに導入されたRich Presenceは、さらに踏み込みます。マップ、スコア、パーティーの人数といった状況をプログラム自身がDiscordに伝え、変化に合わせて更新します。

同じ仕組みはゲーム以外にも使えます。音楽プレーヤー、コードエディター、配信ツールも利用しており、Nowlyはウェブサイトに利用しています。

## Rich Presenceのカードに含まれるもの

Rich Presenceはいくつかの項目で構成されます。すべてのプログラムが全項目を使うわけではありません。

| 項目 | 表示内容 | YouTubeでの例 |
| --- | --- | --- |
| アクティビティの種類 | 名前の前に付く動作 | 視聴中 |
| 名前 | アプリケーション | YouTube |
| 詳細 | 1行目 | 動画のタイトル |
| 状態 | 2行目 | チャンネル名 |
| 大きい画像 | ツールチップ付きのメイン画像 | 動画のサムネイル |
| 小さい画像 | メイン画像の隅に付くアイコン | 再生または一時停止のアイコン |
| 時間情報 | 経過時間、または開始・終了時刻による進行状況のバー | 全26:48のうち14:10 |
| ボタン | 他の人が開けるリンク（最大2つ） | 動画を見る |

アクティビティの種類には**プレイ中**、**再生中**、**視聴中**、**競技中**があります。このため、音楽なら**Spotifyを再生中**、動画なら**Netflixを視聴中**と表示されます。

## プログラムとDiscordの通信方法

Rich Presenceは最初にインターネットを経由するわけではありません。Discordデスクトップアプリは起動時にパソコン上のローカル通信路を開きます。Windowsでは`discord-ipc-0`という名前付きパイプ、macOSとLinuxでは同名のソケットファイルです。アクティビティを設定するプログラムは、次の順で動きます。

1. その通信路に接続します。
2. Discordに登録したアプリケーションIDを伝えます。このIDによってアクティビティの名前と画像が決まります。
3. アクティビティの各項目を送信します。
4. 内容が変われば更新し、終了したらアクティビティを消去します。

Discordアプリはその情報をDiscordのサーバー経由でプロフィールに反映するため、友だちはどの端末からでも確認できます。

通信路はローカルなので、同じパソコンでDiscordデスクトップアプリとともに動くプログラムだけが利用できます。ブラウザのタブやスマートフォンのDiscordには、この通信路がありません。

## ウェブサイトに補助ツールが必要な理由

ウェブサイトからは、このローカル通信路を開けません。ブラウザはウェブページをシステムから意図的に隔離し、拡張機能にも制限を設けています。そのため、ブラウザが再生中の動画を知っていても、Discordへ直接伝えることはできません。

この間をつなぐのがNowlyです。

- **プレゼンス**がブラウザ内のページを読み、アクティビティを作ります。
- **ブラウザ拡張機能**がそれを受け取り、設定を適用します。
- **デスクトップアプリ**がパソコン上でDiscordのローカル通信路を開き、アクティビティを送ります。

デスクトップアプリは小さく、ウィンドウはなく、必要なときにブラウザから起動されます。これがなければ、ブラウザ拡張機能だけでRich Presenceを更新することはできません。

## 誰がRich Presenceを見られるか

アクティビティは、あなたのステータスを見られる友だちや共通のサーバーのメンバーに、プロフィールやメンバー一覧で表示されます。ただし、Discordの**アクティビティのプライバシー**設定、または特定サーバーの設定で共有をオフにした場合は別です。**オフライン表示**にすると誰にも見えません。

ボタンは他の人向けです。友だちが同じ動画やエピソードを開けます。

## 知っておきたい制限

- **アプリケーションごとに同時に1つのアクティビティ。** 複数のプログラムが更新すると、Discordは1つまたは複数を表示したり、表示を切り替えたりする場合があります。同じ内容を表示するツールの併用は避けましょう。
- **更新頻度には制限があります。** Discordが短時間に受け付ける更新は限られるため、ページよりステータスが数秒遅れることがあります。時間情報があれば、更新を送り続けなくてもDiscord側で時間を数えられます。
- **画像はDiscordから取得できる必要があります。** 画像をダウンロードするのはあなたのパソコンではなくDiscordです。非公開または保護された画像にはプロキシが必要です。Nowlyでの扱いは[Nowlyが見られる情報](/guides/what-nowly-can-see)をご覧ください。

## Rich PresenceとDiscord標準のアカウント連携

Spotifyなどのアカウントを**接続**で連携すると、追加のプログラムなしで一部のアクティビティをDiscordに表示できます。ただし仕組みも長所・短所も異なります。[Discordの接続とNowlyの比較](/guides/discord-connections-vs-nowly)で詳しく説明します。
