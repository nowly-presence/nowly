친구의 Discord 프로필에 사진, 타이머, **참가** 버튼과 함께 게임 **플레이 중**이 표시되는 것을 본 적이 있다면 Rich Presence를 본 것입니다. 프로그램이 이름뿐 아니라 무엇을 하고 있는지 자세히 보여줄 수 있는 기능입니다. 이 가이드에서는 Rich Presence에 들어가는 정보, 프로그램이 Discord로 보내는 방식, 웹사이트 활동을 표시하려면 Nowly 같은 도구가 필요한 이유를 설명합니다.

## 게임 이름에서 풍부한 활동 정보로

처음에 Discord는 실행 중인 게임을 감지해 사용자 이름 아래에 게임 이름을 표시했습니다. 게임 개발자를 위해 도입된 Rich Presence는 한 걸음 더 나아갑니다. 프로그램이 맵, 점수, 함께 플레이하는 인원 등의 상황을 Discord에 직접 알리고 상황이 바뀔 때 업데이트합니다.

이 방식은 게임 외에도 적용됩니다. 음악 플레이어, 코드 편집기, 스트리밍 도구가 사용하며 Nowly는 웹사이트에 활용합니다.

## Rich Presence 카드에 들어가는 정보

Rich Presence는 몇 가지 항목으로 구성되며 모든 프로그램이 모든 항목을 채우지는 않습니다.

| 항목 | 표시하는 내용 | YouTube 예시 |
| --- | --- | --- |
| 활동 유형 | 이름 앞에 붙는 동작 | 시청 중 |
| 이름 | 애플리케이션 | YouTube |
| 상세 정보 | 첫 번째 줄 | 영상 제목 |
| 상태 | 두 번째 줄 | 채널 이름 |
| 큰 이미지 | 툴팁이 있는 대표 이미지 | 영상 썸네일 |
| 작은 이미지 | 대표 이미지 모서리의 배지 | 재생 또는 일시정지 아이콘 |
| 타임스탬프 | 경과 시간 또는 시작·종료 시각을 이용한 진행 표시줄 | 26:48 중 14:10 |
| 버튼 | 다른 사람이 열 수 있는 링크 최대 두 개 | 영상 보기 |

활동 유형에는 **플레이 중**, **듣는 중**, **시청 중**, **경쟁 중**이 있습니다. 그래서 음악 프레즌스에는 **Spotify 듣는 중**, 영상 프레즌스에는 **Netflix 시청 중**이라고 표시됩니다.

## 프로그램이 Discord와 통신하는 방법

Rich Presence가 처음부터 인터넷으로 전송되는 것은 아닙니다. Discord 데스크톱 앱은 실행될 때 컴퓨터에서 로컬 통신 채널을 엽니다. Windows에서는 `discord-ipc-0`이라는 이름의 파이프이고 macOS와 Linux에서는 같은 이름의 소켓 파일입니다. 활동을 설정하려는 프로그램은 다음과 같이 동작합니다.

1. 로컬 채널에 연결합니다.
2. Discord에 등록된 애플리케이션 ID를 제시합니다. 이 ID로 활동의 이름과 이미지를 결정합니다.
3. 활동의 각 항목을 전송합니다.
4. 내용이 바뀌면 업데이트하고, 활동을 멈추면 지웁니다.

그런 다음 Discord 앱이 Discord 서버를 통해 프로필에 활동을 게시하므로 친구는 어떤 기기에서든 볼 수 있습니다.

로컬 채널이므로 Discord 데스크톱 앱과 같은 컴퓨터에서 실행되는 프로그램만 사용할 수 있습니다. 브라우저 탭이나 휴대폰의 Discord는 이 채널을 열지 않습니다.

## 웹사이트에 보조 프로그램이 필요한 이유

웹사이트는 그 로컬 채널을 열 수 없습니다. 브라우저가 웹페이지의 시스템 접근을 의도적으로 막고 확장 프로그램도 격리하기 때문입니다. 따라서 브라우저가 재생 중인 영상을 알아도 Discord에 직접 알릴 방법은 없습니다.

Nowly가 이 빈틈을 메웁니다.

- **프레즌스**가 브라우저의 페이지를 읽고 활동 정보를 준비합니다.
- **브라우저 확장 프로그램**이 정보를 모으고 사용자의 설정을 적용합니다.
- **데스크톱 앱**이 컴퓨터에서 Discord의 로컬 채널을 열어 활동을 전송합니다.

데스크톱 앱은 작고 별도 창이 없으며 필요할 때 브라우저가 실행합니다. 이 앱이 없으면 확장 프로그램만으로 Rich Presence를 업데이트할 수 없습니다.

## 누가 Rich Presence를 볼 수 있나요?

프로필과 멤버 목록에서 상태를 볼 수 있는 사람에게 활동이 보입니다. 친구와 같은 서버의 멤버가 해당하며, Discord의 **활동 개인정보 보호** 설정이나 서버별 설정에서 공유를 끄면 보이지 않습니다. 상태가 **오프라인으로 표시**이면 아무도 활동을 볼 수 없습니다.

버튼은 다른 사람을 위한 기능입니다. 친구가 같은 영상이나 에피소드를 열 수 있습니다.

## 알아둘 제한 사항

- **애플리케이션마다 한 번에 하나의 활동.** 여러 프로그램이 활동을 업데이트하면 Discord가 하나만, 여러 개를 표시하거나 번갈아 보여줄 수 있습니다. 같은 내용을 보내는 도구를 둘 이상 동시에 실행하지 마세요.
- **업데이트 빈도 제한.** Discord는 짧은 시간에 받을 수 있는 업데이트 수를 제한하므로 상태가 페이지보다 몇 초 늦을 수 있습니다. 타임스탬프를 사용하면 계속 업데이트하지 않아도 Discord가 직접 시간을 계산합니다.
- **Discord에서 이미지에 접근할 수 있어야 합니다.** 이미지는 사용자 컴퓨터가 아니라 Discord가 내려받으므로 비공개 또는 보호된 이미지에는 프록시가 필요합니다. Nowly가 처리하는 방식은 [Nowly가 볼 수 있는 정보](/guides/what-nowly-can-see)를 참고하세요.

## Rich Presence와 Discord 기본 연결 기능

Spotify처럼 **연결**에서 계정을 연동하면 Discord가 추가 프로그램 없이 일부 활동을 표시하기도 합니다. 이런 연동은 작동 방식과 장단점이 다릅니다. [Discord 연결과 Nowly 비교](/guides/discord-connections-vs-nowly)에서 살펴보세요.
