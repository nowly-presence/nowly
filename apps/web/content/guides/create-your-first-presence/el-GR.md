Κάθε πλατφόρμα στη βιβλιοθήκη του Nowly υπάρχει επειδή κάποιος έγραψε μια παρουσία γι' αυτήν. Αν λείπει ένας ιστότοπος που χρησιμοποιείς, μπορείς να τον προσθέσεις μόνος σου. Μια παρουσία είναι ένα μικρό έργο TypeScript, συνήθως κάτω από εκατό γραμμές για μια πρώτη έκδοση, ενώ το CLI του Nowly αναλαμβάνει τη δημιουργία της δομής, το build και τις τοπικές δοκιμές. Αυτός ο οδηγός σε πηγαίνει από το μηδέν σε μια παρουσία που ενημερώνει την κατάστασή σου στο Discord. Η πλήρης αναφορά βρίσκεται στην [τεκμηρίωση του Nowly](https://docs.nowly.me/).

## Τι χρειάζεσαι

- **Node.js 22 ή νεότερο** και **pnpm**, για να εκτελέσεις το CLI και να κάνεις build τις παρουσίες.
- **Git**, για να κλωνοποιήσεις το αποθετήριο παρουσιών και να ανοίξεις pull request.
- **Περιηγητή Chromium ή Firefox**, καθώς και την **εφαρμογή desktop του Discord** με εγκατεστημένη την [εφαρμογή desktop του Nowly](/desktop), για πραγματική δοκιμή.
- Βασικές γνώσεις JavaScript ή TypeScript και τα εργαλεία προγραμματιστή του περιηγητή για να εξετάσεις τη σελίδα που σε ενδιαφέρει.

## Απόκτησε το αποθετήριο και το CLI

Όλες οι παρουσίες της κοινότητας βρίσκονται σε ένα δημόσιο αποθετήριο, με άδεια MIT:

```bash
git clone https://github.com/nowly-presence/presences.git
cd presences
pnpm install
pnpm i -g @nowly/cli
```

Το `pnpm install` συνδέει επίσης το πακέτο `@nowly/sdk`, που δίνει στον επεξεργαστή σου τους τύπους του Presence API.

## Δημιούργησε τη δομή μιας παρουσίας

```bash
nowly init "Example"
```

Το CLI κάνει μερικές ερωτήσεις και δημιουργεί έναν φάκελο στο `src/E/Example/`, με βάση το πρώτο γράμμα της πλατφόρμας:

- `metadata.json`: όνομα, δημιουργός, υποστηριζόμενες διευθύνσεις, κατηγορία, χρώμα, περιγραφές και ρυθμίσεις της παρουσίας.
- `presence.ts`: ο κώδικας που διαβάζει τη σελίδα και ορίζει τη δραστηριότητα.
- `locales/`: τα κείμενα που εμφανίζονται στο Discord, ένα αρχείο ανά γλώσσα.
- `assets/`: λογότυπο, εικονίδιο και μικρογραφία που χρησιμοποιούνται στο Discord και στη βιβλιοθήκη.

Το CLI ρωτά επίσης αν το Discord εμφανίζει ήδη αυτή την πλατφόρμα μέσω συνδεδεμένου λογαριασμού. Αν ναι, επισημαίνει την παρουσία ώστε η βιβλιοθήκη να ενημερώνει τους χρήστες.

## Περιέγραψε την πλατφόρμα στο metadata.json

Τα σημαντικότερα πεδία είναι οι διευθύνσεις. Το `url` απαριθμεί τα ονόματα host και το `regExp` είναι το μοτίβο με το οποίο πρέπει να ταιριάζει η διεύθυνση μιας σελίδας για να εκτελεστεί η παρουσία. Κράτησέ τα όσο πιο συγκεκριμένα επιτρέπει ο ιστότοπος: μια παρουσία δεν πρέπει να εκτελείται σε σελίδες που δεν καταλαβαίνει.

Το `category` παίρνει μία από τις τιμές `streaming`, `music`, `video`, `social`, `gaming`, `tools`, `ai`, `learning`, `creator` και `other`. Οι περιγραφές γράφονται ανά γλώσσα και τα αγγλικά είναι η εφεδρική γλώσσα.

## Γράψε μια πρώτη παρουσία

Τα `Presence` και `Assets` παρέχονται από το περιβάλλον εκτέλεσης. Μόνο βοηθητικά στοιχεία όπως το `PresenceType` εισάγονται από το SDK:

```ts
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    state: document.location.hostname,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

Το `UpdateData` ενεργοποιείται τακτικά όσο η σελίδα είναι ανοιχτή και κάθε φορά που ο χρήστης αλλάζει κάποια ρύθμιση. Κάθε φορά, διάβασε τη σελίδα και στείλε τη δραστηριότητα. Όταν δεν υπάρχει κάτι που αξίζει να εμφανιστεί, κάλεσε `presence.clearActivity()` αντί να στείλεις κενή κατάσταση.

Για πολυμέσα, το `createMediaTimestamps(video)` από το SDK μετατρέπει ένα στοιχείο `audio` ή `video` στους χρόνους έναρξης και λήξης που χρειάζεται το Discord για τη γραμμή προόδου.

## Σεβάσου τους ανθρώπους που τη χρησιμοποιούν

Οι παρουσίες στη βιβλιοθήκη ακολουθούν μερικούς κανόνες στους οποίους βασίζονται οι χρήστες:

- Εμφάνισε ό,τι κάνει πραγματικά ο χρήστης, όχι κάθε σελίδα που περιηγείται. Βάλε τις σελίδες περιήγησης πίσω από ρύθμιση **Εμφάνιση δραστηριότητας περιήγησης**, απενεργοποιημένη από προεπιλογή.
- Πρόσφερε επιλογή απορρήτου όταν το περιεχόμενο μπορεί να είναι προσωπικό: μια λειτουργία που κρύβει τίτλους ή αποκλείει ιδιωτικές συνομιλίες από το Discord.
- Μην αποστέλλεις δεδομένα πουθενά αλλού εκτός από τη δραστηριότητα και μην διαβάζεις περισσότερα από όσα χρειάζεται η δραστηριότητα.
- Χρησιμοποίησε μεταφρασμένα κείμενα από το `locales/` για κάθε κείμενο που εμφανίζεται στο Discord.

## Κάνε build και τοπική δοκιμή

Επικύρωσε τα μεταδεδομένα και τα αρχεία πολυμέσων και έπειτα κάνε build:

```bash
nowly validate
nowly build example
```

Αν το Nowly δεν είναι ακόμη εγκατεστημένο στον περιηγητή σου, ενσωμάτωσε την παρουσία σε μια έτοιμη επέκταση ανάπτυξης:

```bash
nowly extension example
nowly extension example --firefox
```

Φόρτωσε το `dist/extension-dev` ως μη πακεταρισμένη επέκταση από το `chrome://extensions` με ενεργή τη **Λειτουργία προγραμματιστή** ή φόρτωσε το `dist/extension-dev-firefox/manifest.json` ως προσωρινό πρόσθετο από το `about:debugging` στο Firefox. Άνοιξε τον ιστότοπο που επέλεξες και η κατάστασή σου στο Discord θα πρέπει να αλλάξει.

Αν χρησιμοποιείς ήδη μη πακεταρισμένο build ανάπτυξης του Nowly, μπορείς να δουλεύεις γρηγορότερα με ένα zip:

```bash
nowly pack example
```

Έπειτα σύρε το `dist/packs/example.zip` στην ενότητα **Ρυθμίσεις**, **Για προχωρημένους**, **Εντοπισμός σφαλμάτων** της επέκτασης. Ανυπόγραφα zip γίνονται δεκτά μόνο σε μη πακεταρισμένα build, ποτέ στην έκδοση του καταστήματος.

## Δημοσίευσε την παρουσία

1. Εκτέλεσε το `nowly validate` μία τελευταία φορά και έλεγξε την παρουσία σε μερικές πραγματικές σελίδες, ακόμη και όταν δεν παίζει τίποτα.
2. Άνοιξε pull request στο αποθετήριο παρουσιών, με σύντομη περιγραφή και στιγμιότυπο της κατάστασης στο Discord.
3. Η ομάδα ελέγχει τον κώδικα, υπογράφει την έκδοση και τη δημοσιεύει στη βιβλιοθήκη. Από εκεί μπορεί οποιοσδήποτε να την εγκαταστήσει με ένα κλικ και εσύ εμφανίζεσαι ως δημιουργός της στη σελίδα της στη βιβλιοθήκη.

## Για περισσότερα

Η τεκμηρίωση καλύπτει ολόκληρο το Presence API, τις ρυθμίσεις, τη μετάφραση, τις χρονικές σημάνσεις, τα iframe και τον διακομιστή μεσολάβησης εικόνων που δεν μπορεί να φορτώσει απευθείας το Discord. Ξεκίνα από το [Δημιουργώντας την πρώτη σου παρουσία](https://docs.nowly.me/presence-development/creating-your-first-presence) και κράτα πρόχειρες τις [οδηγίες συνεισφοράς](https://docs.nowly.me/publishing/contribution-guidelines) πριν ανοίξεις pull request.
