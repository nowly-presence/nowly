Discord는 일부 활동을 자체적으로 표시할 수 있습니다. 설정에서 Spotify 계정을 연결하면 다른 프로그램을 설치하지 않아도 프로필에 **Spotify 듣는 중**이라고 나옵니다. 그렇다면 Nowly 라이브러리에는 왜 Spotify 프레즌스가 있을까요? 두 방식의 작동 원리가 매우 다르고 각각 더 적합한 상황이 있기 때문입니다. 이 가이드에서 비교해 보겠습니다.

## Discord 연결의 작동 방식

Discord의 **사용자 설정**에서 **연결**을 열면 다른 서비스의 계정을 연결할 수 있습니다. 그중 일부는 활동도 전달합니다.

- **Spotify**: 연결하면 듣고 있는 곡이 Discord에 표시됩니다. Spotify가 자체 서버에서 Discord로 전달하기 때문에 휴대폰, 스피커, 컴퓨터 어디서 듣든 작동합니다. 친구가 함께 듣는 기능도 있지만 Spotify Premium이 필요합니다.
- **Crunchyroll**: 계정을 연결하면 Crunchyroll에서 시청하는 콘텐츠를 Discord에 표시할 수 있습니다.
- **Twitch**와 **YouTube**: 주로 본인의 채널과 관련된 연결입니다. 생방송 중임을 표시하거나 서버에서 구독자 역할을 동기화할 때 쓰이며, 시청 중인 영상이나 방송은 표시하지 않습니다.

서비스 목록과 공유 내용은 시간이 지나며 바뀌므로 현재 정보는 Discord 설정의 **연결** 페이지를 확인하세요.

## Nowly의 작동 방식

Nowly는 계정을 연결하지 않습니다. 웹사이트의 프레즌스가 브라우저 탭에서 재생 중인 내용을 읽고, 데스크톱 앱이 같은 컴퓨터의 Discord 앱으로 전달합니다. 플랫폼과 Discord 사이에 정보가 직접 교환되지 않습니다. [라이브러리](/library)에서는 Discord가 이미 계정 연결로 지원하는 플랫폼에 **Discord에서 이미 지원** 안내를 표시해 선택할 수 있음을 알려줍니다.

## 중요한 차이점

| | Discord 연결 | Nowly |
| --- | --- | --- |
| 설정 | 계정 한 번 연결 | 확장 프로그램, 데스크톱 앱, 프레즌스 설치 |
| 작동 범위 | 플랫폼이 활동을 보고하는 모든 기기 | 컴퓨터의 브라우저 |
| 계정 연결 | Discord와 플랫폼이 데이터를 공유 | 두 서비스 사이에 계정 연결 없음 |
| 표시 내용 | 연동 기능에서 결정 | 프레즌스와 사용자 설정에서 결정 |
| 개인정보 보호 옵션 | Discord 활동 설정 | 일시 중지, 일정, 개인정보 보호 모드, 탭 숨기기 |
| 플랫폼 수 | 소수 | 40개 이상, 계속 증가 중 |

## Discord 연결이 더 나은 경우

- 주로 브라우저가 아닌 휴대폰이나 스피커로 음악을 듣습니다.
- 친구가 Spotify에서 함께 듣기를 사용하기를 원합니다.
- 컴퓨터에 아무것도 설치하고 싶지 않습니다.

이 경우 계정 연결을 사용하고 같은 플랫폼의 Nowly 프레즌스는 설치하지 마세요.

## Nowly가 더 나은 경우

- Discord 계정과 스트리밍 계정을 연결하고 싶지 않습니다.
- 개인정보 보호 모드로 제목을 숨기거나, 일정으로 저녁에만 공유하거나, **Ctrl+Shift+U**로 전체 공유를 일시 중지하는 등 세밀하게 제어하고 싶습니다.
- 웹 버전 서비스를 사용하며 Discord가 지원하지 않는 Netflix, Disney+, Prime Video, Twitch 시청, ChatGPT 등의 활동도 한곳에서 관리하고 싶습니다.

## 같은 플랫폼에 두 가지를 동시에 쓰지 마세요

Spotify 연결과 Nowly Spotify 프레즌스를 모두 켜면 Discord에 같은 곡이 서로 다른 경로로 두 번 전달됩니다. 상황에 따라 프로필에 활동이 두 개 보이거나 서로 바뀌거나 오래된 정보가 남을 수 있습니다. 플랫폼마다 한 경로만 선택하세요.

- Spotify 연결 설정에서 **Spotify를 상태로 표시**를 끄거나(실제 문구는 다를 수 있습니다) 계정 연결을 해제하세요.
- 또는 해당 플랫폼의 Nowly 프레즌스를 끄거나 제거하세요.

## 함께 활용하는 방법

두 방식을 조합하는 사람도 많습니다. 하루 종일 휴대폰으로 듣는 음악에는 Spotify 연결을 사용하고, 브라우저에서 보는 콘텐츠에는 Nowly를 사용하는 식입니다. 각 플랫폼마다 정보의 출처가 하나라면 Discord에 깔끔하고 최신인 상태가 표시됩니다.
