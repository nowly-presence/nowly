Discordは一部のアクティビティを単独で表示できます。Discordの設定でSpotifyアカウントを連携すると、ほかに何もインストールしなくてもプロフィールに**Spotifyを再生中**と表示されます。それなのに、なぜNowlyのライブラリにもSpotifyのプレゼンスがあるのでしょうか。二つの方法は仕組みが大きく異なり、向いている状況も違うためです。このガイドで比較します。

## Discordの接続の仕組み

Discordの**ユーザー設定**から**接続**を開くと、ほかのサービスのアカウントを連携できます。そのうち一部はアクティビティも送信します。

- **Spotify**：連携すると、再生中の曲がDiscordに表示されます。Spotify自身のサーバーからDiscordに情報が届くため、スマートフォン、スピーカー、パソコンのどれで聴いても動作します。友だちと一緒に聴くこともできますが、Spotify Premiumが必要です。
- **Crunchyroll**：アカウントを連携すると、Crunchyrollで視聴中の作品がDiscordに表示されます。
- **Twitch**と**YouTube**：これらの接続は主に自分のチャンネル向けです。たとえば配信中であることの表示や、サーバー内での登録者ロールの同期に使われます。自分が見ている動画や配信は表示しません。

利用できるサービスや共有内容は変わることがあります。現在の状態はDiscordの設定の**接続**ページで確認してください。

## Nowlyの仕組み

Nowlyはアカウントを連携しません。ウェブサイト用のプレゼンスがブラウザのタブで再生中の内容を読み、デスクトップアプリが同じパソコンのDiscordアプリへ渡します。プラットフォームとDiscordの間で情報をやり取りすることはありません。[ライブラリ](/library)では、Discordの接続にも対応するプラットフォームに**すでにDiscordに対応**と表示し、選択肢があることを知らせています。

## 選ぶ際に重要な違い

| | Discordの接続 | Nowly |
| --- | --- | --- |
| 設定 | アカウントを一度連携 | 拡張機能、デスクトップアプリ、プレゼンスを導入 |
| 動作する場所 | プラットフォームから報告されるすべての端末 | パソコンのブラウザ |
| アカウント連携 | Discordとプラットフォームの間でデータを共有 | 両者を連携しない |
| 表示内容 | 連携機能側が決定 | プレゼンスと自分の設定で決定 |
| プライバシー設定 | Discordのアクティビティ設定 | 一時停止、スケジュール、プライバシーモード、タブの非表示 |
| 対応プラットフォーム | 少数 | 40以上で増加中 |

## Discordの接続が向いている場合

- 主にブラウザではなく、スマートフォンやスピーカーで音楽を聴く。
- Spotifyで友だちと一緒に聴きたい。
- パソコンに何もインストールしたくない。

この場合はDiscordの接続を使い、同じサービスのNowlyプレゼンスはインストールしないでください。

## Nowlyが向いている場合

- Discordとストリーミングサービスのアカウントを連携したくない。
- より細かく管理したい。プライバシーモードでタイトルを隠したり、スケジュールで夜だけ共有したり、**Ctrl+Shift+U**ですべて一時停止したりできる。
- ブラウザでサービスを使い、Netflix、Disney+、Prime Video、Twitchでの視聴、ChatGPTなど、Discordの接続に対応していないサービスも一か所で管理したい。

## 同じプラットフォームで両方を使わない

Spotifyの接続とNowlyのSpotifyプレゼンスを両方オンにすると、Discordは同じ曲を二つの経路から受け取ります。タイミングによっては、プロフィールに二つのアクティビティが表示されたり、表示が切り替わったり、古い情報が残ったりします。プラットフォームごとに一方を選びましょう。

- Spotifyの接続設定で**Spotifyをステータスとして表示**をオフにする（表記は異なる場合があります）か、連携を解除します。
- または、そのプラットフォームのNowlyプレゼンスを削除・無効化します。

## 実用的な組み合わせ

一日中スマートフォンで音楽を聴くならSpotifyにはDiscordの接続を使い、ブラウザで視聴するものにはNowlyを使う、という組み合わせもできます。各プラットフォームからの情報源が一つずつなら、Discordには整理された最新のステータスが表示されます。
