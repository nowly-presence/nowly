Nowly는 웹사이트에서 보고, 듣고, 둘러보는 활동을 Discord Rich Presence로 보여줍니다. 이름 아래에 제목, 이미지, 진행 표시줄, 때로는 버튼까지 표시되는 카드입니다. 설정에는 약 5분이 걸리며, 브라우저 확장 프로그램, 작은 데스크톱 앱, 그리고 표시하려는 웹사이트마다 하나씩 프레즌스가 필요합니다. 이 가이드에서는 순서대로 설치하고 모두 연결됐는지 확인합니다.

## 시작하기 전에 필요한 것

- **컴퓨터**: Windows 10 또는 11, macOS 11 Big Sur 이상, 또는 64비트 Linux 배포판.
- **브라우저**: Chrome, Edge, Brave, Opera 등 Chromium 브라우저 또는 Firefox.
- **Discord 데스크톱 앱**: 설치하고 로그인해 두세요. 브라우저 탭이나 휴대폰의 Discord는 다른 프로그램에서 Rich Presence를 받을 수 없으므로 Nowly와 함께 작동하지 않습니다.

Nowly 계정은 필요하지 않습니다. 아래 기능은 모두 무료입니다.

## 1단계: 브라우저 확장 프로그램 설치

평소 사용하는 브라우저에서 [확장 프로그램 페이지](/extension)를 여세요. 버튼을 누르면 브라우저에 맞는 스토어로 이동합니다. Chrome, Edge, Brave, Opera는 Chrome 웹 스토어로, Firefox는 Firefox 부가 기능 사이트로 연결됩니다. **추가**를 누르고 확인한 다음, Nowly 아이콘을 도구 모음에 고정하면 클릭 한 번으로 열 수 있습니다.

Nowly는 브라우저의 사이드 패널(Firefox에서는 사이드바)에서 사용합니다. 도구 모음 아이콘을 누르거나 **Ctrl+Shift+Y**(Mac에서는 **Cmd+Shift+Y**)로 여세요. 처음 열면 각 단계를 설명하는 짧은 시작 안내가 나옵니다. 안내를 따르거나 여기서 계속 읽어도 됩니다. 단계는 같습니다.

## 2단계: 사용자 스크립트 허용

프레즌스는 해당 웹사이트에서만 실행되는 작은 스크립트입니다. 브라우저는 이를 사용자 스크립트라고 부르며 실행 전에 권한을 요청합니다.

- **Chrome, Edge, Brave, Opera**: `chrome://extensions`(또는 `edge://extensions`, `brave://extensions`, `opera://extensions`)를 열고 Nowly의 **세부정보**를 누른 뒤 **사용자 스크립트 허용**을 켜세요. 이전 버전의 Chrome에는 이 스위치가 없으므로 확장 프로그램 페이지 오른쪽 위의 **개발자 모드**를 대신 켜세요.
- **Firefox**: 시작 안내에서 권한을 한 번 요청합니다. 허용하세요.

이 권한으로 정확히 무엇을 할 수 있는지 궁금하다면 [Nowly가 사용자 스크립트 권한을 요청하는 이유](/guides/allow-user-scripts)를 읽어 보세요.

## 3단계: 데스크톱 앱 설치

Discord는 같은 컴퓨터에서 실행되는 프로그램이 로컬 연결로 보내는 Rich Presence만 받습니다. 웹사이트나 확장 프로그램만으로는 이 연결을 열 수 없습니다. 확장 프로그램에 Nowly Desktop으로 표시되는 Nowly 데스크톱 앱이 바로 그 프로그램입니다. 별도의 창은 없고, 필요할 때 브라우저가 실행하여 활동을 Discord에 전달합니다.

[데스크톱 앱 페이지](/desktop)를 여세요. 운영체제를 감지해 알맞은 파일을 제공합니다.

- **Windows**: 설치 파일을 실행하세요. 아직 유료 인증서로 서명되지 않은 빌드이므로 Windows SmartScreen 경고가 표시될 수 있습니다. nowly.me에서 직접 다운로드한 파일인 경우에만 **추가 정보**를 누른 뒤 **실행**을 선택하세요.
- **macOS**: 디스크 이미지를 열고 안내를 따르세요. 앱은 Apple 공증을 받았으므로 Gatekeeper에서 허용됩니다.
- **Linux**: Debian, Ubuntu, Mint에서는 `.deb` 패키지를 설치하세요. 다른 배포판에서는 압축 파일을 내려받고 안에 든 설치 스크립트를 실행하세요. 문제가 생기면 [Linux에서 Nowly 사용하기](/guides/nowly-on-linux)를 확인하세요.

## 4단계: Discord를 열고 활동 설정 확인

Discord 데스크톱 앱을 실행한 채로 두세요. 이어서 Discord의 **사용자 설정**에서 **활동 개인정보 보호**를 열고 현재 활동 공유가 켜져 있는지 확인하세요. Discord 버전에 따라 문구가 다르지만 활동이나 상태 메시지 공유를 언급하는 스위치입니다.

상태가 **오프라인으로 표시**이면 Nowly에서 무엇을 보내든 다른 사람에게 활동이 보이지 않는다는 점도 기억하세요.

## 5단계: 첫 프레즌스 설치

프레즌스는 [라이브러리](/library)에서 받을 수 있습니다. YouTube는 몇 초 만에 영상을 재생할 수 있어 첫 확인에 가장 좋습니다.

1. [YouTube 프레즌스](/library/youtube) 페이지를 여세요.
2. 페이지에서 확장 프로그램을 감지할 때까지 기다렸다가 **설치**를 누르세요.
3. YouTube에서 영상을 열고 재생하세요.

사이드 패널에서 나가지 않고도 프레즌스를 설치할 수 있습니다. 확장 프로그램 안의 **라이브러리** 탭에도 같은 목록이 있습니다. 모든 프레즌스는 설치 전에 디지털 서명이 검증됩니다.

## 6단계: 진단 결과 확인

Nowly 사이드 패널을 여세요. 진단에는 여섯 가지 항목이 있고 준비되면 각각 초록색으로 바뀝니다.

| 확인 항목 | 의미 |
| --- | --- |
| 확장 프로그램 설치됨 | 이 브라우저에서 확장 프로그램이 실행 중입니다. |
| 사용자 스크립트 허용됨 | 브라우저가 Nowly 프레즌스 실행을 허용합니다. |
| Nowly Desktop 감지됨 | 데스크톱 앱이 확장 프로그램에 응답했습니다. |
| Discord 연결됨 | 데스크톱 앱이 Discord 앱에 연결됐습니다. |
| 프레즌스 설치됨 | 프레즌스가 하나 이상 설치됐습니다. |
| 활동 감지됨 | 현재 탭에서 프레즌스가 표시할 활동을 찾았습니다. |

여섯 항목이 모두 초록색이면 Discord 프로필을 확인하세요. 영상 제목, 채널, 썸네일, 진행 표시줄과 함께 **YouTube 시청 중**이 보여야 합니다. 빨간색 항목이 남아 있다면 그 항목부터 해결하세요. 연결 과정에서 다음으로 확인할 부분입니다. [문제 해결 체크리스트](/guides/rich-presence-not-showing)에서 각 상황을 다룹니다.

## 친구에게 보이는 내용

YouTube 프레즌스는 영상이 재생될 때 제목, 채널 이름, 썸네일, 경과 시간과 **영상 보기** 버튼을 보여줍니다. 일시정지하면 재생 아이콘이 일시정지 아이콘으로 바뀝니다. YouTube 홈이나 검색 화면을 둘러볼 때는 기본적으로 아무것도 표시되지 않습니다. 대부분의 프레즌스는 실제로 보고 듣는 내용만 공유하며, 둘러보기 활동은 각 프레즌스에서 직접 켜는 옵션입니다.
