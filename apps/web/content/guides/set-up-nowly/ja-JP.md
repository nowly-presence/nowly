Nowlyは、ウェブサイトで視聴中、再生中、閲覧中の内容をDiscord Rich Presenceとして表示します。名前の下にタイトル、画像、進行状況のバー、場合によってはボタンが付いたカードが現れます。設定に必要なのは約5分。ブラウザ拡張機能、小さなデスクトップアプリ、そして表示したいサイトごとのプレゼンスを用意します。このガイドでは順番に設定し、最後に接続を確認します。

## 始める前に必要なもの

- **パソコン**：Windows 10または11、macOS 11 Big Sur以降、または64ビット版Linux。
- **ブラウザ**：Chrome、Edge、Brave、OperaなどのChromium系ブラウザ、またはFirefox。
- **Discordデスクトップアプリ**：インストールしてログインしておいてください。ブラウザのタブやスマートフォンで開いたDiscordは、ほかのプログラムからRich Presenceを受け取れないため、Nowlyとは連携できません。

Nowlyのアカウントは不要です。以下はすべて無料で使えます。

## ステップ1：ブラウザ拡張機能をインストール

普段使うブラウザで[拡張機能のページ](/extension)を開きます。ボタンを押すと、そのブラウザに適したストアへ移動します。Chrome、Edge、Brave、OperaならChrome Web Store、FirefoxならFirefox Add-onsです。**追加**をクリックして確認し、Nowlyのアイコンをツールバーに固定すると、いつでもワンクリックで開けます。

Nowlyはブラウザのサイドパネル（Firefoxではサイドバー）で動作します。ツールバーのアイコン、または**Ctrl+Shift+Y**（Macでは**Cmd+Shift+Y**）で開けます。初回は短いセットアップ案内が表示されます。それに従っても、このガイドを読み進めても、手順は同じです。

## ステップ2：ユーザースクリプトを許可

各プレゼンスは、対応するウェブサイトだけで動作する小さなスクリプトです。ブラウザではこれをユーザースクリプトと呼び、実行する前に許可を求めます。

- **Chrome、Edge、Brave、Opera**：`chrome://extensions`（または`edge://extensions`、`brave://extensions`、`opera://extensions`）を開き、Nowlyの**詳細**を選んで、**ユーザースクリプトを許可**をオンにします。古いChromeではこの切り替えがまだないため、拡張機能ページ右上の**デベロッパーモード**をオンにしてください。
- **Firefox**：初回セットアップで一度だけ求められる権限を許可します。

許可する内容を詳しく知りたい場合は、[Nowlyがユーザースクリプトの許可を求める理由](/guides/allow-user-scripts)をご覧ください。

## ステップ3：デスクトップアプリをインストール

Discordは、同じパソコンで動くプログラムからのローカル接続を通じてのみRich Presenceを受け取ります。ウェブサイトや拡張機能だけでは、この接続を開けません。Nowlyデスクトップアプリ（拡張機能内ではNowly Desktopと表示）がその役割を担います。ウィンドウはなく、必要なときにブラウザから起動され、アクティビティをDiscordへ渡します。

[デスクトップアプリのページ](/desktop)を開いてください。お使いのOSが検出され、適切なファイルが案内されます。

- **Windows**：インストーラーを実行します。有料の署名証明書をまだ使用していないため、Windows SmartScreenが警告を表示する場合があります。nowly.meからダウンロードしたファイルであることを確認した場合に限り、**詳細情報**、**実行**の順に選んでください。
- **macOS**：ディスクイメージを開き、案内に従います。アプリはAppleによる公証済みで、Gatekeeperに受け入れられます。
- **Linux**：Debian、Ubuntu、Mintでは`.deb`パッケージをインストールします。その他のディストリビューションではアーカイブをダウンロードし、中のインストールスクリプトを実行します。問題があれば[LinuxでNowlyを使う方法](/guides/nowly-on-linux)をご覧ください。

## ステップ4：Discordを開き、アクティビティ設定を確認

Discordデスクトップアプリを起動したままにします。Discord側でアクティビティの表示が許可されていることも確認しましょう。**ユーザー設定**から**アクティビティのプライバシー**を開き、現在のアクティビティを共有する設定をオンにします。Discordのバージョンによって表記は異なりますが、アクティビティまたはステータスメッセージに関する切り替えです。

また、ステータスを**オフライン表示**にすると、Nowlyが情報を送っていても他の人には見えません。

## ステップ5：最初のプレゼンスをインストール

プレゼンスは[ライブラリ](/library)から入手できます。最初の動作確認には、すぐに動画を再生できるYouTubeがおすすめです。

1. [YouTubeのプレゼンス](/library/youtube)を開きます。
2. 拡張機能が検出されるまで待ち、**インストール**をクリックします。
3. YouTubeで動画を開き、再生します。

拡張機能のサイドパネルからもインストールできます。**ライブラリ**タブには同じ一覧が表示されます。各プレゼンスはインストール前にデジタル署名が検証されます。

## ステップ6：診断結果を確認

Nowlyのサイドパネルを開きます。診断には6項目があり、準備が整った項目は緑色になります。

| 確認項目 | 意味 |
| --- | --- |
| 拡張機能がインストール済み | このブラウザで拡張機能が動作しています。 |
| ユーザースクリプトが許可済み | ブラウザがNowlyのプレゼンスの実行を許可しています。 |
| Nowly Desktopを検出 | デスクトップアプリが拡張機能に応答しています。 |
| Discordに接続済み | デスクトップアプリがDiscordアプリに接続できています。 |
| プレゼンスがインストール済み | プレゼンスが少なくとも1つインストールされています。 |
| アクティビティを検出 | 現在のタブで表示できる内容をプレゼンスが見つけました。 |

6項目すべてが緑色になったら、Discordのプロフィールを見てください。**YouTubeを視聴中**とともに、動画タイトル、チャンネル、サムネイル、進行状況のバーが表示されるはずです。赤い項目が残る場合は、まずその項目に対処してください。接続経路の次の問題を示しています。[トラブルシューティングのチェックリスト](/guides/rich-presence-not-showing)で各ケースを説明しています。

## 友だちに見えるもの

YouTubeのプレゼンスでは、再生中の動画のタイトル、チャンネル名、サムネイル、経過時間に加え、**動画を見る**ボタンが表示されます。一時停止すると、再生アイコンが一時停止アイコンに変わります。YouTubeのホーム画面や検索を閲覧しているだけなら、初期設定では何も表示されません。ほとんどのプレゼンスが実際の視聴・再生内容だけを共有し、閲覧中のアクティビティはプレゼンスごとに有効にする方式です。

## 次にできること

- [ライブラリ](/library)から、実際に使うプラットフォームを追加しましょう。Netflix、Twitch、Crunchyroll、Spotifyなど、40以上があります。
- 一時停止、タブの非表示、共有する時間帯の指定は、[Discordに表示する内容を細かく選ぶ方法](/guides/control-what-discord-shows)をご覧ください。
- 裏側の仕組みに興味があれば、[Discord Rich Presenceとは？](/guides/what-is-discord-rich-presence)をお読みください。
