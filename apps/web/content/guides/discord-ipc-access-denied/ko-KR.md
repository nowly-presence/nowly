Windows에서 Nowly의 **Nowly Desktop 감지됨**은 초록색인데 **Discord 연결됨**은 빨간색이고 로그에 다음과 같은 내용이 나타날 때가 있습니다.

```text
open \\.\pipe\discord-ipc-0: Access is denied.
```

Nowly에 Discord가 연결을 차단한다는 메시지가 나올 수도 있고 데스크톱 앱이 Windows 알림을 표시할 수도 있습니다. 원인은 거의 항상 같습니다. Nowly나 Discord의 버그가 아니라, 브라우저는 일반 권한인데 Discord는 관리자 권한으로 실행 중인 것입니다.

## discord-ipc-0이란?

게임을 비롯해 Discord 활동을 설정하려는 프로그램은 명명된 파이프라는 로컬 채널을 통해 Discord 앱과 통신합니다. Windows에서 첫 번째 파이프의 이름은 `\\.\pipe\discord-ipc-0`입니다. Discord가 실행될 때 만들고 Nowly 데스크톱 앱이 열어서 활동을 보냅니다.

이 단계에서 정보는 인터넷으로 나가지 않습니다. 같은 컴퓨터에서 실행 중인 두 프로그램 사이의 통신입니다.

## Windows에서 '액세스가 거부되었습니다'라고 나오는 이유

Windows는 관리자 권한 프로그램과 일반 프로그램을 구분합니다. **관리자 권한으로 실행**한 프로그램은 더 높은 무결성 수준에서 작동하고, 그 프로그램이 만든 객체인 Discord의 명명된 파이프 역시 일반 권한의 프로그램으로부터 보호됩니다.

브라우저는 일반 권한으로 실행되므로 브라우저가 시작한 Nowly 데스크톱 앱도 일반 권한입니다. Discord를 관리자 권한으로 시작했다면 Windows가 일반 권한의 앱이 관리자 수준의 파이프를 열지 못하게 막고 연결은 **Access is denied** 오류로 실패합니다.

게임이나 다른 Rich Presence 도구도 똑같은 문제를 겪기 때문에 'Discord에 게임이 표시되지 않는다'는 증상과 이 오류가 함께 나타나곤 합니다.

## 단계별 해결 방법

1. **Discord를 완전히 종료하세요.** 창을 닫는 것만으로는 부족합니다. 시계 근처 알림 영역의 Discord 아이콘을 마우스 오른쪽 버튼으로 누르고 **Discord 종료**를 선택하세요.
2. **Discord 프로세스가 남지 않았는지 확인하세요.** **Ctrl+Shift+Esc**로 작업 관리자를 열고 남아 있는 `Discord.exe` 프로세스를 모두 끝내세요.
3. **관리자 권한 설정을 해제하세요.** 사용하는 Discord 바로 가기를 마우스 오른쪽 버튼으로 누르고 **속성**을 연 뒤 **호환성** 탭에서 **관리자 권한으로 이 프로그램 실행**을 해제하세요. 같은 **속성** 창의 **바로 가기** 탭에서 **고급**을 누르고 **관리자 권한으로 실행**도 해제되어 있는지 확인하세요. **모든 사용자에 대한 설정 변경**에 해당 옵션이 켜져 있다면 거기에서도 끄세요.
4. **일반적인 방법으로 Discord를 실행하세요.** 보통 때처럼 두 번 클릭하면 됩니다.
5. **Nowly를 다시 연결하세요.** 사이드 패널에서 **다시 연결**을 누르거나 브라우저를 다시 시작하세요.

이제 **Discord 연결됨**이 초록색으로 바뀌고 몇 초 안에 활동이 표시되어야 합니다.

## Discord가 계속 관리자 권한으로 실행된다면

- 사용하는 모든 바로 가기를 확인하세요. 바탕 화면, 시작 메뉴, 작업 표시줄의 바로 가기는 설정이 각각 다를 수 있습니다.
- Windows 시작과 함께 Discord가 실행된다면 최고 권한을 사용하도록 설정된 예약 작업이나 타사 시작 프로그램에서 실행하는 것일 수 있습니다. 그 옵션을 해제하거나 권한 없이 실행하도록 항목을 다시 만드세요.
- 관리자 권한으로 실행한 게임 안에서 눌러서 말하기 기능을 쓰려고 Discord도 관리자 권한으로 실행하는 경우가 있습니다. 이때는 선택해야 합니다. Discord와 게임을 모두 일반 권한으로 실행하거나, 브라우저의 Rich Presence가 Discord에 도달하지 못하는 상태를 감수해야 합니다.

## 피해야 할 방법

문제를 우회하려고 브라우저를 관리자 권한으로 실행하거나 Nowly 데스크톱 앱을 강제로 관리자 권한으로 실행하지 마세요. 브라우저는 네이티브 메시징으로 데스크톱 앱을 직접 시작합니다. 브라우저 전체에 관리자 권한을 주면 웹페이지에 문제가 생겼을 때 시스템 전체가 위험해질 수 있습니다. 올바른 해결책은 Discord를 일반 권한으로 되돌리는 것입니다.

## Discord PTB와 Canary

Windows에서 Nowly 데스크톱 앱은 첫 번째 Discord 파이프인 `discord-ipc-0`에 연결합니다. 일반 Discord와 Discord PTB 또는 Canary를 동시에 실행하면 먼저 실행한 앱이 그 파이프를 차지하고 활동도 그 앱에만 표시됩니다. 혼란을 피하려면 Discord 앱을 하나만 실행하세요.

## 그래도 연결되지 않나요?

오류는 사라졌는데 상태가 비어 있다면 다른 부분에 문제가 있습니다. [문제 해결 체크리스트](/guides/rich-presence-not-showing)로 돌아가 **사용자 스크립트 허용됨** 단계부터 확인하세요. 위 방법을 따랐는데도 로그에 **Access is denied**가 계속 나타난다면 Windows 버전과 Discord 실행 방법을 적어 Nowly Discord 서버에 문의하세요.
