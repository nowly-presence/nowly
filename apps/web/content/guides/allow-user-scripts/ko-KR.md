Nowly를 설정할 때 대부분의 확장 프로그램은 요청하지 않는 권한 하나를 요구합니다. 사용자 스크립트를 실행할 권한입니다. 낯선 기술 용어이고 브라우저 경고가 걱정스러울 수도 있습니다. 이 가이드에서는 권한의 실제 범위, Nowly에 필요한 이유, 지원 브라우저별 허용 방법을 설명합니다.

## 사용자 스크립트란?

사용자 스크립트는 방문한 웹페이지에서 페이지 자체 코드와 함께 실행되는 작은 JavaScript 코드입니다. 브라우저에서는 오래전부터 Tampermonkey 같은 부가 기능을 통해 이를 지원해 왔습니다.

현재 Chrome 확장 프로그램 형식인 Manifest V3에서는 둘을 명확히 구분합니다. 스토어에 올라간 확장 프로그램 패키지에 포함된 코드는 확장 프로그램과 함께 심사를 받습니다. 설치 후 확장 프로그램이 추가하는 코드는 사용자 스크립트로 취급하며, 명시적으로 허용해야 브라우저가 실행합니다. Firefox도 자체 권한 요청으로 같은 원칙을 따릅니다.

## 프레즌스가 사용자 스크립트인 이유

Nowly 프레즌스 하나는 웹사이트 하나의 구조를 이해하는 코드입니다. YouTube에서 영상 제목이 있는 곳, Netflix가 에피소드 번호를 제공하는 방식, Spotify의 재생·일시정지 여부를 파악합니다. 이런 프레즌스는 40개 이상이고 웹사이트 화면 구성도 자주 바뀝니다.

모든 프레즌스를 확장 프로그램에 넣으면 수정할 때마다 새 확장 프로그램 버전을 올리고 스토어 심사를 받아야 합니다. 방문하지도 않는 수십 개 사이트의 코드까지 갖고 있어야 합니다. 대신 확장 프로그램은 작게 유지하고 [라이브러리](/library)에서 필요한 프레즌스를 따로 설치합니다.

- 사용하는 플랫폼만 설치할 수 있습니다.
- 문제가 생긴 프레즌스는 확장 프로그램을 업데이트하지 않고도 몇 시간 안에 수정해 다시 배포할 수 있습니다.
- 프레즌스는 지정된 주소에서만 실행됩니다. 예를 들어 YouTube 프레즌스는 `www.youtube.com`과 `m.youtube.com`에서만 실행됩니다.

## Nowly가 프레즌스를 안전하게 관리하는 방법

다운로드한 코드가 실행되기 때문에 브라우저에서 먼저 허락을 구합니다. Nowly도 추가 검사를 합니다.

- 공식 프레즌스는 모두 Nowly 팀이 ECDSA P-256 키로 서명합니다. 스크립트를 등록하기 전에 확장 프로그램이 서명과 번들·메타데이터의 SHA-256 해시를 검증합니다. 서명 후 수정된 스크립트는 거부됩니다.
- 모든 프레즌스의 소스 코드가 공개되어 있어 설치 전에 누구나 작동 방식을 확인할 수 있습니다.
- 프레즌스가 찾은 정보를 확장 프로그램에 전달하면, 확장 프로그램은 컴퓨터의 데스크톱 앱을 거쳐 Discord로 보냅니다. 이 경로에 Nowly 서버는 없으며, 프레즌스 코드는 서명 전에 검토합니다.
- 서명되지 않은 패키지는 수동으로 불러온 개발용 빌드에서만 허용하며 스토어 버전에서는 허용하지 않습니다.

## Chrome, Edge, Brave, Opera에서 허용하기

1. 확장 프로그램 페이지를 여세요. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`, Brave는 `brave://extensions`, Opera는 `opera://extensions`입니다.
2. **Nowly**를 찾아 **세부정보**를 누르세요.
3. **사용자 스크립트 허용**을 켜세요.
4. Discord에 표시하려는 웹사이트의 탭을 새로고침하세요.

이전 버전의 Chrome 및 Chromium 브라우저에는 **사용자 스크립트 허용** 스위치가 아직 없습니다. 이때는 확장 프로그램 페이지 오른쪽 위의 **개발자 모드**를 켜면 사용자 스크립트를 사용할 수 있습니다. 이를 켜도 스토어 버전 Nowly의 업데이트나 검증 방식은 바뀌지 않습니다.

## Firefox에서 허용하기

Firefox는 Nowly 시작 안내에서 자체 권한 창을 한 번 띄웁니다. 허용하면 끝입니다.

권한 창을 닫았다면 `about:addons`를 열고 **Nowly**를 선택한 뒤 **권한** 탭에서 사용자 스크립트 권한을 허용하세요. 그런 다음 표시하려는 탭을 새로고침하세요.

## 제대로 작동하는지 확인하기

**Ctrl+Shift+Y**(Mac에서는 **Cmd+Shift+Y**)로 Nowly 사이드 패널을 여세요. 진단의 **사용자 스크립트 허용됨** 항목이 초록색이어야 합니다. 그러면 Nowly가 설치된 프레즌스를 등록합니다. 다음으로 지원 페이지에서 **활동 감지됨** 항목을 확인하세요.

권한을 켰는데도 해당 항목이 빨간색이라면 다음을 확인하세요.

- 확장 프로그램 페이지에서 Nowly를 새로고침하거나 브라우저를 다시 시작하세요.
- 다른 확장 프로그램이 아닌 Nowly의 설정을 변경했는지 확인하세요.
- 학교나 회사에서 관리하는 브라우저라면 정책상 모든 확장 프로그램의 사용자 스크립트가 차단될 수 있습니다.

## 이 권한으로 할 수 없는 일

사용자 스크립트를 허용해도 Nowly가 비밀번호, 다른 확장 프로그램 또는 파일에 접근할 수 있게 되는 것은 아닙니다. 특정 웹사이트에 스크립트를 등록할 수 있을 뿐이며, 브라우저는 여전히 각 스크립트에 지정된 주소만 허용합니다. Nowly는 설치한 프레즌스가 지원하지 않는 페이지를 읽는 데 이 권한을 사용하지 않습니다.

언제든 권한을 끌 수 있습니다. 그러면 프레즌스 실행과 Discord 활동 표시가 멈추지만 삭제되는 것은 없습니다. 다시 켜면 이전 상태로 이어서 작동합니다.

## 요약

사용자 스크립트 덕분에 Nowly는 작은 확장 프로그램으로 수십 개 웹사이트를 지원하고, 프레즌스를 빠르게 업데이트하며, 필요한 것만 설치할 수 있습니다. 브라우저마다 한 번 권한을 허용해야 하며, 이 권한을 사용하는 프레즌스는 모두 서명되고 코드가 공개되어 있으며 해당 웹사이트에서만 실행됩니다.
