무엇을 시청하는지 아는 도구라면 그 정보가 어디로 가는지 명확히 설명해야 합니다. 이 가이드에서는 활동이 이동하는 단계를 따라가며 기기에 남는 정보를 정리하고, 선택적 기능을 통해 Nowly 서버와 통신하는 경우도 솔직하게 알려드립니다. 공식 기준인 [개인정보처리방침](/privacy)을 이해하기 쉽게 풀어 쓴 안내입니다.

## 핵심만 먼저

활동은 웹페이지에서 사용자 컴퓨터의 Discord 앱으로만 전달됩니다. nowly.me나 Nowly API를 거치지 않습니다. 이용 통계는 직접 켜지 않으면 꺼져 있고 계정도 선택 사항입니다.

## 활동이 전달되는 경로

지원되는 웹사이트에서 재생 버튼을 누르면 다음 일이 일어납니다.

1. **프레즌스가 페이지를 읽습니다.** 해당 사이트의 프레즌스가 브라우저 탭에서 제목, 에피소드 번호, 채널 이름, 영상 재생 여부 등 필요한 정보를 읽습니다.
2. **확장 프로그램이 활동을 준비합니다.** 일시 중지, 일정, 개인정보 보호 모드, 언어 등 사용자 설정을 적용해 Rich Presence를 구성합니다.
3. **데스크톱 앱이 활동을 받습니다.** 확장 프로그램이 브라우저와 같은 컴퓨터의 프로그램 사이를 잇는 네이티브 메시징으로 Nowly 데스크톱 앱에 전달합니다.
4. **Discord가 로컬로 받습니다.** 데스크톱 앱이 Discord의 로컬 연결로 Discord 앱에 전달합니다.
5. **Discord가 공유합니다.** Discord 앱이 자체 서버로 전송해 친구에게 보여줍니다. 여기에는 Discord의 개인정보처리방침이 적용됩니다.

1~4단계는 모두 사용자 컴퓨터에서 진행됩니다. 이 경로에 Nowly 서버는 포함되지 않습니다.

## 프레즌스가 읽는 정보

프레즌스는 자신이 만들어진 사이트의 페이지에서 상태 표시에 필요한 정보만 읽습니다. YouTube 프레즌스는 영상 제목, 채널, 썸네일 주소, 재생 위치를 읽습니다. Spotify 프레즌스는 브라우저에서 재생 중인 곡을 읽습니다. 다른 탭, 방문 기록, 양식 입력란, 비밀번호는 읽지 않습니다.

일부 웹사이트는 세부 정보를 자체 데이터로만 제공합니다. 예를 들어 Netflix 프레즌스는 Netflix 탭 안에서 Netflix 웹사이트에 재생 중인 작품명과 에피소드를 요청합니다. Netflix 페이지 자체가 하는 방식과 같습니다.

## 이미지와 이미지 프록시

Discord는 상태에 표시할 이미지를 내려받아야 합니다. 대부분의 플랫폼 이미지는 공개되어 Discord가 직접 불러옵니다. Netflix 포스터처럼 그대로 불러올 수 없는 이미지도 있습니다. 이때 프레즌스는 Nowly 이미지 프록시를 사용합니다. 이미지 주소를 Nowly API로 전달하면 API가 이미지를 가져와 Discord에 표시할 수 있게 합니다.

이 주소는 시청 중인 작품과 관련될 수 있으므로 알아두는 것이 좋습니다. 프록시는 이 목적에만 사용하고 광고용 프로필을 만드는 데 쓰지 않습니다. 로그는 서비스 운영과 보안에 필요한 기간 동안만 보관합니다.

## 컴퓨터에 남는 정보

- 설치한 프레즌스, 각 설정, 활성화 여부.
- 현재 활동의 제목, 플랫폼, 재생 시간, 이미지 주소.
- 문제 해결에 도움이 되는 최근 동작과 방문한 지원 페이지 주소가 기록된 디버그 로그.
- 캐시 폴더에 저장되는 데스크톱 앱 로그 `nowly-host.log`.
- 확장 프로그램에 표시하려고 Discord 앱에서 가져온 Discord 이름과 아바타의 로컬 사본.

확장 프로그램을 초기화하거나 제거하면 여기에 저장된 정보가 모두 지워지고, 데스크톱 앱 로그도 언제든 삭제할 수 있습니다.

## 권한을 쉬운 말로 설명하면

- **웹사이트 접근**: 가벼운 스크립트가 열린 페이지가 지원 플랫폼에 속하는지 확인해 사이드 패널에서 알맞은 프레즌스를 추천합니다. 방문 기록을 다른 곳으로 보내지 않습니다.
- **사용자 스크립트**: 설치한 프레즌스가 해당 웹사이트에서 실행되게 합니다. [Nowly가 사용자 스크립트 권한을 요청하는 이유](/guides/allow-user-scripts)를 참고하세요.
- **네이티브 메시징**: 확장 프로그램이 컴퓨터의 데스크톱 앱과 통신하게 합니다.
- **저장소**: 설정과 프레즌스를 브라우저에 보관합니다.

## 사용자가 선택할 때만 Nowly에 전달되는 정보

- **이용 통계**는 기본적으로 꺼져 있습니다. 켜면 Nowly API에 임의의 기기 식별자, 브라우저, 운영체제, 언어, 버전과 설치 등의 이벤트가 전달됩니다. 페이지, 제목, 검색어, Discord 신원은 전달되지 않습니다.
- **계정**은 선택 사항입니다. Discord로 로그인하면 설정과 설치한 프레즌스 목록이 브라우저 간에 동기화됩니다. 현재 활동, 탭, 방문 기록은 동기화되지 않습니다.
- 프레즌스 페이지에서 보낸 **좋아요와 신고**는 신고 내용과 함께 Nowly API에 전달됩니다.
- 라이브러리에서 **프레즌스를 다운로드**하면 일반 다운로드와 마찬가지로 Nowly 서버와 CDN에 접속합니다.

## 데이터를 직접 관리하기

- [내 데이터](/consent) 페이지에서 이용 통계를 켜거나 끄고 기기에 대해 저장된 모든 내용을 내보내거나 삭제할 수 있습니다.
- [계정 페이지](/account)에서 계정 데이터를 다운로드하거나 계정을 삭제할 수 있습니다.
- 확장 프로그램을 제거하면 로컬에 저장한 내용이 모두 지워집니다.

## Discord는 이 정보를 어떻게 처리하나요?

활동이 Discord에 도착하면 Discord는 프로필을 볼 수 있는 사람에게 이를 보여주고 자체 개인정보처리방침에 따라 처리합니다. Nowly가 그 부분을 바꿀 수는 없지만 처음에 무엇을 보낼지는 사용자가 정할 수 있습니다. [Discord에 표시할 내용 직접 고르기](/guides/control-what-discord-shows)를 참고하세요.
