Rich Presence는 현재 페이지, 해당 웹사이트의 프레즌스, 브라우저 확장 프로그램, 데스크톱 앱, Discord 앱이라는 다섯 고리를 거칩니다. 상태가 비어 있다면 그중 한 곳의 연결이 끊긴 것입니다. 전부 다시 설치하기보다 어느 부분이 문제인지 찾는 편이 빠릅니다. 아래 항목을 순서대로 확인하세요. 대부분은 처음 네 항목에서 해결됩니다.

## 먼저 Nowly 진단 결과 확인

공유하려는 탭에서 Nowly 사이드 패널을 여세요(**Ctrl+Shift+Y**, Mac에서는 **Cmd+Shift+Y**). 진단에는 **확장 프로그램 설치됨**, **사용자 스크립트 허용됨**, **Nowly Desktop 감지됨**, **Discord 연결됨**, **프레즌스 설치됨**, **활동 감지됨**이라는 여섯 항목이 표시됩니다.

위에서부터 확인하다가 처음으로 초록색이 아닌 항목에서 멈추세요. 아래에서는 각 항목과 브라우저 진단에서 파악할 수 없는 몇 가지 상황을 다룹니다.

## 1. Discord 데스크톱 앱을 사용 중인지 확인

Rich Presence는 컴퓨터에 설치한 Discord 앱에서만 작동합니다. 같은 계정으로 로그인했더라도 브라우저 탭, 휴대폰 또는 다른 컴퓨터의 Discord만으로는 표시되지 않습니다.

브라우저 버전과 데스크톱 버전을 둘 다 사용한다면 브라우저의 Discord를 닫아 보세요. 실제로는 데스크톱 앱을 통해 다른 사람에게 활동이 보이는데 브라우저에서는 상태가 비어 있다고 생각할 수 있습니다.

## 2. Discord에서 활동 공유를 허용했는지 확인

Discord는 활동을 받았더라도 숨길 수 있습니다.

- **사용자 설정**에서 **활동 개인정보 보호**를 열고 현재 활동 공유 옵션을 켜세요.
- 상태를 확인하세요. **오프라인으로 표시**하면 모두에게 활동이 숨겨집니다.
- 일부 서버에서는 서버별 개인정보 설정으로 그 서버에만 활동 공유를 끌 수 있습니다. 다른 사람은 보는데 특정 서버의 친구에게만 보이지 않는다면 이 설정을 확인하세요.

구분하는 쉬운 방법이 있습니다. 내 프로필에는 활동이 보이는데 친구에게 보이지 않는다면 Nowly가 아닌 Discord의 개인정보 설정 문제입니다.

## 3. 데스크톱 앱이 설치되어 실행 중인지 확인

**Nowly Desktop 감지됨**이 빨간색이면 확장 프로그램이 데스크톱 앱에 연결할 수 없습니다.

- 아직 설치하지 않았다면 [데스크톱 앱 페이지](/desktop)에서 설치한 뒤 사이드 패널에서 **연결 확인**을 누르세요.
- 방금 설치했다면 사이드 패널을 닫고 다시 열거나 브라우저를 다시 시작해 새 앱을 감지하게 하세요.
- 브라우저와 같은 컴퓨터에 설치하세요. 다른 기기 사이에서는 작동하지 않습니다.
- Linux에서는 `.deb` 패키지가 실제로 설치되지 않았거나 Flatpak·Snap으로 설치한 브라우저가 가장 흔한 원인입니다. [Linux에서 Nowly 사용하기](/guides/nowly-on-linux)를 참고하세요.

## 4. Discord에 연결됐는지 확인

**Nowly Desktop 감지됨**은 초록색인데 **Discord 연결됨**이 빨간색이면 데스크톱 앱이 Discord와 통신할 수 없습니다.

- Discord 데스크톱 앱을 실행하고 완전히 로드될 때까지 기다린 뒤 **연결 확인**을 누르세요.
- Windows에서는 Discord를 관리자 권한으로 실행한 것이 가장 흔한 원인입니다. [discord-ipc-0의 접근 거부 오류 해결하기](/guides/discord-ipc-access-denied)에서 빠르게 고치는 방법을 안내합니다.
- 일반 Discord와 Discord PTB 또는 Canary를 함께 사용한다면 하나만 남기고 종료하세요.

## 5. 사용자 스크립트가 허용됐는지 확인

**사용자 스크립트 허용됨**이 빨간색이라면 브라우저가 프레즌스를 차단하고 있습니다. Nowly 세부정보 페이지에서 **사용자 스크립트 허용**을 켜거나 이전 버전의 Chrome에서는 **개발자 모드**를 켠 뒤 탭을 새로고침하세요. 브라우저별 자세한 방법은 [Nowly가 사용자 스크립트 권한을 요청하는 이유](/guides/allow-user-scripts)에 있습니다.

## 6. 알맞은 프레즌스가 설치되어 켜져 있는지 확인

웹사이트마다 별도 프레즌스가 필요합니다. **프레즌스 설치됨**이 초록색인데 특정 사이트에서 아무것도 표시되지 않는다면 [라이브러리](/library)에서 그 사이트의 페이지를 열고 **설치됨**이라고 나오는지 확인하세요. 이어서 사이드 패널에서 확인하세요.

- 프레즌스가 켜져 있는지 확인하세요.
- 공유가 일시 중지되지 않았는지 확인하세요. 일시 중지 상태라면 패널에 **공유가 일시 중지됨**이라고 나옵니다. 버튼이나 **Ctrl+Shift+U**로 다시 시작하세요.
- 프레즌스가 잠시 꺼져 있지 않은지, 시간을 설정했다면 **공유 일정 외 시간**이 아닌지 확인하세요.
- **이 탭 숨기기**로 현재 탭이 숨겨지지 않았는지 확인하세요.

## 7. 현재 페이지가 프레즌스 지원 범위에 있는지 확인

프레즌스가 현재 페이지에서 표시할 내용을 찾지 못하면 **활동 감지됨**이 빨간색으로 남습니다. 대부분은 다음 두 가지 중 하나입니다.

- **시청이 아닌 둘러보기 중입니다.** 대부분의 프레즌스는 실제로 재생 중인 영상, 에피소드, 곡, 생방송만 공유합니다. 보통 홈, 검색, 카탈로그에서는 프레즌스 설정의 **둘러보기 활동 표시**를 켜지 않으면 아무것도 표시하지 않습니다. 각 프레즌스의 라이브러리 페이지에서 기본 표시 내용을 확인할 수 있습니다.
- **주소가 지원되지 않습니다.** 프레즌스가 실행되는 주소는 라이브러리 페이지의 **지원 사이트**에 나옵니다. 예를 들어 Prime Video는 `primevideo.com`에서 실행됩니다. 사이트가 주소를 옮겼거나 화면 구조를 바꿨다면 프레즌스 페이지의 **문제 신고**를 사용하세요.

프레즌스를 설치하거나 설정을 바꾼 후에는 탭을 한 번 새로고침하세요. 설치 전에 이미 열어 둔 페이지에는 아직 프레즌스가 없습니다.

## 8. 다른 Rich Presence 도구가 간섭하지 않는지 확인

PreMiD나 자체 Rich Presence를 제공하는 음악 플레이어 등 다른 도구가 Nowly가 보낸 활동을 덮어쓰거나 지울 수 있습니다. 테스트하는 동안은 다른 도구를 꺼 두세요. 플레이 중인 게임이 프로필에 표시되는 활동을 차지할 수도 있습니다.

## 9. 그래도 표시되지 않나요?

- 탭을 새로고침한 뒤 브라우저와 Discord를 다시 시작하세요. 단순해 보여도 연결 과정의 모든 부분을 다시 만듭니다.
- 확장 프로그램, 데스크톱 앱, Discord를 업데이트하세요.
- 확장 프로그램의 런타임 로그를 열고 **로그 복사**를 눌러 문의에 첨부하세요. 로그에는 방문한 지원 페이지의 주소가 들어갈 수 있으므로 공유 전에 내용을 확인하세요.
- Nowly Discord 서버에서 문의하거나 한 웹사이트에만 문제가 있다면 라이브러리 페이지에서 해당 프레즌스를 신고하세요.

## 연결 과정을 한 문장으로

페이지가 지원되고 프레즌스가 설치되어 실행 중이며 사용자 스크립트가 허용되고 데스크톱 앱에 연결할 수 있어야 합니다. Discord도 열려 있고 활동 공유가 허용되어야 합니다. 처음 실패한 부분을 찾아 해결하면 대개 나머지도 작동합니다.
