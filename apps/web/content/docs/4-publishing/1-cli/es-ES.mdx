---
title: CLI
description: Usa la CLI de Nowly para crear, compilar, validar y probar presences localmente.
---

The Nowly CLI is published as `@nowly/cli` on npm. Install it globally:
```bash
pnpm i -g @nowly/cli
```

## Modo interactivo

Ejecuta la CLI sin argumentos para abrir un menú interactivo:

```bash
nowly
```

## Crear una presence

```bash
nowly init "Netflix"
```

## Compilar presences

Compila todas las presences:

```bash
nowly build
```

Compila una presence:

```bash
nowly build youtube
```

## Probar una presence localmente

Si solo has clonado el repositorio `presences` (el caso más común para colaboradores), usa `nowly extension` para obtener una build de desarrollo lista para cargar, sin necesitar el monorepo `nowly` completo:

```bash
nowly build youtube
nowly extension youtube
```

Esto descarga la última build de desarrollo de la extensión desde el CDN, empaqueta la(s) presence(s) indicadas, y escribe un archivo `dev-presences.json` dentro. Luego:

1. Abre `chrome://extensions`, activa el **modo desarrollador**
2. **Cargar extensión sin empaquetar** → selecciona la carpeta generada `dist/extension-dev`
3. La presence se instala automáticamente — sin servidor API, sin página de instalación, sin URL de API personalizada

Después de editar la presence, recompílala y vuelve a ejecutar `nowly extension <slug>`, y recarga la extensión.

Para usar una build local específica en lugar de la del CDN, pasa `--from`:

```bash
nowly extension youtube --from ../nowly/apps/extension/dist/chrome
```

### Si tienes el monorepo completo

Si has clonado `nowly` en sí (con `presences` como submódulo), puedes compilar la extensión con todas las presences incluidas directamente:

```bash
pnpm build:extension:dev
```

Recompila la presence modificada y luego la extensión después de cada cambio:

```bash
nowly build youtube
pnpm build:extension:dev
```

Recarga en `chrome://extensions` — la presence ya está instalada y lista para usar.

## Listar presences

```bash
nowly list
```

## Validar metadatos

```bash
nowly validate
```
