## Pourquoi les timestamps comptent

Les timestamps rendent l'activité Discord vivante. Ils montrent depuis combien de temps l'utilisateur regarde ou combien de temps il reste.

## Utiliser createMediaTimestamps

`document` est l'API DOM du navigateur (disponible car les presences s'exécutent comme des scripts de contenu). `Assets` est fourni par le runtime (voir [Assets](/docs/presence-development/assets)).

```ts filename="presence.ts"
import { createMediaTimestamps } from "@nowly/sdk"

const video = document.querySelector("video")

if (video) {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    ...createMediaTimestamps(video),
  })
}
```

## Média en pause

Lorsque le média est en pause, `createMediaTimestamps` ne renvoie aucun timestamp. Cela évite d'afficher une progression de lecture incorrecte.

## Flux en direct

Les flux en direct n'ont souvent pas de durée fixe. Utilisez uniquement un timestamp de début ou omettez les timestamps selon le comportement de la plateforme.
