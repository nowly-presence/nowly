## Comienza con la CLI

Usa la CLI de Nowly para generar una nueva presence:

```bash
nowly init "Ejemplo"
```

La CLI crea los metadatos, un script de presence y los recursos requeridos.

## Código básico de presence

`Presence` y `Assets` son proporcionados por el runtime — consulta [Presence API](/docs/presence-development/presence-api) y [Assets](/docs/presence-development/assets).
`document` es la API DOM estándar del navegador, disponible porque las presences se ejecutan como scripts de contenido en la extensión.

Solo `PresenceType` (y otros helpers como `createMediaTimestamps`) deben importarse desde `@nowly/sdk`.

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    state: document.location.hostname,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

## Flujo de runtime

Cuando el usuario visita una URL coincidente, Nowly carga tu presence. La presence lee el estado de la página y llama a `setActivity`. La extensión reenvía ese payload al Nowly Host, que actualiza Discord.

## Ciclo de desarrollo

<Steps>
<Step title="Generar" description="Crea la carpeta de la presence, los metadatos y los recursos requeridos.">

```bash
nowly init "Ejemplo"
```

</Step>
<Step title="Configurar" description="Establece el nombre, autor, URL compatibles, categoría, color y descripciones localizadas.">

Edita `metadata.json` — consulta [Metadata](/docs/presence-development/metadata) para todos los campos disponibles.

</Step>
<Step title="Implementar" description="Escribe la lógica de la presence usando el SDK de Presence.">

```typescript filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

</Step>
<Step title="Validar" description="Comprueba que la estructura de metadatos sea correcta y que los recursos estén en su lugar.">

```bash
nowly validate
```

</Step>
<Step title="Compilar" description="Compila la presence en un paquete independiente.">

```bash
nowly build ejemplo
```

</Step>
<Step title="Empaquetar" description="Reconstruye la extensión con tu presence incluida.">

```bash
pnpm build:extension:dev
```

</Step>
<Step title="Recargar" description="La presence se instala automáticamente en cuanto la extensión se recarga.">

Recarga en `chrome://extensions`

</Step>
<Step title="Probar" description="Abre el sitio web objetivo — la presence se activa automáticamente.">

Visita el sitio

</Step>
</Steps>

Repite **Implementar** → **Compilar** → **Empaquetar** → **Recargar** después de cada cambio de código.
