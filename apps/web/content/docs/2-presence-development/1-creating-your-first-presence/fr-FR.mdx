## Commencez avec la CLI

Utilisez la CLI Nowly pour générer une nouvelle presence&nbsp;:

```bash
nowly init "Exemple"
```

La CLI crée les métadonnées, un script de presence et les assets requis.

## Code de base d'une presence

`Presence` et `Assets` sont fournis par le runtime — voir [Presence API](/docs/presence-development/presence-api) et [Assets](/docs/presence-development/assets).
`document` est l'API DOM standard du navigateur, disponible car les presences s'exécutent comme des scripts de contenu dans l'extension.

Seuls `PresenceType` (et autres helpers comme `createMediaTimestamps`) doivent être importés depuis `@nowly/sdk`.

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    state: document.location.hostname,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

## Flux d'exécution

Lorsque l'utilisateur visite une URL correspondante, Nowly charge votre presence. La presence lit l'état de la page et appelle `setActivity`. L'extension transmet ce payload à Nowly Host, qui met à jour Discord.

## Boucle de développement

<Steps>
<Step title="Générer" description="Créez le dossier de la presence, les métadonnées et les assets requis.">

```bash
nowly init "Exemple"
```

</Step>
<Step title="Configurer" description="Définissez le nom, l'auteur, les URL prises en charge, la catégorie, la couleur et les descriptions localisées.">

Modifiez `metadata.json` — voir [Metadata](/docs/presence-development/metadata) pour tous les champs disponibles.

</Step>
<Step title="Implémenter" description="Écrivez la logique de la presence à l'aide du SDK Presence.">

```typescript filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

</Step>
<Step title="Valider" description="Vérifiez que la structure des métadonnées est correcte et que les assets sont en place.">

```bash
nowly validate
```

</Step>
<Step title="Compiler" description="Compilez la presence en un paquet autonome.">

```bash
nowly build exemple
```

</Step>
<Step title="Charger" description="Installez la presence compilée dans le navigateur. Deux méthodes : une extension pré-build, ou un zip à déposer.">

Voir [Charger et tester en local](/docs/presence-development/load-and-test) pour le comparatif complet.

**Première fois** (Nowly pas encore dans le navigateur)&nbsp;: intègre la presence dans une extension prête à charger.

```bash
nowly extension exemple
```

Charge `dist/extension-dev` en unpacked dans `chrome://extensions`.

**Nowly déjà chargé&nbsp;:** crée un zip et dépose-le dans Réglages → Avancé → Debug (mode développeur).

```bash
nowly pack exemple
```

</Step>
<Step title="Tester" description="Ouvrez le site web cible — la presence s'active automatiquement.">

Visitez le site

</Step>
</Steps>

Répétez **Implémenter** → **Compiler** → **Charger** après chaque modification de code.
