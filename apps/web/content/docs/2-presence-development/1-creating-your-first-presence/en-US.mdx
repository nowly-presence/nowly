## Start With the CLI

Use the Nowly CLI to scaffold a new presence:

```bash
nowly init "Example"
```

The CLI creates metadata, a presence script, and required assets.

## Basic Presence Code

`Presence` and `Assets` are provided by the runtime — see [Presence API](/docs/presence-development/presence-api) and [Assets](/docs/presence-development/assets).
`document` is the standard browser DOM API, available because presences run as content scripts in the extension.

Only `PresenceType` (and other helpers like `createMediaTimestamps`) must be imported from `@nowly/sdk`.

```ts filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    state: document.location.hostname,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

## Runtime Flow

When the user visits a matching URL, Nowly loads your presence. The presence reads page state and calls `setActivity`. The extension forwards that payload to Nowly Host, which updates Discord.

## Development Loop

<Steps>
<Step title="Scaffold" description="Generate the presence folder, metadata, and required assets.">

```bash
nowly init "Example"
```

</Step>
<Step title="Configure" description="Set the name, author, supported URLs, category, color, and localized descriptions.">

Edit `metadata.json` — see [Metadata](/docs/presence-development/metadata) for all available fields.

</Step>
<Step title="Implement" description="Write the presence logic using the Presence SDK.">

```typescript filename="presence.ts"
import { PresenceType } from "@nowly/sdk"

const presence = new Presence()

presence.on("UpdateData", async () => {
  await presence.setActivity({
    details: document.title,
    largeImageKey: Assets.Logo,
    type: PresenceType.Watching,
  })
})
```

</Step>
<Step title="Validate" description="Check that your metadata structure is correct and assets are in place.">

```bash
nowly validate
```

</Step>
<Step title="Build" description="Compile the presence into a standalone bundle.">

```bash
nowly build example
```

</Step>
<Step title="Bundle" description="Rebuild the extension with your presence baked in.">

```bash
pnpm build:extension:dev
```

</Step>
<Step title="Reload" description="The presence is auto-installed as soon as the extension reloads.">

Reload at `chrome://extensions`

</Step>
<Step title="Test" description="Open the target website — the presence activates automatically.">

Visit the site

</Step>
</Steps>

Repeat **Implement** → **Build** → **Bundle** → **Reload** after each code change.
