## Structure des dossiers

Une presence se trouve sous `src`, regroupée par la première lettre de son nom&nbsp;:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
`-- assets/
    |-- logo.png
    |-- icon.png
    `-- thumbnail.jpg
```

## metadata.json

`metadata.json` décrit la plateforme, les URL prises en charge, l'auteur, la catégorie, les descriptions localisées et les assets de la place de marché.

## presence.ts

`presence.ts` contient la logique d'exécution. Elle détecte l'état de la page et appelle l'API Presence.

## utils/

Pour les presences complexes, répartissez votre logique dans des fichiers dédiés sous un dossier `utils/`. La presence YouTube, par exemple, organise les helpers DOM, l'analyse des chaînes et la résolution des Shorts dans des modules séparés&nbsp;:

```txt
src/Y/YouTube/
|-- metadata.json
|-- presence.ts
|-- assets/
|   |-- logo.png
|   |-- icon.png
|   `-- thumbnail.jpg
`-- utils/
    |-- categories.ts
    |-- dom.ts
    |-- channel.ts
    |-- text.ts
    |-- bridge.ts
    |-- shorts-dom.ts
    |-- shorts-resolve.ts
    `-- youtube-data.ts
```

Le bundler résout les importations locales depuis `presence.ts`, vous pouvez donc importer les fichiers utilitaires normalement&nbsp;:

```ts filename="presence.ts"
import { findVideo } from "./utils/dom"
import { getChannelInfo } from "./utils/channel"
```
