## Selectores de idioma

Los controles anteriores superponían una bandera en el campo cerrado y usaban un select HTML nativo. Los navegadores quitan el markup custom de `<option>`, así que la lista abierta era solo texto.

El menú de la extensión es ahora un listbox custom (portal, para no recortarse en las tarjetas de ajustes). El footer del sitio sigue usando el Select compartido, con una bandera junto a cada locale.

## Tras una actualización

Las builds de Chrome y Firefox Store siguen abriendo `https://nowly.me/changelog/{versión del manifiesto}` en `onInstalled` con `reason === "update"`. En esta release esa URL es `/changelog/1.4.1`. Un reload unpacked no abre pestaña.
