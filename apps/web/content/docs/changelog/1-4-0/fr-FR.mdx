## Panneau latéral

Le panneau n'est plus une seule page scrollable avec une barre d'actions. **Accueil**, **Bibliothèque** et **Réglages** sont des vues séparées, plus un onglet **Logs** en mode développeur. La vue courante est conservée après un redémarrage du service worker.

La barre de statut confirme Nowly Host quand le pont natif est sain, puis disparaît. Elle reste affichée si l'hôte manque ou est déconnecté. Tant que la pause Discord est active, le badge toolbar et la barre de statut restent visibles.

Le menu overflow du header utilise un bouton plein.

## Pause, raccourcis et menu page

La pause est stockée dans les réglages de l'extension. Les scripts de présence peuvent continuer à tourner ; Discord ne reçoit plus d'activité tant que tu n'as pas repris.

Raccourcis par défaut (Chrome et navigateurs Chromium) :

- **Ctrl+Shift+Y** ouvre le panneau latéral.
- **Ctrl+Shift+U** bascule la pause Discord.

Change-les dans `chrome://extensions/shortcuts`. Les réglages du panneau listent seulement les touches actuelles.

Clic droit sur une page compatible pour ouvrir Nowly sur cette présence, ou une recherche Bibliothèque si elle n'est pas encore installée.

## Bibliothèque

L'onglet **Bibliothèque** est dans la navigation basse, à côté d'Accueil et Réglages. Le catalogue vient de `GET /presences`. L'install télécharge `GET /presences/:slug` dans le service worker, vérifie la signature, puis enregistre le userScript. L'UI ne manipule jamais le bundle.

La recherche et les filtres de catégorie restent dans le panneau. Les catégories passent à la ligne au lieu d'un scroll horizontal. Le champ de recherche garde le fond de carte au focus.

Une ligne ouvre une fiche compacte (visuel, description, URL, installer). Pas de choix de version dans l'extension : ça reste sur le site.

Les mises à jour proposées sur l'accueil appellent le même flux d'install. Le site nowly.me peut toujours installer via le content script.

## Liste et grille

Les présences restent groupées par catégorie. Le sélecteur liste / grille vit dans le header et n'apparaît que sur l'accueil tant que la liste est visible (pas sur une fiche, les réglages ou les logs).

- **Liste :** le nom ouvre la fiche. Activation, planning et réglages restent sur la ligne. Un badge de version s'affiche à côté du statut Activée ou Désactivée.
- **Grille :** icône, nom et statut, alignés à gauche. Toute la carte est cliquable. Activation et planning sont sur la fiche.

La recherche filtre la liste installée sans quitter l'accueil.

## Fiche de gestion

Retour (ou Accueil) ramène à la liste. La carte lecteur est masquée tant qu'une présence est ouverte.

La page est découpée en blocs titrés : visuel, fonctionnalités et URL, crédits, puis Réglages. Un badge de version est collé au nom. Désinstaller est en dessous, isolé, avec une confirmation.

## Réglages et dialogs

Général, Présences et Avancé se plient indépendamment. Avancé ne s'ouvre par défaut que si le mode développeur est déjà actif.

Le snooze et le planning utilisent le même Dialog. Ouvrir une présence affiche maintenant une fiche de gestion, plus un overlay. Les anciens flux en Sheet ont disparu.

## Flux développeur

Si Nowly est déjà chargé en unpacked, compile un zip et dépose-le sur le panneau Debug (mode développeur) :

```
nowly pack youtube
```

Le zip est écrit dans `dist/packs/<slug>.zip` et doit contenir `metadata.json` plus `bundle.js`. Ne zippe pas le source TypeScript.

Si l'extension n'est pas encore chargée, `nowly extension <slug>` écrit toujours un dossier Chrome avec `dev-presences.json`.

Doc : [Charger et tester en local](/docs/presence-development/load-and-test).

## Après une mise à jour

Les builds store Chrome et Firefox ouvrent `https://nowly.me/changelog/1.4.0` (ou la version du manifeste) sur `onInstalled` avec `reason === "update"`. Un reload unpacked n'ouvre pas d'onglet.
