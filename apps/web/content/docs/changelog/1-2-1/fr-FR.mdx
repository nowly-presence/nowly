---
title: 1.2.1
date: 2026-06-25
description: Correctif — suppression des fuites de variables d'environnement de développement dans le build production et simplification de la configuration API.
---

`1.2.1` est une release de maintenance qui corrige un problème de build où des variables d'environnement de développement fuyaient dans l'artefact Chrome Web Store, simplifie la surface de configuration de l'API, et nettoie les pages légales des références obsolètes aux commentaires et à l'OAuth Discord.
