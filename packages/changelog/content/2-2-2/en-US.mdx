## Fixes

- Repeated native heartbeat responses no longer fill Runtime logs. Nowly records a heartbeat when the connection state, status, or native version changes, while keeping errors visible.
- Very short Discord asset tooltips are trimmed and omitted in both the extension and native host before an activity is sent, avoiding invalid RPC payloads.

## Improvements

- The light theme now uses the dark Nowly wordmark for better contrast.
- The Presence API documentation now explains Discord's two-character tooltip requirement and Nowly's automatic sanitization.
