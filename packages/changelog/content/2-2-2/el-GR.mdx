## Διορθώσεις

- Οι πολύ σύντομες συμβουλές εργαλείων των assets του Discord καθαρίζονται και παραλείπονται τόσο στην επέκταση όσο και στον native host πριν από την αποστολή δραστηριότητας, ώστε να αποφεύγονται μη έγκυρα RPC payloads.
- Οι επαναλαμβανόμενες απαντήσεις heartbeat του native host δεν γεμίζουν πλέον τα αρχεία καταγραφής. Το Nowly καταγράφει heartbeat μόνο όταν αλλάζει η κατάσταση σύνδεσης, η κατάσταση ή η έκδοση του native host, ενώ τα σφάλματα παραμένουν ορατά.

## Βελτιώσεις

- Το φωτεινό θέμα χρησιμοποιεί πλέον το σκούρο λογότυπο Nowly για καλύτερη αντίθεση.
- Η τεκμηρίωση του Presence API εξηγεί πλέον την απαίτηση του Discord για tooltips δύο χαρακτήρων και τον αυτόματο καθαρισμό από το Nowly.
