## Fehlerbehebungen

- Sehr kurze Discord-Asset-Tooltips werden sowohl in der Erweiterung als auch im nativen Host bereinigt und vor dem Senden einer Aktivität ausgelassen, damit keine ungültigen RPC-Payloads entstehen.
- Wiederholte native Heartbeat-Antworten füllen die Laufzeitprotokolle nicht mehr. Nowly protokolliert einen Heartbeat nur bei Änderungen von Verbindungsstatus, Status oder nativer Version; Fehler bleiben sichtbar.

## Verbesserungen

- Das helle Design verwendet jetzt das dunkle Nowly-Logo für besseren Kontrast.
- Die Dokumentation der Presence API erklärt jetzt Discords Anforderung von mindestens zwei Zeichen für Tooltips und die automatische Bereinigung durch Nowly.
