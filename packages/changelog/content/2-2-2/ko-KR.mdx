## 수정 사항

- 너무 짧은 Discord asset 툴팁은 확장 프로그램과 네이티브 호스트에서 모두 정리된 뒤 활동을 보내기 전에 무시하여 잘못된 RPC payload를 방지합니다.
- 반복되는 네이티브 heartbeat 응답이 더 이상 런타임 로그를 가득 채우지 않습니다. 연결 상태, 상태 또는 네이티브 버전이 변경될 때만 heartbeat를 기록하며 오류는 계속 표시합니다.

## 개선 사항

- 밝은 테마에서 대비를 높이기 위해 어두운 Nowly 워드마크를 사용합니다.
- Presence API 문서에서 Discord 툴팁에 두 글자 이상이 필요하다는 점과 Nowly의 자동 정리 동작을 설명합니다.
