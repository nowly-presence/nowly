## 修正

- 短すぎる Discord アセットのツールチップは拡張機能とネイティブホストの両方で整えられ、アクティビティ送信前に無視されるため、無効な RPC ペイロードを防げます。
- 同じ内容のネイティブ heartbeat がランタイムログを埋め尽くさなくなりました。接続状態、ステータス、またはネイティブ版が変わった場合だけ heartbeat を記録し、エラーは引き続き表示します。

## 改善

- ライトテーマではコントラストを高めるため、暗い Nowly ワードマークを使用するようになりました。
- Presence API のドキュメントで、Discord がツールチップに2文字以上を求めることと、Nowly が自動的に値を整えることを説明しています。
