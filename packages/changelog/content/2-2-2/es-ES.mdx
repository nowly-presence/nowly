## Correcciones

- Las descripciones emergentes de assets de Discord demasiado cortas se limpian y se omiten tanto en la extensión como en el host nativo antes de enviar una actividad para evitar payloads RPC no válidos.
- Las respuestas repetidas del heartbeat nativo ya no llenan los registros de ejecución. Nowly registra un heartbeat cuando cambia el estado de conexión, el estado o la versión nativa, y mantiene visibles los errores.

## Mejoras

- El tema claro ahora usa el logotipo oscuro de Nowly para mejorar el contraste.
- La documentación de la Presence API explica ahora el requisito de Discord de dos caracteres para las descripciones emergentes y la limpieza automática de Nowly.
