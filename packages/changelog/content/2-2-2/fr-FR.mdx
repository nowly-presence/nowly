## Correctifs

- Les réponses répétées du heartbeat natif ne remplissent plus les journaux d’exécution. Nowly enregistre un heartbeat lorsque l’état de connexion, le statut ou la version native change, tout en conservant les erreurs.
- Les infobulles d’assets Discord trop courtes sont nettoyées puis omises dans l’extension et le host natif avant l’envoi d’une activité afin d’éviter les payloads RPC invalides.

## Améliorations

- Le thème clair utilise maintenant le wordmark sombre de Nowly pour un meilleur contraste.
- La documentation de l’API Presence explique désormais la limite de deux caractères de Discord et le nettoyage automatique effectué par Nowly.
