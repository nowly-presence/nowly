## 새로운 기능

### 커스텀 활동 자동 감지

- 커스텀 활동에 선택 사항인 감지 링크를 추가하면 포커스가 있는 브라우저 창의 활성 탭과 일치할 때 자동으로 선택돼요. 일치하는 페이지를 떠나면 자동 선택이 끝나요.
- 도메인이나 경로를 지정할 수 있어요. 하위 도메인에는 `*.example.com`, 경로에는 끝에 `*`를 사용할 수 있어요. 수동으로 계속 사용하려면 입력란을 비워 두세요.
- 수동으로 활성화한 커스텀 활동이 자동 감지보다 우선해요.
- 여러 활동이 일치하면 가장 최근에 수정된 활동이 선택돼요.
- 커스텀 활동을 내보내고 가져올 때 감지 링크도 포함돼요. 이 필드가 없는 이전 파일도 계속 지원해요.

### 커스텀 활동 공개 링크

- Discord 계정의 작성자 이름과 아바타로 공개 링크를 게시할 수 있어요. 저장된 버전만 공개되며 저장하지 않은 초안은 공개되지 않아요.
- 미리보기를 확인한 뒤 명시적으로 독립된 사본을 추가할 수 있어요. 새 사본은 비활성 상태이고 자동 감지도 꺼져 있어요.
- 명시적으로 업데이트하거나 게시를 취소해도 같은 링크가 유지돼요. 받는 사람의 사본은 설치된 상태로 남으며 자동 업데이트되지 않아요.
- 받는 사람은 업데이트를 검토한 뒤 로컬 변경 사항을 유지하거나 교체할 수 있어요. 편집기가 열려 있으면 저장하지 않은 작업을 보호하기 위해 교체를 차단해요.
- 공유된 활동을 삭제할 때 같은 패널에서 공개 링크 비활성화와 활동 삭제를 차례로 확인해요. 링크가 없으면 삭제 확인을 바로 표시해요.
- 계정을 삭제한 뒤 게시 데이터가 없음을 확인하면 이전 계정 없이 원본을 로컬에서 삭제할 수 있어요. 확인할 수 없거나 결과가 불확실하면 원본을 보존해요.

### 공지와 릴리스 노트

- 소식 탭에서 공지와 게시된 릴리스 노트를 읽고 항목을 열어 자세한 내용을 확인할 수 있어요. 게시된 변경 내역 파일은 자동으로 포함되며, 날짜가 없거나 미래 날짜이거나 명시적으로 미게시 상태인 초안은 제외돼요.
- 공지는 인터페이스 언어를 사용하고 번역이 없으면 대체 언어로 표시해요. 릴리스 노트는 영어로 대체돼요.
- 고정 공지는 활동 머리글 위에 표시돼요. 경고는 심각도에 따라 노란색, 주황색, 빨간색을 사용하고 점검은 테마의 기본 강조색을 사용해요. 띠를 누르면 소식이 열리고 닫기 버튼은 없어요.
- 점검 종료 예상 시각은 날짜로 표시되며 카운트다운이나 복구 보장은 아니에요. 해당 시각이 되면 띠는 사라지지만 별도 만료 시각이 없으면 공지는 계속 읽을 수 있어요.
- 목록은 자동으로 새로고침되고 마지막으로 받은 유효한 사본을 오프라인에서도 볼 수 있어요. 읽음 상태는 기기에 저장돼요.

### Discord 활동 표시

- 프레즌스는 활동 버튼과 별개로 `detailsUrl`과 `stateUrl`을 사용해 세부 정보와 상태 텍스트에 공개 HTTPS 링크를 연결할 수 있어요. 유효하지 않거나 대응하는 텍스트가 없는 링크는 무시돼요.
- 프레즌스는 `statusDisplayType`으로 Discord의 간략한 상태에 활동 이름, 상태 또는 세부 정보 중 무엇을 표시할지 선택할 수 있어요. 활동 카드의 내용은 바뀌지 않아요.

이 필드는 호환되는 SDK, 확장 프로그램, 네이티브 호스트가 필요해요. 이전 버전은 이 필드를 무시해요. 커스텀 활동 편집기에 새 표시 선택기를 추가하는 기능은 아니에요.

## 개선 및 수정

- 진행 상황을 표시하는 재사용 가능한 다단계 패널을 추가했어요. 이후 화면에서 자유로운 콘텐츠와 양식을 넣을 수 있어요.
- 좁은 화면에서 토스트 메시지를 자르지 않고 여러 줄로 표시하며, 아이콘 크기는 일정하게 유지해요.
- 어두운 테마에서 빨간색 삭제 확인 버튼의 텍스트 대비를 개선했어요.

- 커스텀 활동 편집기에 추가할 수 있는 링크 버튼의 남은 개수가 표시돼요.
- 설정을 섹션별로 쉽게 둘러볼 수 있어요. 스크롤하면 설정 제목과 연결 요약을 함께 보여 줘요. 아이콘 크기와 타일 스타일을 통일하고, 로그아웃 상태의 계정 카드는 간소화했으며, 계정 아바타 모서리도 같은 둥근 스타일로 맞췄어요.
- 필요하지 않을 때 라이브러리, 커스텀 또는 소식 탭을 숨길 수 있어요. 활동과 설정은 계속 사용할 수 있어요. 설정에서 기본 배치를 복원할 수 있어요. 소식을 숨겨도 활동의 고정 공지는 숨겨지지 않아요.
- YouTube를 포함한 동영상의 진행 막대가 이제 재생에 따라 채워져요. 커스텀 활동의 카운트다운은 계속 남은 시간을 표시해요.
- 커스텀 활동 카운트다운에서 남은 시간 앞에 마이너스 기호가 더 이상 표시되지 않아요.
- 평가 요청의 ‘평가’ 버튼에서 위에 이미 표시된 별 아이콘이 반복되지 않아요.
- ‘Nowly 후원’에서 Bitcoin, Ethereum 또는 Solana 주소를 한 번의 클릭으로 복사하고 복사 확인 메시지를 볼 수 있어요.
- 업데이트할 수 있는 설치된 프레즌스가 2개 이상이면 한 번에 업데이트할 수 있어요. 업데이트는 순서대로 진행돼요.
- 활동이 없을 때 표시되는 카드의 버튼이 좁은 사이드 패널에도 맞도록 개선했어요.
- 프레즌스별로 업데이트, 재설치, 삭제를 순서대로 처리해 오래된 업데이트가 방금 삭제한 활동을 복원하지 않게 했어요.
- 프레즌스 활성화는 스크립트 등록에 성공한 후에만 저장돼요. 활성화나 일괄 작업 실패를 성공으로 표시하지 않고 알려 줘요.
- 사용자 스크립트 권한 라벨이 브라우저에서 무엇을 켜야 하는지 더 명확히 설명해요.

## 개인정보 보호와 플랫폼

- 선택적 Umami 제품 이벤트가 기존 Insights 통계를 대체해요. 사이트와 확장 프로그램의 동의는 별개이며, 영구 방문자 식별자나 탐색 및 활동 내용 없이 API를 통해 이벤트를 전달해요.
- 기존 Insights 페이지, 엔드포인트, 통계 모델과 캠페인 기능을 제거했어요. 이 버전은 기존 전역 통계 및 세션 녹화 스크립트를 활성화하지 않아요.
- 법적 동의는 내부 버전 번호 대신 약관과 개인정보 처리방침의 실제 업데이트 날짜를 따라요. 이전 숫자 형식의 동의 기록은 재확인이 필요하며 캐시된 문서 날짜는 오프라인에서도 사용할 수 있어요.
- 삭제 페이지는 기기 기능 데이터의 유지·삭제와 선택적 통계를 구분해요. 페이지를 열 때 사이트 통계에 동의한 경우에만 제품 이벤트를 보내요.
- ChromeOS 대기 명단과 지원 화면을 제거했어요. 확장 프로그램은 Chrome과 Firefox, 네이티브 호스트는 Windows, macOS, Linux를 대상으로 해요.

## 사이트, 문서와 유지보수

- 패키지 이름, 설명, 프로젝트 링크를 Nowly와 각 패키지의 역할에 맞게 업데이트했어요.
- 패키지 기여자 표기를 통일해 Gaëtan H와 Anthony (KiMi)를 함께 명시했어요.
- Git 커밋 시 스테이징된 TypeScript 파일에 프로젝트 서식을 자동 적용하고, 스테이징되지 않은 변경 사항은 보존해요.

- 홈페이지에서 커스텀 활동을 소개하며 이미지 대비와 공지 막대 색상을 현재 테마에 맞췄어요.
- 사이트의 키보드 탐색, 건너뛰기 링크와 포커스 표시를 개선했어요. 애니메이션은 동작 줄이기 설정을 따르고 움직이는 콘텐츠는 일시정지할 수 있어요.
- 번역된 FAQ, 연락 및 복구 안내와 쿠키 정책 링크를 업데이트했어요.
- 개발자 문서에 `settings.ts` 자동 탐색, Discord 간략 상태 선택, 클릭 가능한 활동 텍스트와 이미지 프록시를 설명했어요.
- 공지 API는 보호된 게시, 예약, 만료와 실시간 목록 업데이트를 지원해요.
- Nowly의 공개 코드는 이제 MIT 라이선스를 사용해요. 확장 프로그램, 사이트와 API 테스트를 정리하고 수정했으며 공지 상세 내용과 표시 모드 전환 테스트도 포함돼요.
