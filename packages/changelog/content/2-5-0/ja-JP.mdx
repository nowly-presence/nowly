## 新機能

### カスタムアクティビティの自動検出

- カスタムアクティビティに任意の検出リンクを追加すると、フォーカスのあるブラウザーウィンドウのアクティブなタブが一致したときに自動で選択されます。一致するページを離れると、自動選択は終了します。
- ドメインやパスを指定できます。サブドメインには `*.example.com`、パスには末尾の `*` を使えます。手動で使い続ける場合は空欄にしてください。
- 手動で有効にしたカスタムアクティビティは、自動検出より優先されます。
- 複数のアクティビティが一致した場合は、最後に更新されたものが選択されます。
- カスタムアクティビティの書き出しと読み込みに検出リンクが含まれます。この項目のない古いファイルも引き続き利用できます。

### カスタムアクティビティの公開リンク

- Discord アカウントの作者名とアバター付きで公開リンクを発行できます。公開されるのは保存済みの内容で、未保存の下書きではありません。
- プレビューを確認してから、明示的に独立したコピーを追加できます。新しいコピーは無効な状態で、自動検出もオフです。
- 明示的な更新や公開取り消しでも同じリンクが保持されます。受信者のコピーはインストールされたままで、自動更新されません。
- 受信者は更新内容を確認してから、ローカルの変更を保持するか置き換えるか選べます。エディターが開いている間は、未保存の作業を守るため置き換えを防ぎます。
- 元のアクティビティを削除する前に、公開済みや公開処理中のリンクを明示的に取り消し、元のサーバーでオンライン確認を行ってください。
- アカウント削除後、その公開データが存在しないことを確認できれば、以前のアカウントなしでローカルの元データを削除できます。確認できない場合や結果が不明な場合、元のアクティビティは保持されます。

### お知らせとリリースノート

- ニュースタブでお知らせと公開済みのリリースノートを確認し、各項目を開いて詳細を読めます。公開済みの変更履歴ファイルは自動で追加され、日付のない草案、未来の日付の草案、明示的に未公開の草案は表示されません。
- お知らせはインターフェースの言語で表示され、翻訳がない場合は代替言語を使います。リリースノートの代替言語は英語です。
- 固定された通知はアクティビティの見出しの上に表示されます。警告は重要度に応じて黄色、オレンジ、赤になり、メンテナンスはテーマのプライマリカラーを使います。通知帯からニュースを開けますが、閉じるボタンはありません。
- メンテナンスの終了予定は日時で表示され、カウントダウンや復旧の保証ではありません。予定時刻になると通知帯は消えますが、別の有効期限がなければお知らせ自体は引き続き読めます。
- 一覧は自動更新され、最後に取得した有効な内容をオフラインでも読めます。既読状態はデバイスに保存されます。

### Discord のアクティビティ表示

- プレゼンスは `detailsUrl` と `stateUrl` で、詳細や状態のテキストに公開 HTTPS リンクを付けられます。アクティビティのボタンとは別の機能で、無効なリンクや対応するテキストのないリンクは無視されます。
- `statusDisplayType` で Discord のコンパクトなステータスに表示するテキストを、アクティビティ名、状態、詳細から選べます。アクティビティカードの内容は変わりません。

これらの項目には対応する SDK、拡張機能、ネイティブホストが必要です。古いバージョンでは無視されます。カスタムアクティビティのエディターに新しい表示切り替えを追加するものではありません。

## 改善と修正

- カスタムアクティビティのエディターに、追加できるリンクボタンの残り数を表示します。
- プレビューでアクティビティ名を不要に重複表示しないようにしました。ツールチップで名前全体を確認できます。
- 検出セクションの余白を見やすく調整しました。
- 不要なときはライブラリ、カスタム、ニュースのタブを非表示にできます。アクティビティと設定は引き続き利用できます。設定から初期配置に戻せます。ニュースを非表示にしても、アクティビティの固定通知は表示されます。
- YouTube などの動画の進行バーは、再生が進むにつれて伸びるようになりました。カスタムアクティビティのカウントダウンは引き続き残り時間を表示します。
- 「Nowly を支援」で Bitcoin、Ethereum、Solana のアドレスをワンクリックでコピーでき、コピー後に確認メッセージが表示されます。
- 更新可能なインストール済みプレゼンスが 2 件以上ある場合、まとめて更新できます。更新は順番に実行されます。
- 非アクティブ時のアクティビティカードのボタンが、幅の狭いサイドパネルにも収まるようになりました。
- プレゼンスごとに更新、再インストール、削除を順序立てて処理し、古い更新が削除したばかりのアクティビティを復元しないようにしました。
- プレゼンスの有効化は、スクリプトの登録に成功した後でのみ保存されます。有効化や一括処理の失敗を成功として扱わずに通知します。
- ユーザースクリプトの権限ラベルで、ブラウザー側で何を有効にする必要があるかを明確にしました。

## プライバシーとプラットフォーム

- 従来の Insights 統計を、任意の Umami 製品イベントに置き換えました。サイトと拡張機能の同意は別々で、永続的な訪問者 ID や閲覧・アクティビティ内容を含めずに API 経由で送信します。
- 従来の Insights ページ、エンドポイント、統計モデル、キャンペーン機能を削除しました。このバージョンで従来のグローバル統計やセッション録画のスクリプトが有効になることはありません。
- 利用規約とプライバシーポリシーの確認は、内部バージョン番号ではなく実際の更新日に基づきます。従来の数値形式の同意記録は再確認が必要です。キャッシュ済みの文書日付はオフラインでも利用できます。
- アンインストールページでは、デバイスの機能用データの保持・削除と任意の統計を区別します。ページを開いた際の製品イベントは、サイトの統計への同意がある場合のみ送信します。
- ChromeOS の順番待ちリストとサポート画面を削除しました。拡張機能は Chrome と Firefox、ネイティブホストは Windows、macOS、Linux 向けです。

## サイト、ドキュメント、保守

- ホームページでカスタムアクティビティを紹介し、画像のコントラストとお知らせバーの色を現在のテーマに合わせました。
- サイトのキーボード操作、スキップリンク、フォーカス表示を改善しました。アニメーションは動きを減らす設定に従い、動くコンテンツは一時停止できます。
- 翻訳された FAQ、問い合わせ・復旧案内、Cookie ポリシーへのリンクを更新しました。
- 開発者向けドキュメントに `settings.ts` の自動検出、Discord のコンパクトなステータスの選択、クリックできるアクティビティテキスト、画像プロキシの説明を追加しました。
- お知らせ API は保護された公開操作、公開予約、有効期限、一覧のリアルタイム更新に対応しています。
- Nowly の公開コードは MIT ライセンスになりました。拡張機能、サイト、API のテストを整理・修正し、お知らせの詳細と表示モード切り替えのテストも見直しました。
