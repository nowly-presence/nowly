## 새로운 기능

- 설정의 "계정 및 동기화"에서 Discord로 로그인할 수 있습니다(선택 사항). 계정이 없어도 Nowly는 이전과 똑같이 동작합니다.
- 로그인하면 설치한 프레즌스(켜짐 여부와 일정 포함), 설정, 각 프레즌스의 설정이 다른 브라우저에도 그대로 적용됩니다. 다른 브라우저에서 받은 프레즌스는 평소처럼 서명된 다운로드로 설치됩니다.
- 처음 로그인할 때 계정과 브라우저 모두에 데이터가 있으면 어느 쪽을 남길지 묻습니다.
- 현재 활동, 탭, 방문한 페이지, 기록은 절대 동기화되지 않습니다. 개발자 설정과 사용자 지정 API 주소는 각 기기에 남습니다.
- "로그아웃"은 기기의 데이터를 모두 그대로 둡니다. "동기화 중지 및 온라인 사본 삭제"는 동기화된 사본을 지우고 모든 기기에서 로그아웃합니다.
- nowly.me/account에서 연결된 기기를 확인하고, 데이터를 다운로드하거나 계정을 삭제할 수 있습니다.
- 새로운 테마 변형: 춘분, 하지, 추분, 동지 전후 일주일 동안의 봄, 여름, 가을, 겨울 테마와 새해 테마가 추가되었어요. 각 테마마다 고유한 색상이 있고 Nolo도 그에 맞게 꾸미고 나와요. 당일에는 Nolo가 짧은 인사를 하러 들르고, 1월 1일에는 불꽃놀이와 함께 새해 카운트다운을 해요.
- 이제 확장 프로그램의 테마가 nowly.me와 연결돼요. 계절 테마를 켜 두면 사이트도 확장 프로그램과 같은 계절로 꾸며져요. 설정에서 계절 테마를 끄면 둘 다 원래대로 돌아가요.

## 개선 사항

- 새 버전을 처음 열 때 Nolo가 새 기능을 한 번만 소개합니다.
- 여러 기기를 연결해도 좋아요는 계정당 한 번만 계산됩니다.
- Discord가 관리자 권한으로 실행되어 Nowly를 차단하면 연결을 복구하는 방법을 안내하는 메시지가 표시됩니다.
- 이제 설정의 "정보"에서 Ko-fi 또는 GitHub Sponsors로 Nowly를 후원할 수 있습니다. 14일 동안 사용하면 활동 탭 맨 아래의 작은 카드로도 안내할 수 있습니다. "나중에"를 누르면 90일 동안 숨겨지며, 활동 중에는 절대 표시되지 않습니다. 모든 정보는 기기에만 저장됩니다.
- nowly.me/support에 Ko-fi와 GitHub Sponsors 후원 카드가 추가되었습니다.
