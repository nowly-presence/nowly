이번 릴리스는 확장 프로그램 재설계를 완료하고 확장 프로그램, 웹사이트, 문서 전반에서 Nowly의 현지화를 확대합니다.

## 재구축된 확장 프로그램

새 사이드 패널 구조를 사용하며 Activity, Store, Settings, 온보딩, 진단, 런타임 로그 전용 화면을 제공합니다. 설정은 더 명확한 카드와 섹션으로 구성되며 라이트, 다크, 시스템 외관 모드를 지원합니다.

새 Activity와 Store 흐름으로 presence 탐색, 설치, 예약, 일시 중지, 현재 활동을 더 쉽게 이해할 수 있습니다. 안내형 온보딩, 재연결, 네이티브 연결 상태, 설치 피드백과 빈 상태도 새 UI에 맞게 재구축했습니다.

백그라운드 계층에는 타입 저장소, 타입 메시지 라우터, 진단과 런타임 로그, presence 및 activity 관리자, 네이티브 호스트 처리, 기기 동기화, 릴리스 보안 검사가 추가되었습니다. 표시 상태, 기록, 해시, 미디어 이벤트로 전체 페이지를 새로 고치지 않고도 활동을 업데이트할 수 있습니다.

## Canary와 로컬 개발

Chrome Canary 빌드는 `pnpm --filter @nowly/extension build:chrome`로 만들 수 있습니다. 빌드 파이프라인은 개발 및 Canary 배포용 manifest와 presence를 생성합니다. 로컬 presence asset을 지원하며 업데이트 중 보관된 presence는 건너뜁니다.

CLI는 `nowly build --watch`와 `nowly pack --watch`를 지원합니다. 웹사이트와 확장 프로그램은 안정 버전 설치와 Canary 테스트 빌드를 구분합니다.

## 더 많은 로케일

영어, 프랑스어, 스페인어에 더해 독일어, 브라질 포르투갈어, 폴란드어, 일본어, 한국어, 터키어, 말레이어, 그리스어를 지원합니다. 언어 메뉴는 해당 국기를 사용하고 브라우저 언어 감지는 모든 로케일을 지원하며 presence 개발, 고급 주제, 게시, changelog 문서도 번역되었습니다.

## 확장 프로그램 세부 사항

- 익명 사용 분석은 기본적으로 꺼져 있으며 Settings에서 관리할 수 있습니다.
- Discord 네이티브 presence를 명확히 표시해 중복 활동을 방지합니다.
- 로컬 호스팅 웹 인스턴스에서도 연결 브리지를 사용할 수 있습니다.
- 새 설치에서는 예약이 꺼져 있고 자정까지 일시 중지를 지원합니다.
- 데스크톱 앱이 없거나 오래된 경우 더 명확한 연결 안내를 제공합니다.
- 개발자 모드는 사이드 패널 내비게이션에서 바로 전용 런타임 로그 화면을 제공합니다.
- 웹사이트 푸터에 Nowly의 X 계정으로 바로 연결되는 링크가 추가되었습니다.
- presence 상세 페이지에 좋아요 버튼과 실시간 설치 수 및 활성 사용자 수가 확장 프로그램과 nowly.me 양쪽에 표시됩니다.
- Store에서 이미 설치된 presence를 열면 별도의 카탈로그 페이지 대신 Activity의 상세 화면으로 바로 이동합니다.
- Activity 목록에서 여러 presence를 선택해 한 번에 활성화, 비활성화 또는 제거할 수 있습니다.

## 검증

Activity 관리자, URL 매칭, 릴리스 보안, 저장소, 메시지 처리를 검증합니다. 확장 프로그램 typecheck, 테스트, Canary 빌드, 웹사이트 빌드, 문서 빌드는 최종 검증 과정에 포함됩니다.
