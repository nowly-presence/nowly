今回のリリースで拡張機能の再設計が完了し、拡張機能、Web サイト、ドキュメント全体で Nowly のローカライズが拡大しました。

## 再構築された拡張機能

新しいサイドパネル構成を採用し、アクティビティ、ストア、設定、オンボーディング、診断、実行ログの専用ビューを用意しました。設定は見やすいカードとセクションに整理され、ライト、ダーク、システムの外観モードに対応します。

新しいアクティビティとストアのフローにより、presence の閲覧、インストール、スケジュール、スヌーズ、現在のアクティビティを理解しやすくしました。ガイド付きオンボーディング、再接続、ネイティブ接続状態、インストール結果、空状態も新 UI に合わせて再構築しています。

バックグラウンド層には型付きストレージ、型付きメッセージルーター、診断と実行ログ、presence とアクティビティの管理、ネイティブホスト処理、デバイス同期、リリースセキュリティ検証を追加しました。可視性、履歴、ハッシュ、メディアのイベントは、ページ全体を再読み込みせずにアクティビティを更新できます。

## Canary とローカル開発

Chrome Canary ビルドは `pnpm --filter @nowly/extension build:chrome` で作成できます。ビルドパイプラインは開発用および Canary 配布用の manifest と presence バンドルを生成します。ローカル presence アセットにも対応し、更新時にはアーカイブ済み presence をスキップします。

CLI は `nowly build --watch` と `nowly pack --watch` に対応しました。Web サイトと拡張機能は安定版インストールと Canary テストビルドを区別します。

## 対応ロケールの拡大

英語、フランス語、スペイン語に加え、ドイツ語、ブラジルポルトガル語、ポーランド語、日本語、韓国語、トルコ語、マレー語、ギリシャ語に対応しました。言語メニューは対応する旗を表示し、ブラウザー言語検出は全ロケールをカバーします。presence 開発、応用トピック、公開、changelog のドキュメントも翻訳されています。

## 拡張機能の詳細

- 匿名の利用分析は既定で無効のままで、設定から管理できます。
- Discord ネイティブ presence を明確に表示し、重複アクティビティを防ぎます。
- ローカルでホストされた Web インスタンスでも接続ブリッジを利用できます。
- 新規インストールではスケジュールは無効で、深夜までのスヌーズに対応します。
- デスクトップアプリがない、または古い場合の接続案内を改善しました。
- 開発者モードでは、サイドパネルのナビゲーションから直接、専用のランタイムログ表示を利用できます。
- ウェブサイトのフッターに Nowly の X アカウントへの直接リンクが追加されました。
- プレゼンスの詳細ページに、いいねボタンとインストール数・アクティブユーザー数のリアルタイム表示が、拡張機能と nowly.me の両方で表示されるようになりました。
- ストアからすでにインストール済みのプレゼンスを開くと、別のカタログページではなく、Activity の詳細ビューに直接移動するようになりました。
- Activity のリストで複数のプレゼンスを選択し、まとめて有効化・無効化・アンインストールできるようになりました。

## 検証

アクティビティ管理、URL マッチング、リリースセキュリティ、ストレージ、メッセージ処理をカバーしています。拡張機能の typecheck、テスト、Canary ビルド、Web サイトビルド、ドキュメントビルドを最終検証で実行します。
