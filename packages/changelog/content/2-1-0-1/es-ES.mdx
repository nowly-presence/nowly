`2.1.0.1` es una corrección crítica. El build de `2.1.0` incluía por error una dirección de API de desarrollo local en lugar de la API de producción, cortando la conexión con los servidores de Nowly. Esta versión corrige el build para que la extensión vuelva a hablar con la API real. Sin más cambios funcionales o visuales.
