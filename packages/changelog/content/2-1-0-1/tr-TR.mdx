`2.1.0.1` kritik bir düzeltmedir. `2.1.0` derlemesi yanlışlıkla üretim API'si yerine yerel geliştirme API adresiyle paketlenmiş ve Nowly sunucularıyla olan bağlantıyı kesmişti. Bu sürüm, uzantının gerçek API ile yeniden konuşabilmesi için derlemeyi düzeltir. Bunun dışında işlevsel veya görsel bir değişiklik yoktur.
