`2.1.0.1` ialah pembetulan kritikal. Binaan `2.1.0` secara tidak sengaja disertakan dengan alamat API pembangunan tempatan bukannya API pengeluaran, menyebabkan sambungan ke pelayan Nowly terputus. Keluaran ini membetulkan binaan supaya sambungan bercakap semula dengan API sebenar. Tiada perubahan fungsi atau visual lain.
