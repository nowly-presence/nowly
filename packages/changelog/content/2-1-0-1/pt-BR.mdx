`2.1.0.1` é uma correção crítica. O build `2.1.0` incluiu por engano um endereço de API de desenvolvimento local em vez da API de produção, quebrando a conexão com os servidores da Nowly. Esta versão corrige o build para que a extensão volte a falar com a API real. Nenhuma outra mudança funcional ou visual.
