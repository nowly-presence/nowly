`2.1.0.1`은 긴급 수정 버전입니다. `2.1.0` 빌드에 프로덕션 API 대신 로컬 개발용 API 주소가 실수로 포함되어 Nowly 서버와의 연결이 끊겼습니다. 이번 릴리스는 빌드를 수정하여 확장 프로그램이 다시 실제 API와 통신하도록 합니다. 그 외 기능이나 UI 변경 사항은 없습니다.
