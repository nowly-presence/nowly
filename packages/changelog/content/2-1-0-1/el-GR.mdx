`2.1.0.1` είναι μια κρίσιμη διόρθωση. Το build της `2.1.0` περιείχε κατά λάθος μια τοπική διεύθυνση API ανάπτυξης αντί της διεύθυνσης παραγωγής, διακόπτοντας τη σύνδεση με τους διακομιστές του Nowly. Αυτή η έκδοση διορθώνει το build ώστε η επέκταση να επικοινωνεί ξανά με το πραγματικό API. Καμία άλλη λειτουργική ή οπτική αλλαγή.
