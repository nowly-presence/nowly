`2.1.0.1` is a critical hotfix. The `2.1.0` build's API endpoint was accidentally baked in as a local development address instead of the production API, breaking the connection to Nowly's servers. This release corrects the build so the extension talks to the real API again. No functional or UI changes beyond that.
