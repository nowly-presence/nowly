`1.1.0` es una release de mantenimiento. No cambia la forma del producto; hace que los flujos existentes se comporten como se espera y reorganiza el changelog en páginas separadas por release.

## Navegación de la extensión

El badge de actualización ahora abre directamente `/library/[item]`. Ya no hay desvío por la antigua estructura de URLs con idioma.

## Estado de actualización

La versión instalada se refresca en cuanto llega la actualización. El badge desaparece al momento en lugar de quedarse hasta reiniciar.

## Tracking activo

`activeUsers` ahora sigue un modelo por dispositivo. El número refleja dispositivos realmente activos en lugar de un simple placeholder.

## Flujo de desactivación

Desactivar una presencia elimina ese dispositivo del contador activo. No queda actividad fantasma después de un toggle.

## Limpieza al desinstalar

La extensión define una URL de desinstalación best-effort y la página web purga el dispositivo. La eliminación sigue funcionando aunque la extensión ya no esté disponible.

## Pulido de la página detalle

Los bloques de icono transparentes usan backdrop blur. La banner ya no se filtra tanto a través del tratamiento del icono.

## Estructura del changelog

El changelog se movió a `/changelog` y ahora usa una página por versión. Cada release se puede enlazar, revisar y mantener de forma independiente.

## Navegación docs

El changelog ahora aparece en la sidebar de docs con hijos por versión. Las notas de versión son accesibles como el resto de la documentación.

## Sitemap docs

El sitemap de docs ahora incluye el índice del changelog y las páginas de versión. Las release notes se indexan como el resto de la documentación.

## Página de la app de escritorio

El flujo de descarga se agrupó en el hero. Las tarjetas secundarias quedaron ocultas para dejar una sola zona de descarga.

## Panel de descarga

El select de plataforma, la línea de versión y los botones viven en un panel compacto debajo del hero.

## CTA de escritorio

El CTA de instalar la extensión usa un icono y apunta a la biblioteca.

## Almacenamiento de la app de escritorio

La nota de almacenamiento muestra los tamaños exactos del manifest `1.1.0` de la app de escritorio.

## Plataformas del inicio

La sección de plataformas del inicio ahora usa tarjetas de servicio más completas y elimina el título `Disponibles`. La lista de servicios se siente más actual y sigue alimentada por los datos live de las presencias.

## Espaciado de contribuidores

Las filas de contribuidores ahora son compactas y de ancho completo. La sección ya no muestra un hueco extraño entre personas.

## Docs CLI

La nota de build de producción se retiró de la documentación CLI. La doc ya no sugiere un camino separado de build Chrome Web Store ahí.
