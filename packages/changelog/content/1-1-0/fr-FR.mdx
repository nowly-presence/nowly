`1.1.0` est une release de maintenance. Elle ne change pas la forme du produit ; elle fait simplement en sorte que les flux existants se comportent comme on s'y attend et réorganise le changelog en pages de release séparées.

## Navigation de l'extension

Le badge de mise à jour ouvre maintenant directement `/library/[item]`. Il n'y a plus de détour par l'ancienne structure d'URL localisée.

## État de mise à jour

La version installée se rafraîchit dès que la mise à jour arrive. Le badge disparaît tout de suite au lieu de rester jusqu'au redémarrage.

## Tracking actif

`activeUsers` suit maintenant un modèle par appareil. Le chiffre reflète de vrais appareils actifs au lieu d'un simple placeholder.

## Désactivation

Désactiver une présence retire cet appareil du compteur actif. Aucune activité fantôme ne reste après un toggle.

## Nettoyage de désinstallation

L'extension définit une URL de désinstallation best-effort et la page web purge l'appareil. La suppression continue de fonctionner même quand l'extension n'est plus disponible.

## Polish des pages détail

Les blocs d'icône transparents utilisent un backdrop blur. La bannière ne traverse plus autant le traitement de l'icône.

## Structure du changelog

Le changelog a été déplacé vers `/changelog` et utilise maintenant une page par version. Chaque release peut être reliée, parcourue et maintenue indépendamment.

## Navigation docs

Le changelog apparaît maintenant dans la sidebar docs avec des enfants par version. Les notes de version deviennent accessibles comme le reste de la documentation.

## Sitemap docs

Le sitemap docs inclut maintenant l'index du changelog et les pages de version. Les release notes sont indexées comme le reste de la doc.

## Page application bureau

Le flux de téléchargement a été regroupé dans le hero. Les cartes secondaires ont été masquées pour garder une seule zone de téléchargement.

## Panneau de téléchargement

Le select de plateforme, la ligne de version et les boutons sont dans un panneau compact sous le hero.

## CTA bureau

Le CTA d'installation de l'extension utilise une icône et pointe vers la bibliothèque.

## Stockage application bureau

La note de stockage affiche les tailles exactes du manifest `1.1.0` de l'application bureau.

## Plateformes accueil

La section plateformes de l'accueil utilise maintenant des cartes de service plus complètes et retire le titre `Disponibles`. La liste des services paraît plus actuelle et reste alimentée par les données live des présences.

## Espacement contributeurs

Les lignes de contributeurs sont maintenant compactes et pleine largeur. La section n'affiche plus un espace étrange entre les personnes.

## Docs CLI

La note de build production a été retirée de la documentation CLI. La doc n'implique plus un chemin séparé de build Chrome Web Store à cet endroit.
