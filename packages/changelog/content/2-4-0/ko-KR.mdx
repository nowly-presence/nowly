## 새로운 기능

### 커스텀 활동

- 새 커스텀 탭에서 사이트 프레즌스를 설치하지 않고 Discord 활동을 만들고 수정하고 삭제해요. 처음에는 Nolo가 기능을 소개해요.
- 기기에 최대 50개를 저장해요. 동시에 하나만 활성화할 수 있으며, 끌 때까지 탭 프레즌스보다 우선해요.
- 이름, 유형(플레이, 듣기, 시청, 참여), 텍스트 두 줄, 마우스 오버 설명이 있는 큰 이미지와 작은 이미지, 최대 두 개의 HTTPS 버튼을 설정해요.
- 경과 시간 또는 5분부터 24시간까지의 카운트다운을 선택해요. 타이머는 생성이 아닌 활성화 시점에 시작해요.
- 공부, 코딩, 게임, 플레이리스트, 영화, 라이브, 운동, 여행, 커피 휴식의 9개 템플릿. 편집기를 채우지만 확인하기 전에는 저장하지 않아요.
- 실시간 미리보기와 현재 활동을 열고 중지하거나 재개하는 전용 카드를 추가했어요.

### 이미지와 공유

- PNG, JPEG, WebP, GIF 업로드, HTTPS URL 또는 24개 아이콘과 10개 색상을 선택해요. 큰 이미지가 없으면 Nowly 로고, 작은 이미지가 없으면 배지를 표시하지 않아요.
- GIF를 제외한 이미지는 자동 축소 및 변환해요. 이미지당 최대 1 MiB이며 GIF는 변환하지 않아요. 로컬 복사본은 미리보기와 재전송에 쓰이고 Discord에는 호스팅 URL을 보내요.
- 활성 이미지를 주기적으로 갱신해요. 30일간 사용하지 않은 호스팅 파일은 정리 대상이며 만료된 이미지는 필요할 때 로컬 복사본에서 다시 올려요.
- 저장된 활동을 `[이름].json`으로 내보내요. 저장하지 않은 수정이 아닌 마지막 저장본을 사용하며 텍스트, 유형, 타이머, 버튼과 로컬 이미지 복사본을 포함해요. 복사본이 없는 이미지는 빠져요.
- 로컬 ID, 생성/수정 날짜, 활성 상태, 업로드 이미지의 호스팅 URL은 제외해요. 입력한 HTTPS 링크는 남으니 공유 전에 확인하세요.
- 접근성 레이블과 툴팁이 있는 아이콘 가져오기 버튼 또는 보이는 커스텀 탭에 끌어 놓기로 여러 파일을 가져와요. 다른 화면에서는 가로채지 않아요.
- 기존 활동을 덮어쓰지 않고 비활성 상태의 새 활동을 만들어요. 한 개를 가져오면 편집기가 열리고 여러 개면 결과를 요약해요.
- 4 MiB 초과 파일, 호환되지 않는 형식/버전, 유효하지 않은 활동은 거부해요. 포함된 이미지는 검증 후 다시 업로드해요. 이미지가 실패하면 활동은 해당 이미지 없이 유지하고 경고해요.

## 개선

- 활동 만들기, JSON 공유, 이미지 개인정보 보호를 설명하는 영어와 프랑스어 가이드 3개를 추가했어요. 화면 크기에 맞는 스크린샷을 원본 크기로도 열 수 있어요.
- 탭을 길게 눌러 이동하거나 양옆으로 끌어 별도 그룹을 만들어요. 설정에서 배치를 초기화할 수 있어요.
- 카드와 미리보기가 Discord 유형별 배치를 따라요. 플레이는 이름을 별도 줄에, 나머지는 머리말에 표시해요. 대화 상자는 패널 위에 떠 있고 빈 화면에는 예제와 템플릿을 보여줘요.
- 모든 기능과 오류를 11개 언어로 번역했으며 2.4.0 전체에서 언어별로 178개 키를 추가했어요.

## 수정

- 활성 탭 이름이 잘리지 않아요. 가져오기 버튼은 아이콘만 표시해 작게 유지해요.
- 동시 가져오기를 차단하고 일괄 작업도 50개 제한을 지켜요. 한 파일이 실패해도 다음 파일은 처리해요.
- 같은 이미지의 반복/동시 업로드를 서버에서 멱등하게 처리해요. 원격 삭제에 실패하면 참조를 유지해 재시도할 수 있어요.

## 제거 및 호환성

- 기존 사용자 기능은 제거하지 않았어요. 계절 테마, ChromeOS, iframe, 내장 프레즌스를 유지해요.
- 상태 서비스의 미사용 숫자 파서를 제거하고 데이터 내보내기의 JSON 다운로드 도우미를 공통화했어요.
- 커스텀 활동은 로컬에 보관하며 계정과 동기화하지 않아요. 파일로 공유하고 새 분석 이벤트는 추가하지 않았어요.

## 기술 및 개인정보

- 기기 토큰으로 보호하는 이미지 업로드/갱신/삭제 경로를 추가했어요. 서명, MIME, 크기, SHA-256 검증과 기기당 시간당 20회 업로드 제한을 적용해요.
- `CustomAsset` 테이블, PostgreSQL 마이그레이션, S3/R2 저장소, 보호된 미사용 이미지 정리를 추가했어요. 저장소와 정리 일정은 배포 시 설정해야 해요.
- 기기 데이터 내보내기에 호스팅 이미지 URL과 메타데이터를 포함해요. 데이터 삭제 시 원격 객체도 지우고 실패 시 재시도할 수 있어요.
- 로컬 이미지용 `unlimitedStorage` 권한, 공유 및 PostgreSQL 통합 테스트, 서브모듈 변경 없는 워크스페이스 TypeScript 포맷을 추가했어요.
