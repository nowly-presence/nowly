## 새로운 기능

- 활동, 라이브러리, 설정 탭을 갖춘 완전히 새로운 사이드 패널. 이동해도 스크롤 위치가 유지됩니다.
- 검색, 카테고리, 트렌드, 인기순, 최신순, A-Z 정렬, 게시 날짜, 신규 배지, 설치된 프레즌스 관리 기능을 제공하는 라이브러리.
- 프레즌스 페이지에서 통계, 좋아요, 설정, 임시 일시정지, 일정, 게시 날짜, 업데이트 날짜, 작성자의 GitHub, 문제 신고를 확인할 수 있습니다.
- 여러 탭이 활성화된 경우 드래그 앤 드롭으로 우선순위를 정하고 탭별 공유를 설정할 수 있습니다.
- 플래그가 포함된 11개 인터페이스 언어. Discord 언어는 설치된 모든 프레즌스가 공통으로 제공하는 언어로 제한되며, 프레즌스별로 최대 11개 언어를 선택할 수 있습니다.
- 현재 탭에서 이용 가능한 프레즌스를 추천하는 설정.
- 기기 데이터 내보내기와 삭제 기능.
- 확장 프로그램 평가 링크와 한 번만 표시되는 리뷰 요청.
- 새로운 연결 진단, 개발자 로그, 새로운 온보딩.
