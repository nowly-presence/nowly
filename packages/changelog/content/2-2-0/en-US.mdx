## What's new

- A complete new side panel with Activity, Library, and Settings tabs. Navigation keeps your scroll position.
- A richer library with search, categories, trending presences, Popular, New, and A-Z sorting, publication dates, New badges, and Manage actions for installed presences.
- Presence pages now show statistics, likes, settings, temporary pauses, schedules, publication dates, update dates, author GitHub links, and issue reports.
- Drag and drop priority ordering when several tabs are active, with sharing controls for each tab.
- Eleven interface languages with flags. Discord language choices are limited to languages shared by all installed presences, with per-presence choices for up to eleven languages.
- A setting to suggest available presences for the current tab.
- Device data export and deletion controls.
- A link to rate the extension and a one-time review request.
- New connection diagnostics, developer runtime logs, and onboarding.
