## Novedades

- Un nuevo panel lateral completo con las pestañas Actividad, Biblioteca y Ajustes. La navegación conserva la posición de desplazamiento.
- Una biblioteca más completa con búsqueda, categorías, tendencias, orden por Populares, Novedades y A-Z, fechas de publicación, insignias Nuevo y acciones Gestionar para las presencias instaladas.
- Las páginas de presencia muestran estadísticas, Me gusta, ajustes, pausa temporal, horarios, fechas de publicación y actualización, el GitHub del autor y el informe de problemas.
- Orden de prioridad mediante arrastrar y soltar cuando hay varias pestañas activas, con controles de uso compartido para cada pestaña.
- Once idiomas de interfaz con banderas. Los idiomas de Discord se limitan a los idiomas comunes de todas las presencias instaladas, con una elección por presencia de hasta once idiomas.
- Una opción para sugerir las presencias disponibles en la pestaña actual.
- Controles para exportar y eliminar los datos del dispositivo.
- Un enlace para valorar la extensión y una solicitud de valoración única.
- Nuevos diagnósticos de conexión, registros para desarrolladores y una nueva introducción.
