## Novidades

- Um novo painel lateral completo com as abas Atividade, Biblioteca e Configurações. A navegação mantém a posição de rolagem.
- Uma biblioteca mais completa com pesquisa, categorias, tendências, ordenação por Populares, Novidades e A-Z, datas de publicação, selos Novo e ações Gerenciar para presenças instaladas.
- As páginas de presença agora mostram estatísticas, curtidas, configurações, pausa temporária, horários, datas de publicação e atualização, o GitHub do autor e denúncias de problemas.
- Ordem de prioridade por arrastar e soltar quando várias abas estão ativas, com controles de compartilhamento para cada aba.
- Onze idiomas de interface com bandeiras. Os idiomas do Discord ficam limitados aos idiomas comuns a todas as presenças instaladas, com uma escolha por presença de até onze idiomas.
- Uma opção para sugerir presenças disponíveis na aba atual.
- Controles para exportar e excluir os dados do dispositivo.
- Um link para avaliar a extensão e uma solicitação única de avaliação.
- Novos diagnósticos de conexão, registros para desenvolvedores e uma nova introdução.
