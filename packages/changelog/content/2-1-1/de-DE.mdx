`2.1.1` ist eine Wartungsversion, die einen Fehler behebt, bei dem eine Presence tatsächlich aktiv sein konnte - Discord Rich Presence wurde normal aktualisiert -, während der Zähler „aktive Nutzer" auf ihrer nowly.me-Seite über längere Zeit bei 0 blieb.

## Heartbeat für aktive Nutzer

Die Erweiterung verfolgte aktive Presences in einer einfachen In-Memory-Variable innerhalb des Hintergrund-Service-Workers. Chrome beendet und startet diesen Service Worker regelmäßig neu, wenn er inaktiv ist, wodurch dieser Zustand stillschweigend zurückgesetzt wurde - die periodische Heartbeat-Anfrage an die API konnte dadurch null aktive Presences melden, obwohl ein Tab tatsächlich aktiv war, und der Zähler „aktive Nutzer" konnte nach dem Deaktivieren einer Presence mehrere Minuten brauchen, um die Realität widerzuspiegeln. Die Nachverfolgung aktiver Presences wird jetzt in `chrome.storage.session` gespeichert, das Neustarts des Service Workers übersteht, sodass der Heartbeat zuverlässig bleibt.
