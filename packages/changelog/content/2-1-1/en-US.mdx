`2.1.1` is a maintenance release fixing a bug where a presence could be genuinely active - Discord Rich Presence updating normally - while the "active users" count on its nowly.me page stayed at 0 for extended periods.

## Active-user heartbeat

The extension tracked which presences were currently active in a plain in-memory variable inside the background service worker. Chrome routinely terminates and restarts this service worker when idle, which silently reset that state to empty - so the periodic heartbeat request to the API could report zero active presences even while a tab was genuinely active, and the "active users" count could take several minutes to reflect reality after toggling a presence off. Active-presence tracking now persists in `chrome.storage.session`, which survives service worker restarts, so the heartbeat stays accurate.
